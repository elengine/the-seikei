- 目的:管理者の実機確認(2026-10-09、Fold 8、会話)。「ビーミングの動作中に左右に揺れる動きを寄せるボタンで直すゲーム性は、やめる。ゲーム性は速さと止めるタイミングだけ」「速さは茶色の横棒を左右に引っぱって調整(0〜100)。今の速さを数字で出す」「100 ぴったりで止めたつもりでも、100.9 のように少しでも超えるとオーバーの判定になる。表示は 100 なので、101 に行っていなければ 100 ぴったりで止めた判定にしてほしい」。

## 決まり(括弧の中は確認役が決めた所。数値は `params.ts`)

1. **左右の揺れをやめる**:`shiftCm`・`shiftVel`・`nudge`・乗り上げ(`overflowMs`)と、「中央に保てた割合」の採点をやめる。操作欄の「◀ 寄せる」「寄せる ▶」を無くす。円盤の幅合わせ(幅の誤差の採点)は今のまま。
2. **速さを 0〜100 の連続に**:`speed: 0 | 50 | 100` を `speed: number`(0〜100)にする。アクション `{ type: 'setSpeed'; value: number }`(0〜100 に丸める)。巻く速さは速さに比例(100 で今と同じ、`FULL_WIND_SEC_AT_100`)。
3. **適正な速さ**:巻き量ごとの目標(0〜30%:50、25〜75%:100、70〜99%:50、95% 以上:0 で止める)は今のまま。速さが連続になるので、**目標 ±10 の中を適正**とする(`SPEED_OK_TOL = 10`。目標 50 なら 40〜60、100 なら 90〜100、0 なら 0〜10 ではなく「止めている〔0〕」だけ)。重なる区間ではどちらかに入れば適正。
4. **止めるタイミングの判定**:巻き量の表示は**小数点以下を切り捨て**て出す(今の表示に合わせる)。判定も表示と同じにする:
   - 巻き量が **100.0 以上 101.0 未満**で止めて「確認」すれば、「100% ぴったりで止めた」扱い(止めた位置の採点で最良)。
   - **101.0 に届いたら**糸が切れて失敗(今は 100.0 を超えたら失敗)。
   - 「確認」を出す条件(95% 以上で速さ 0)は今のまま。
5. **採点**:星3 = 適正な速さ 0.8 以上・止めた位置 99 以上(表示の値で)・微調整 2 回以下・幅の誤差 1cm 以内。星2 = 適正 0.6 以上・止めた位置 97 以上・幅の誤差 3cm 以内。星1 = それ以外(仕上げれば)。成績の行から「中央に保てた割合」「乗り上げ」を消す。
6. **遊び方**を今の画面に合わせる(00_rules。寄せる・偏りの説明を消す)。
- `isValidResume` も合わせる(古い途中保存は読まない形でよい)。
