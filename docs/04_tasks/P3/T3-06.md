# T3-06 ビーミング:3つの作業(幅合わせ → 糸をビームに付ける → 張りを見て巻く)、張りのメーター、動く適正範囲

- 目的:管理者の実機確認と指示(2026-10-09、会話)。
  - ビーミングは3つの作業にする:①円盤の幅合わせ(今のまま)②ドラムの糸をビームまで引っぱって付ける(新しい)③巻く。
  - ③では、下の「速さの目標の帯」(巻き量の帯に色の区間があるもの)をやめる。代わりに、ドラム巻きと同じ**張りのメーター**を出す。
  - 速さを上げると張りが少し遅れて上がる。メーターの**適正範囲が巻き量に合わせて動き**、遊ぶ人の速さを導く。
    - 30% までは速さ 50 ぐらい。
    - 30% を超えたら 100 へ上げさせる。
    - 70% ぐらいで 50 に戻させる。
    - そこから 100% に近づくにつれて落とさせ、100% 近くで止めて「完了」を押して終わる。
- 絵(ドラムをドラム巻きと同じ見た目に・回る向き・ビームの回転)と、②の糸の絵の作り込みは、実装担当が PU-26 で行う(この作業の後)。

- 進め方:1つのコミット。テストを先に書いて RED を確認してから直す。**push の前に `npm run check`。** version を patch で上げる(main より大きく。package-lock もそろえる)。

## 決まり(括弧の中は確認役が決めた所。数値は `params.ts`)

### 流れ

1. `phase` を `'setup' | 'attach' | 'beaming' | 'done'` にする。
2. **①幅合わせ(`setup`)**:今のまま。操作欄のボタンの名前を「巻き始める」から「**ビーム設定OK**」に変える。押すと `finishSetup` で、幅の誤差を記録して `'attach'` に進む。
3. **②糸を付ける(`attach`)**:
   - 盤面のドラムの下の端(糸のシートの端)を指で押さえ、ビームまで引っぱって離すと、糸が付く。新しいアクション `{ type: 'attachThread' }` で `'beaming'` に進み、速さは 0。
   - 当たり判定は `geometry.ts` に置く。
     - 押さえる所:ドラムの下の端。横はシートの幅、縦は上下 32px ずつ(画面上で 64px 以上)。
     - 離してよい所:ビームの軸と巻いた糸の円筒。円盤の間で、上下 32px の余裕を付ける。
   - それ以外で離したら、糸の端はドラムへ戻る(何も起きない。採点もしない)。
   - 引っぱっている間は、糸の端から指の位置まで、シートの線を描く(色は柄の色。今のシートの描き方を使い回してよい)。
   - 操作欄には案内の1行「ドラムの糸を、ビームまで引っぱってください」を出す(20px 以上)。
   - 茶色の棒は、`'attach'` でも動かない。
4. **③巻く(`beaming`)**:
   - 茶色の棒で速さを 0 より大きくすると巻き始める(今のまま)。「完了」を押すと結果が出る。
   - 今の「確認」のボタンを「**完了**」に変える。出す条件(95% 以上・速さ 0)と、押せない形のお知らせは今のまま。
   - お知らせの文:「棒を左端まで戻して止めてから、完了を押します」。

### 張り(tension)

5. state に `tension: number`(0〜100)を足す。張りは速さに**遅れて付いていく**:毎 tick、`tension += (speed - tension) × (1 - exp(-dt / TENSION_FOLLOW_MS))`。
   - `TENSION_FOLLOW_MS = 800`。
   - 速さ 0 の間も、張りは 0 へ下がっていく。今の `tick` は速さ 0 で何もしないが、`'beaming'` の間は張りだけは毎回動かす。巻き量と時間は、速さが 0 より大きいときだけ進む(今のまま)。
6. **適正範囲**は、巻き量に応じた**目標**の ±`SPEED_OK_TOL`(10)。0〜100 に収める。
   - 目標は、次の点を直線で結んだ値にする(`TARGET_POINTS`。巻き量 % → 目標)。
   - 点:(0, 50)、(30, 50)、(35, 100)、(70, 100)、(75, 50)、(100, 0)
   - 意味:30% までは 50。30〜35% で 100 へ上がり、70% まで 100。70〜75% で 50 に下がり、そこから 100% で 0 へ。
   - 関数 `targetOf(progress): number` と `okRangeOf(progress): { min: number; max: number }` を作って export する。
   - 今の `GOOD_SPEED_ZONES`・`goodSpeedOf` はやめる。
7. **適正**:張りが適正範囲の中にあれば適正。`goodMs` は、今と同じく巻いている間(速さが 0 より大きい間)に、張りが範囲の中なら数える。
8. 星の基準は T3-05 のまま。「適正」の割合が、張りで数えたものに変わるだけ。
   - `restarts`(微調整)・止めた位置・101% で糸切れも今のまま。
   - 成績の行の名前「適正な速さで巻いた割合」は「ちょうどよい張りで巻いた割合」に変える。
9. `isValidResume` も合わせる。`tension` が数であること、`phase` に `'attach'` を含める。古い途中保存は読まない形でよい。

### 操作欄

10. 巻き量の帯(色の区間の付いた「速さの目標」の帯)を無くす。
11. 代わりに、ドラム巻きと同じ張りのメーターを置く。
    - 部品は `src/core/ui/pedalControl.ts` の `createTensionMeter` を使う。`showState` はドラム巻きと同じ。
    - `update(tension, okRangeOf(progress))` で、毎回範囲が動く。
    - 節の見出しは用語の呼び名 `terms.t('tension')`。
12. 「巻き量 N%」(切り捨て)と「速さ N」の数字は残す。速さの数字の藍・朱と ▲▼ はやめて、ふつうの文字色にする(張りの判定はメーターとランプで示す)。
13. 盤面のランプ(`drawSpeedLamp`)は、張りが範囲の中かで点ける。
    - 名前は `drawTensionLamp` にしてよい。
    - 記号の併記は今のまま(色だけに頼らない)。

## テスト(先に書く)

- 流れ:`setup` → `finishSetup` → `attach` → `attachThread` → `beaming`。
  - `attach` で `setSpeed` は効かない。
  - `setup` で `attachThread` は効かない。
- 張り:速さ 100 にした直後は張りがまだ低い。0.8 秒で目標の約 63%、3 秒で 95% 以上。速さ 0 に戻すと下がっていく。
- `targetOf`:0%→50、30%→50、32.5%→75、50%→100、72.5%→75、87.5%→25、100%→0。`okRangeOf(0.5)` は {90, 100}。
- 適正:張りが範囲の中のときだけ `goodMs` が増える。速さ 0 の間は増えない。
- 当たり判定:ドラムの下の端の帯の中/外。ビームの円盤の間の中/外。
- controller:
  - ドラムの端からビームへ引っぱって離すと `beaming` になる。
  - 途中で離すと `attach` のまま。
  - `pointercancel` では何も起きない。
  - unmount で引っぱる操作のイベントが外れる。
- 操作欄:
  - 「ビーム設定OK」「完了」がある。「巻き始める」「確認」が無い。
  - 巻き量の帯が無い。
  - 張りのメーターがあり、範囲が巻き量で変わる。
  - `attach` で案内の1行が出る。
- 遊び方:4ページの文。「確認」「巻き始める」「速さの目標」の言葉が無い。
