## T3-04a:ルール(`logic.ts`)

- **張り(ペダル・張りのメーター)をやめる**。`BeamingState` から `pedal`・`tension`・`range`・`okMs` を外し、代わりに次を持つ(`isValidResume` も合わせる)。
  ```ts
  speed: 0 | 50 | 100;          // レバーの位置(停止・50%・100%)
  progress: number;             // 巻き量 0〜1(1 を超えたら糸切れ)
  goodMs: number;               // 適正な速さで巻いていた時間
  windMs: number;               // 巻いていた時間(speed > 0 の時間)
  restarts: number;             // 巻き量 95% を超えてから、停止 → 50% に戻した回数(微調整)
  broken: boolean;              // 100% を超えて糸が切れた
  ```
- **巻く速さ**:`speed` 100 で `FULL_WIND_SEC_AT_100`(30 秒)で 0→1 になる速さ、50 はその半分。0 は止まる。
- **適正な速さ**(巻き量 % で決まる。重なる所はどちらでも適正):0〜30 は 50、25〜75 は 100、70〜99 は 50、95〜100 は 0(止める)。数値は `params.ts` の表 `GOOD_SPEED_ZONES`。`speed > 0` のあいだ、そのときの巻き量の適正に合っていれば `goodMs` に足す。
- **100% を超えたら**:`broken` を true、`phase` を 'done'(失敗)。
- **確認(`confirm`)**:巻き量 95% 以上で、`speed` が 0 のときだけ受け付ける。判定して 'done'。
- **偏り(寄せる)・幅合わせ**:今のまま。
- **採点**(失敗でなければ):
  - 適正な速さの割合 = `goodMs / windMs`。
  - 止めた位置 = 巻き量(%)。99.0 以上が最良。
  - 微調整の回数 = `restarts`。
  - 幅合わせの誤差・中央に保てた割合(今のまま)。
  - 星3:適正 0.8 以上・止めた位置 99.0 以上・微調整 2 回以下・幅の誤差 1cm 以内・中央 0.8 以上。星2:適正 0.6 以上・止めた位置 97.0 以上・幅の誤差 3cm 以内。星1:それ以外。
  - **失敗**(糸切れ)は星なし。結果の画面は題名「糸が切れました」、成績の行に「巻き量が 100% を超えました」、ボタンは「もう一度」「一覧」。
  - 成績の行:「適正な速さ 86%」「止めた位置 99.2%」「微調整 1回」「幅合わせの誤差 0.5cm」「中央に保てた割合 91%」。
- テスト:速さ 100 で 30 秒で巻き終わる/適正の表どおりに `goodMs` が増える/95% 未満では確認できない/止めずに 100% を超えると失敗/95% から 50 に戻して 100 に近づけられる、`restarts` が増える/採点の境目。

## T3-04b:速さのレバー

- 盤面の**ビームの少し上**に、速さのレバー(横に3つの止まり:左「停止」・中「50%」・右「100%」)を置く。引っぱるか、止まりを押して動かす。押せる所は 64px 以上。文字は 20px 以上。今のペダルの帯は無くす。
- 座標は `geometry.ts`。巻いているあいだも幅合わせの段階でも見える(幅合わせの段階では押せない形)。
- テスト:止まりを押すと `speed` が変わる、引っぱって離すと近い止まりに吸い付く、幅合わせの段階では動かない。
- **適正な速さを示す表示**(管理者の確認 2026-10-05:「張りのメーターが無くなり、代わりに速さの適正範囲を示す UI になる。どのような UI が適切かは任せる。仕上がりを見て調整」):
  - **巻き量の帯**:操作欄の「巻き量 73%」の下に、横長の帯(0〜100%)。帯を適正な速さの区間ごとに塗り分け、区間の中に文字で「50%」「100%」「50%」「停止」(重なる所は境目の線)。今の巻き量の位置に縦の印。95% と 100% の所に目印の線、100% の線は朱(「ここを超えると糸が切れる」)。
  - **レバーの止まり**:今の巻き量で適正な止まりを、藍の枠と「適正」の小さな文字で示す(重なる区間では2つとも)。
  - **ランプ**(ドラム巻きの PU-14b と同じ部品の考え):盤面のビームの上の左寄りに、今の速さが適正なら緑の「○」、外れていればオレンジの「▲」(速すぎ)か「▼」(遅すぎ)、停止中は消灯。色だけに頼らず記号を添える。
  - テスト:巻き量に合わせて適正な止まりの印が変わる、帯の区間の文字、ランプの3つの状態。
- 「寄せる」ボタンは今のまま残す(管理者の確認 2026-10-05)。
