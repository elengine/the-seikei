## 決まり(括弧の中は確認役が決めた所)

1. **目標の点**(`TARGET_POINTS`。巻き量 % → 目標の速さ)を次にする:
   - (0, 0)、(10, 100)、(85, 100)、(90, 25)
   - 意味:0〜10% で 0 から 100 へ上がる。10〜85% は 100(10〜80% は下の揺らぎあり。80〜85% は揺らぎ無しの 100)。85〜90% で 100 から 25 へ下がる。
   - 範囲は今のとおり「目標 − 揺らぎ ± レベルの幅(`OK_TOL_BY_LEVEL`)」で、0〜100 に収める。
2. **揺らぎの区間**:35〜70% → **10〜80%**。下がる間隔・量・下がる/戻る時間は今のまま。区間の外に出たらすぐ 0 に戻す(今のまま)。数値の区間は `params.ts` に置く(`DIP_FROM_PCT = 10`・`DIP_TO_PCT = 80`)。
3. **90〜100% は止めてよい範囲**:巻き量が 90% 以上のときは、目標とレベルの幅を使わず、適正範囲を**いつでも 0〜30**(`STOP_ZONE = { from: 90, min: 0, max: 30 }` を `params.ts` に)にする。速さ 0(止めている)も範囲の中。
   - `goodMs`:今は「巻いている間(速さ > 0)に範囲の中なら数える」。90% 以上で止めている時間は、巻いていないので数えない(今のまま。止めても損をしない)。
   - 「完了」の条件(95% 以上・速さ 0)と、101% で糸が切れるのは今のまま。
4. 遊び方4ページ目の文:「巻き量が 90% を超えると、緑の範囲がいちばん左まで広がり、いつでも止められます。95% を超えたら、木の棒を左端まで戻して止め、『完了』を押します。100% で止めるといちばんよい結果です。101% に届くと糸が切れます」
