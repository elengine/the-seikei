## 決まり

1. **メーターの針は速さ**:操作欄(縦長では盤面の上の帯)のメーターは、張りではなく**速さ(`s.speed`、0〜100)**を示す。木の棒を動かすと、針はその場で同じ値になる(遅れない・揺れない)。
   - 部品は今の `createTensionMeter` のまま使ってよい。`update(s.speed, okRangeOf(s.progress, s.level, s.dip))`。
   - 節の見出しは `terms.t('speed')`(用語に `speed` が無ければ「速さ」と書かずに、ルビーが `terms` に足す前に報告で相談する)。
2. **適正範囲の動きは今のまま**:`TARGET_POINTS`、レベルの幅 `OK_TOL_BY_LEVEL`、35〜70% の小さな揺らぎ(`dip`)は変えない。
3. **適正の判定は速さで**:`goodMs` は、巻いている間(速さ > 0)に**速さが適正範囲の中**なら数える。盤面のランプ(○▲▼)も速さで判定する(▲は速すぎ、▼は遅すぎ)。
4. **張り(`tension`)をやめる**:state の `tension`、`TENSION_FOLLOW_MS`、tick の中の張りの計算を消す。`isValidResume` は `tension` を求めない形にし、古い途中保存(`tension` がある形)も読んでよい(余分な値は捨てる)。
5. 成績の行「ちょうどよい張りで巻いた割合」→「**ちょうどよい速さで巻いた割合**」。星の基準は変えない。
6. 遊び方3ページ目の文:「木の棒を右へ引っぱると巻き始めます。速さのメーターの針を緑の範囲に入れるように、木の棒を動かします。緑の範囲は、巻き量に合わせて動きます」。絵のメーターの見出しも「速さ」にする。
