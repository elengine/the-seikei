## 決まり(実装済み)

1. **75% からの減速**:巻き量が `BRAKE_FROM`(0.75)を超えると、木の棒の速さにかかわらず、機械の巻く速さが落ちていく。車がなめらかに止まるときと同じ一定の減速(実際の速さ ∝ √残り)で、`BREAK_AT`(1.001)でちょうど 0 になる(`logic.ts` の `brakeFactor`)。メーターの針は今のとおり木の棒の位置(`s.speed`)を示す。
2. **小数表示**:巻き量の表示は、95% 以上で小数第 1 位まで(切り捨て。`progressLabel`)。95% 未満は整数(切り捨て)。
3. **糸切れは 100.1%**:巻き量が `BREAK_AT`(100.1%)に届くと糸が切れて失敗(T3-05 の 101% から変更)。切れた瞬間に短いブザー(`sounds.ts` の `buzzer`、約 0.4 秒)。文は「巻き量が100%を超えたので糸が切れました」、文字は 1.25 倍。
4. **遊び方**:「101%」を「100.1%」に。
5. **ドラムの糸**:糸の厚みは √ の曲線で減り、100.1%(`SIDE_YARN_GONE`)でちょうど無くなる(PU-32 追加修正 4 の 16 の 100.9% から変更)。
