## 仕様:base.css

- `:root` に CSS 変数(`--c-kinari` など全色、`--gap`、`--radius`、`--btn-min-h`、`--btn-min-w`)を定義し、T0-01 で直書きした色を変数に置き換える。
- `:root[data-font="large"]` と `:root[data-font="xlarge"]` で `--fs-body`、`--fs-button`、`--fs-heading`、`--fs-number` を切り替える。
- 部品用のクラス:`.btn`、`.btn--primary`(machineDark 地・白文字)、`.btn--secondary`(白地・藍の枠と文字、枠線 3px)、`.dialog-backdrop`、`.dialog`、`.dialog__message`、`.dialog__actions`、`.text-input`(文字は `--fs-body`、高さ 64px 以上)。
- ボタンは押している間 `transform: translateY(2px)`。フォーカス時は藍の太い枠。

## 仕様:widgets.ts

```ts
export function createButton(opts: {
  label: string; variant?: 'primary' | 'secondary'; onClick: () => void; testId?: string;
}): HTMLButtonElement;

// 2択の確認。押したボタンの値で解決する。背景を押しても閉じない。
export function confirmDialog(parent: HTMLElement, opts: {
  message: string; okLabel: string; cancelLabel: string;
}): Promise<boolean>;

// 文字入力。「決定」で入力値、「やめる」で null。空文字の決定は不可(ボタンを押せない状態にする)。
export function textInputDialog(parent: HTMLElement, opts: {
  title: string; initial: string; maxLength: number; okLabel?: string; cancelLabel?: string;
}): Promise<string | null>;
```

- ボタンには `data-testid` を付けられるようにする(ブラウザ検証用)。
- ダイアログは閉じたら DOM から取り除く。

## テスト(jsdom)

1. `createButton` をクリックすると onClick が1回呼ばれる。variant ごとにクラスが付く。
2. `confirmDialog` で ok を押すと true、cancel で false。閉じた後に DOM に残らない。
3. `textInputDialog` で入力して決定すると値、やめると null。空のときは決定ボタンが disabled。
4. `applyFontScale` で data-font 属性が変わる。
