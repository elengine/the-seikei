- 目的:ホーム画面と設定画面を作り、ブラウザで操作できるようにする。
- 関連要件:FR-C-01、FR-C-03、FR-C-05、NFR-U 全般、03_basic_design 1章・2章
- 前提:T0-13、T0-14

## 作成・変更するファイル

`src/app/screens/homeScreen.ts`(新規)、`src/app/screens/settingsScreen.ts`(新規)、`src/main.ts`(変更)

## 仕様:homeScreen.ts

```ts
export function createHomeScreen(ctx: AppContext): Screen;
```

- 上部に屋号を見出しの大きさで表示し、その下に名前があれば「◯◯さん、こんにちは」。
- 登録済みゲーム(`listGames()`)ごとに大きな主ボタン(題名は `ctx.terms.t(m.titleTermKey)`)。P0 ではゲームがないので「ゲームはただいま準備中です」と表示する。
- 下部に副ボタン「せってい」。
- ボタンは縦に1列(portrait)、または2列(landscape)で並べる。
- ボタンを押したら `ctx.audio.play('tap')`。

## 仕様:settingsScreen.ts

```ts
export function createSettingsScreen(ctx: AppContext): Screen;
```

項目ごとに、現在の値と「かえる」ボタンを1行ずつ並べる。

| 項目 | 操作 |
|---|---|
| お名前 | textInputDialog(最大10文字) |
| 屋号 | textInputDialog(最大12文字) |
| 文字の大きさ | 「大」「特大」の2つのボタン。選ばれている方を藍の枠で示し、文字でも「(いまの設定)」と書く |
| 音 | 「鳴らす」「鳴らさない」の2つのボタン |
| 音の大きさ | 「小」「中」「大」(0.4 / 0.7 / 1.0)。変更したら ok の音を鳴らして聞かせる |
| 呼び名をかえる | `#/settings/terms` へ(画面は T0-16) |
| もどる | ホームへ |

最下部に小さめの副ボタン「管理者」。押すと textInputDialog で数字を入れさせ、`1967` なら `#/admin` へ(画面は T0-16)、違えば何もせず閉じる。

設定の変更は即座に保存し、画面にも反映する(文字の大きさは画面全体が切り替わる)。

## 仕様:main.ts

1. `createSystemClock()` と `createAppContext({ dbName: 'seikei-game', … })` を作る。
2. ルート `/` → ホーム、`/settings` → 設定 で ScreenManager を作って start。
3. 最初の `pointerdown` で `ctx.audio.unlock()` を一度だけ呼ぶ。

(移行処理と PWA は T0-17 で追加する)

## 完了条件

- `npm run check` と `npm test` が成功する。
- ブラウザ検証(CDP など)で次を確かめ、結果を報告する。画面幅 1180×820(iPad 横)と 412×915(スマホ縦)の両方で行う。
  1. ホームに屋号「整経所」と「ゲームはただいま準備中です」が出る。
  2. 設定で屋号を変えると、ホームに戻ったとき新しい屋号が出る。再読み込みしても残る。
  3. 文字の大きさを「特大」にすると、本文の文字が 24px になる。
  4. すべてのボタンの大きさが 64px 以上(高さ)。
  5. 管理者に `0000` を入れても移動しない。
