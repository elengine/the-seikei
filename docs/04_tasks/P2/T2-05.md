## 座標(geometry.ts)

- 論理座標は 1000×750。座標の変換(`toPx`・`fromPx`)は、クリール立てと同じ形で、この geometry.ts だけで行う。
- 区画:左にクリール(x 40〜240)、中央に帯を送る台とレール(x 260〜560)、右にドラム(x 580〜960)。上の余白(y 0〜90)に、目盛り盤と赤ランプ。

```ts
export const LOGICAL_W = 1000;
export const LOGICAL_H = 750;
/** 糸 thread(0〜threadCount-1)の、クリール側とドラム側の切れ端の位置(論理座標) */
export function endPoint(thread: number, side: 'creel' | 'drum', threadCount: number): { x: number; y: number };
/** 画面上の点(論理座標)から、いちばん近い切れ端を返す。画面上で 32px(= 64px 四方の半分)より遠ければ null */
export function hitEnd(p: { x: number; y: number }, threadCount: number, scale: number): { thread: number; side: 'creel' | 'drum' } | null;
```

- 糸は、クリールの各コーン(threadCount 本、上から下へ等間隔)から台のレールを通り、ドラムの今の帯の区画へ向かう線。
- 切れ端は、糸の途中(台の左右)で切れて垂れる形。クリール側の端は x 380、ドラム側の端は x 460 付近。
- **当たりの大きさは画面上で 64px 四方以上**(NFR-U-02)。論理座標では `32 / scale` の半径で判定する。隣の糸の当たりと重なるときは、いちばん近い端を選ぶ。

## 描画(renderer.ts)

```ts
export function drawBoard(
  ctx: CanvasRenderingContext2D,
  fit: { scale: number; offsetX: number; offsetY: number },
  s: WindingState,
  content: Content,
  opts: { threadCount: number; show: 'red' | 'droop' | 'small'; timeMs: number },  // show は難易度の見せ方、timeMs は揺れの計算用
): void;
```

1. 背景(kinari)を Canvas 全体に塗る。
2. クリール:machine 色の枠と、柄の色のコーン(threadCount 本。柄の並びの色を上から順に使う)。
3. 糸:コーンからドラムまで、柄の色の線。巻いているときは、糸の上に小さな印が流れて動く(速さに比例)。
4. ドラム:茶色(wood)の桟を組んだかご状の胴。帯の区画を sections 等分し、巻き終えた帯と巻いている帯を、柄の色の縞で、巻いた長さに応じた厚みで描く。
5. 目盛り盤:今の帯の巻いた長さ(割合)を円の針で示し、横に「帯 3 / 5」を文字で出す。
6. 赤ランプ:'broken' のとき shu で点灯(点滅しない)し、横に「停止」と文字で出す。そうでなければ灰色で消灯。
7. 'broken' のとき、切れた糸を途中で切って、両側の切れ端を垂らす。見せ方は `show`:'red' は切れた糸を shu で描いて timeMs でゆっくり揺らす、'droop' は色を変えず垂れだけ、'small' は垂れを小さく。1手目を済ませたら、クリール側の端に藍の丸印。
8. 'done' のとき、ドラムの表面を帯ごとの出来(`qualities`)で描き分ける。出来が低い帯ほど、表面の線を波打たせる(波の高さ = (1 − 出来) × 係数)。
- 文字は画面上 20px 以上。文字の位置と大きさは画面 px で決める(クリール立ての追加修正の教訓)。Canvas の幅は `clientWidth` を使う。

## テスト(先に書く)

- geometry:toPx・fromPx の往復。endPoint が threadCount 本とも盤面の中。hitEnd が端の上で当たり、遠いと null。scale 0.4(スマホ縦)でも、画面上 30px 離れた点で当たる。隣り合う糸の間を押すと、近いほうを返す。
- renderer(偽の ctx):'broken' で shu の線が描かれる(show 'red')。ランプの点灯・消灯で色が変わる。'done' で帯の数だけ表面が描かれる。文字は 20 以上(画面 px)。
