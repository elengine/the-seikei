## 型

```ts
import type { RngState } from '../../core/clock/clock';
import type { PedalState } from '../../core/mechanics/pedal';
import type { BreakState } from '../../core/mechanics/breakage';

export type Level = 1 | 2 | 3;   // 初級・中級・上級

export interface WindingState {
  level: Level;
  patternId: string;
  sections: number;                 // 帯の数
  phase: 'ready' | 'winding' | 'broken' | 'cutting' | 'done';
  current: number;                  // 巻いている帯(0 始まり)
  lengths: number[];                // 帯ごとの巻いた長さ
  windMs: number[];                 // 帯ごとの、巻いていた時間(speed > 0)
  okMs: number[];                   // 帯ごとの、適正範囲に入っていた時間
  pedal: PedalState;
  tension: number;                  // 最後に計算した張り(描画用)
  brk: BreakState;
  breaks: number;
  wrongTaps: number;
  rng: RngState;
}

export type WindingAction =
  | { type: 'start' }                                     // 「巻き始める」
  | { type: 'setPedal'; value: number }
  | { type: 'tick'; dtMs: number }
  | { type: 'tapEnd'; thread: number; side: 'creel' | 'drum' }
  | { type: 'cut' }                                       // 「帯を切って留める」
  | { type: 'pausePedal' };                               // 裏に回ったときなど、ペダルを 0 にする

export function init(opts: { level: Level; patternId: string; sections: number; seed: number }): WindingState;
export function reduce(s: WindingState, a: WindingAction): WindingState;   // 元の s は変更しない
export function qualities(s: WindingState): number[];      // 帯ごとの出来 okMs / windMs(windMs 0 なら 0)
export function starsOf(s: WindingState): 1 | 2 | 3;       // 平均 0.8 以上 3、0.6 以上 2、それ未満 1
export function isValidResume(x: unknown): x is WindingState;
export function lastTapResult(prev: WindingState, next: WindingState): 'first' | 'tied' | 'wrongThread' | 'retry' | null;
// 効果音とメッセージのため。controller が reduce の前後を比べて使う(breaks・wrongTaps・brk の変化から判定)
```

## params.ts(難易度ごと。数値はここだけに置く)

`SECTIONS`(3・5・7)、`RANGE`(30〜70・38〜62・44〜56)、`BREAK_RATE`(0.01・0.02・0.04)、`STANDALONE_PATTERN`(`p-pin-kon`・`p-chalk-char`・`p-alt-kon`)、共通の `MAX_SPEED`、`SECTION_LENGTH`(pedal 50 で 20 秒)、`TENSION`(T2-01 の TensionParams の初期値)、`BREAK`(T2-02 の BreakParams の初期値)、`MAX_TICK_MS = 100`、`STARS3 = 0.8`、`STARS2 = 0.6`。

## ルール

- **init**:phase 'ready'、current 0、各配列は 0 で埋める、pedal は `initPedal`、brk は `initBreak`、rng は `seedFrom(seed)`。
- **start**:'ready' のときだけ 'winding' にする。
- **setPedal**:'winding' のときだけ値を変える。'broken'・'cutting'・'done'・'ready' では変えない。
- **pausePedal**:どの phase でもペダルを 0 にする('done' を除く)。
- **tick**:`dtMs` を `MAX_TICK_MS` で丸める(0 未満は 0)。'winding' のときだけ進める。
  1. noise を進める(`stepNoise`)。
  2. progress = (current + lengths[current] / SECTION_LENGTH) / sections。tension を計算して保存する。
  3. speed > 0 なら:lengths[current] に speed × dt を足す。windMs に dt を足し、範囲内なら okMs にも足す。糸切れの判定(`stepBreak`)を進める。
  4. 切れたら phase 'broken'、breaks + 1。
  5. lengths[current] が SECTION_LENGTH 以上になったら、SECTION_LENGTH に揃え、phase 'cutting'、ペダルを 0 にする。
- **tapEnd**:'broken' のときだけ `tapEnd` を呼ぶ。'wrongThread' なら wrongTaps + 1。'tied' なら phase 'winding'、**ペダルを 0 にする**。
- **cut**:'cutting' のときだけ。最後の帯なら 'done'。そうでなければ current + 1、'winding'(ペダルは 0 のまま)。
- 'done' の後はどの操作でも状態を変えない。
- **isValidResume**:形(phase・配列の長さ = sections・数値の範囲)を確かめる。再開したときのペダルは controller が `pausePedal` で 0 にする。

## テスト(先に書く)

1. init → start → setPedal(50) → 20 秒を少し超えるぶん tick(100ms × 201)で、帯0が 'cutting' になり、ペダルが 0。
2. 'ready' のとき setPedal は効かない。'broken' のときも効かない。
3. tick の dtMs 5000 は 100 として扱われる(長さの増え方で確かめる)。
4. pedal 40(安全なペダル)で全帯を巻くと、糸切れが0回、qualities がすべて 1、星3(cut を挟む)。
5. pedal 100 で巻くと、上級では、同じ種で決まった回で 'broken' になる。tapEnd で creel → drum と押すと 'winding' に戻り、ペダル 0、breaks 1。
6. 別の糸を押すと wrongTaps + 1。
7. 止まっている時間(pedal 0)は windMs に入らない。
8. 最後の帯で cut → 'done'。'done' の後の操作は状態を変えない。
9. starsOf:平均 0.85 → 3、0.7 → 2、0.5 → 1。
10. isValidResume:init の結果は true、配列の長さが違うと false。
