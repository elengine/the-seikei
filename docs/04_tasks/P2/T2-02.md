## 型

```ts
import type { RngState } from '../clock/clock';

export interface BreakParams {
  checkMs: number;        // 500
  rate: number;           // 範囲の上を1外れるごとの確率(初級 0.01・中級 0.02・上級 0.04)
  maxChance: number;      // 1回の判定の上限 0.5
  threadCount: number;    // 8
}

export type BreakState =
  | { kind: 'running'; sinceCheckMs: number }
  | { kind: 'broken'; thread: number; firstTapped: boolean };

export interface BreakStats { breaks: number; wrongTaps: number; }

export function initBreak(): BreakState;   // running、sinceCheckMs 0

/** 運転中の時間経過。checkMs たまるごとに1回判定する。切れたら broken(thread は乱数) */
export function stepBreak(
  s: BreakState, p: BreakParams, dtMs: number, tension: number, rangeMax: number, rng: RngState,
): { state: BreakState; rng: RngState; broke: boolean };

/** 切れ端をタップした。side は 'creel'(クリール側)か 'drum'(ドラム側) */
export function tapEnd(
  s: BreakState, thread: number, side: 'creel' | 'drum',
): { state: BreakState; result: 'first' | 'tied' | 'wrongThread' | 'retry' | 'ignored' };
```

## ルール

- **stepBreak**:`kind` が 'running' のときだけ時間を数える('broken' なら何もしない)。`sinceCheckMs` が `checkMs` 以上になるたびに1回判定し、`checkMs` を引く(1回の dtMs で複数回の判定が起きてもよい)。
  - `tension <= rangeMax` なら切れない。
  - `tension > rangeMax` なら、`chance = min(maxChance, rate × (tension − rangeMax))` の確率で切れる。
  - 切れたら `{ kind: 'broken', thread: 0〜threadCount-1 の乱数, firstTapped: false }`、`broke: true`。同時に切れるのは1本だけ。
- **tapEnd**('broken' のときだけ。'running' なら result 'ignored'):
  - thread が切れた糸と違う → 'wrongThread'(状態はそのまま。1手目を済ませていても、1手目からやり直し = firstTapped false)。
  - 切れた糸で side 'creel'、firstTapped false → firstTapped true、'first'。
  - 切れた糸で side 'drum'、firstTapped true → `initBreak()` に戻り、'tied'。
  - 切れた糸で side 'drum'、firstTapped false → 'retry'(先にクリール側を押す。状態はそのまま)。
  - 切れた糸で side 'creel'、firstTapped true → 'first'(そのまま)。
- 回数(BreakStats)は、呼び出し側(各ゲームの reducer)が result を見て数える。

## テスト(先に書く)

1. tension が範囲内なら、10分ぶん進めても切れない。
2. tension が範囲の上を大きく外れる(chance が上限 0.5)と、同じ種で決まった回で切れ、thread が 0〜7。同じ種と同じ入力なら同じ結果。
3. dtMs 1200・checkMs 500 で、判定が2回行われ、sinceCheckMs が 200 になる(切れない条件で確かめる)。
4. 'broken' の間は stepBreak が何もしない。
5. tapEnd:正しい順(creel → drum)で 'tied'、running に戻る。
6. tapEnd:別の糸 → 'wrongThread'、firstTapped が false に戻る。
7. tapEnd:drum を先に → 'retry'。running のとき → 'ignored'。
