## T2-14a:15題

- **お題は、クリール立てのお題(`content.creelPuzzles`)から作る**(データを二重に持たない)。`puzzles.ts` に `windingPuzzles(content): WindingPuzzle[]` を置く。

  ```ts
  export interface WindingPuzzle {
    id: string;          // クリール立てのお題と同じ id(例 's2-3')
    stage: 1 | 2 | 3 | 4 | 5;
    patternId: string;   // クリール立てと同じ柄
    name: string;        // 柄の名前(例「紺地のピンストライプ」)
    sections: number;    // 帯の数
    level: Level;        // 張り・糸切れなどの難易度の数値(params の初級・中級・上級)
  }
  ```

- 段階ごとの帯の数と難易度(`params.ts` の `PUZZLE_STAGE`):

  | 段階 | 帯の数 | 難易度の数値 |
  |---|---|---|
  | 1 | 3 | 初級 |
  | 2 | 4 | 初級 |
  | 3 | 5 | 中級 |
  | 4 | 6 | 中級 |
  | 5 | 7 | 上級 |

- State に `puzzleId` を足す(途中保存 `isValidResume` も合わせる。古い形の保存は再開しない)。
- **一覧:** クリール立ての一覧と同じ形(段階ごとの節「段階N」、`createListRow`、見本は柄、名前、補足「帯 N本」、状態は星・次はこれ・鍵)。解放の決まりもクリール立てと同じ(前のお題をクリアすると次が遊べる。1題目は最初から)。
  - クリール立てで同じお題をクリアしていれば、補足に「クリール立て済み」と添える(遊べるかどうかには関係しない)。
- 成績は `best['puzzle:<id>']`(クリール立てと同じ形)。今までの `best['level:N']` は使わない(残っていても読まない)。
- 結果の画面の「次へ」は「次のお題へ」(次のお題があり、解放されていれば)。題名の下は「段階N 柄の名前」。
- テスト:
  - `puzzles.test.ts`:お題が15題、id と柄がクリール立てと同じ、段階ごとの帯の数と難易度が表のとおり。
  - `listView.test.ts`:節が5つ、「次はこれ」が1つ、未解放を押すと理由が出る、クリール立て済みの補足。
  - `logic.test.ts`:`puzzleId` を持つ、帯の数がお題どおり。

## T2-14b:糸の種類の手応え

- お題の柄でいちばん多く使う糸の `spec`(例「ウール 2/48」「ウール 2/60」「ウール紡毛 1/20」)から、糸の手応え `YarnFeel` を決める(`puzzles.ts` に `yarnFeelOf(spec)`)。

  | 手応え | 当てはまる糸 | 変えるもの(`params.ts` の `YARN_FEEL`) |
  |---|---|---|
  | 標準 | 2/48 など、下に当てはまらないもの | 変えない |
  | 細い糸 | 番手の数が 60 以上(例 2/60) | 切れやすい:`BREAK_RATE` ×1.5、`BREAK_EXTRA_STEP` −2(最小 4) |
  | 太い糸 | 紡毛、または番手の数が 30 以下(例 1/20) | 張りが流れやすい:`DRIFT` の `perSec` ×1.3、`snagRate` ×1.3 |

- 一覧の補足と、ゲームの題名の下に、糸の手応えを短く出す(例「帯 5本・細い糸(切れやすい)」)。遊び方(T2-12)は変えない。
- 「ペダルで必ず範囲に届く」決まり(T2-11)は、どの手応えでも守る(テストで確かめる)。
- テスト:
  - `puzzles.test.ts`:「ウール 2/60」→ 細い糸、「ウール紡毛 1/20」→ 太い糸、「ウール 2/48」→ 標準。
  - `logic.test.ts`:細い糸のお題は、同じ外れ方で標準より切れやすい(同じ種で比べる)。太い糸のお題は、流れの動きが大きい。どの手応え・どの段階でも、ペダル 10〜100 のどこかで範囲の中心に届く。
