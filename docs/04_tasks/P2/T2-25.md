## 決まり

1. 時計の文字は「経過時間」「/」「制限時間」の3つの部品(span)に分ける。
2. 目標(制限時間)を超えたら:
   - 「超過」の文字は出さない。
   - **経過時間の部品だけ**を、ゆっくり点滅させる(1 回の明滅 1.6 秒。見えている時間を長めに。CSS の animation で、不透明度 1 ↔ 0.25)。数値は CSS の変数か tokens に置く。
   - 「/」と制限時間は点滅させない。
   - 経過時間の朱の色は今のまま(色に加えて点滅で知らせる。色だけに頼らない)。
3. 目標を超えていないあいだは点滅しない(今のまま)。
4. 文字の大きさの計算は、「0:00/0:00」(超過の文字なし)で測る形に直す。
5. 端末の「視差効果を減らす」(`prefers-reduced-motion: reduce`)では点滅させず、経過時間に下線を引く(色だけに頼らないため)。
6. 遊び方5ページ目の絵の例も「1:52 / 1:30」(超過なし)にする。絵では点滅は表せないので、文字は今の朱のままでよい。
