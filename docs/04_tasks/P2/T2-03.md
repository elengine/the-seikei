## 型

```ts
export interface PedalControl {
  root: HTMLElement;
  setValue(v: number): void;       // 外から値を変える(0〜100)。onChange は呼ばない
  setEnabled(on: boolean): void;   // 糸切れ中などは押せない見た目にし、操作を受け付けない
  destroy(): void;
}
export function createPedalControl(parent: HTMLElement, opts: {
  label: string;                   // 呼び出し側で terms.t('pedal') 済み
  onChange: (v: number) => void;   // 利用者が動かしたとき
}): PedalControl;

export interface TensionMeter {
  root: HTMLElement;
  update(tension: number, range: { min: number; max: number }): void;
  destroy(): void;
}
export function createTensionMeter(parent: HTMLElement, opts: { label: string }): TensionMeter; // label は terms.t('tension') 済み
```

## ペダル(足踏みの横木)

実物は、ドラムの下の横長の木製のフットバーを踏み下げる量で速さを変える(P2/README「実物に合わせて決めたこと」1)。画面でもその形にする。


- 縦長の溝の中を、**横長の木の棒(横木)**が上下に動く。**一番上が 0(止まる)、一番下が 100(速い)。押し下げるほど速い。** 溝の高さは 240px 以上、横木は幅 160px 以上・高さ 64px 以上。横木は木の色(`--c-wood`)。
- 溝の中を押すと、その位置の値になる。押したまま動かすと追従する。**指を離しても位置を保つ。**
- `pointerdown` で `setPointerCapture`。`pointermove` は捕まえている間だけ。`pointerup`・`pointercancel` で離す。
- **iPad(Safari)対策**:溝と横木に `touch-action: none` を付ける(指で動かしている間に画面がスクロールしない)。
- 横に「踏み込む」(+10)と「戻す」(-10)のボタン(64px 以上)を置く。
- 値は、横木の横に文字でも出す(例「速さ 50」)。色だけに頼らない。
- `setEnabled(false)` のとき、横木と溝を薄く表示し、押しても値が変わらない。

## 張りのメーター

- 横長の帯。0〜100 の目盛りの上に、適正範囲を緑(`--c-machine-light` など tokens の色)で塗り、今の張りを縦の針で示す。
- 帯の下に文字で状態を出す:範囲内「適正」、上「強すぎ」、下「弱い」。記号も付ける(例「○ 適正」「▲ 強すぎ」「▼ 弱い」)。色だけに頼らない。
- 文字は `--fs-body` 以上。

## テスト(jsdom、先に書く)

1. ペダル:溝の高さ 240px を仮定し(`getBoundingClientRect` を偽物にする)、溝の上端を押すと 0、下端で 100、真ん中で 50 が onChange に渡る(押し下げるほど速い)。
2. `pointermove` は、`pointerdown` の後だけ onChange を呼ぶ。`pointerup` の後は呼ばない。
3. 「踏み込む」で +10、「戻す」で -10(0〜100 に丸める)。
4. `setEnabled(false)` の間は、押しても onChange が呼ばれない。
5. `setValue` は onChange を呼ばず、表示の数字が変わる。
6. メーター:tension 50・範囲 38〜62 で「適正」、70 で「強すぎ」、30 で「弱い」。針の位置(style の値)が tension に比例する。
7. destroy で DOM から消え、pointer のリスナーも外れる。
