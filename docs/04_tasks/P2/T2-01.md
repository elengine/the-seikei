## 型

```ts
import type { RngState } from '../clock/clock';

export interface TensionParams {
  maxSpeed: number;        // pedal 100 のときの速さ(長さ/秒)
  base: number;            // 30
  perPedal: number;        // 0.4
  yarnDrift: number;       // 4(progress 0→1 で最大 +4)
  noiseAmp: number;        // 2(noise は -noiseAmp〜+noiseAmp)
  noiseStepPerSec: number; // noise が1秒に動ける最大の量(例 1)
  range: { min: number; max: number };  // 適正範囲
}

export interface PedalState {
  pedal: number;    // 0〜100(整数に丸めない)
  noise: number;    // -noiseAmp〜+noiseAmp
  rng: RngState;
}

export function initPedal(seed: RngState): PedalState;              // pedal 0、noise 0
export function setPedal(s: PedalState, value: number): PedalState; // 0〜100 に丸める
export function speedOf(s: PedalState, p: TensionParams): number;   // pedal / 100 * maxSpeed
export function tensionOf(s: PedalState, p: TensionParams, progress: number): number;
// base + perPedal * pedal + yarnDrift * clamp(progress, 0, 1) + noise
export function stepNoise(s: PedalState, p: TensionParams, dtMs: number): PedalState;
// 乱数で noise を少し動かす。1回の変化は noiseStepPerSec * dtMs/1000 以内。範囲の外に出ない
export function zoneOf(tension: number, p: TensionParams): 'low' | 'ok' | 'high';
```

- すべて純粋関数。元の状態は変更しない。乱数は `core/clock` の `nextFloat` を使う。
- `src/core/mechanics` は `src/core` の中なので、`app`・`games`・`zukan` を import しない。

## 効果音「機械が止まる音」(`sounds.ts`)

- `SoundName` に `'stop'` を足す。糸が切れて機械が止まったときに鳴らす。実物は、糸が切れるとペダルが戻り「ガシャン」という機械の音がする(P2/README「実物に合わせて決めたこと」2)。それに近い、短く重なった金属的な音にする。例:`triangle` の 600Hz 40ms(0ms から)、300Hz 120ms(10ms から)、250Hz 200ms(30ms から)を重ね、gain はそれぞれ 0.3 以下。250〜2000Hz、gain 0.5 以下の決まりを守る。

## テスト(先に書く)

1. `setPedal` は 0〜100 に丸める(-5 → 0、130 → 100)。
2. `speedOf`:pedal 0 で 0、pedal 50 で maxSpeed の半分。
3. `tensionOf`:pedal・progress・noise を決めた値で、式どおりの値になる。progress は 0〜1 に丸める。
4. `stepNoise`:1000回進めても noise が -noiseAmp〜+noiseAmp の中。1回の変化が上限以内。同じ種なら同じ結果。
5. **安全なペダルの保証**:初級(30〜70)・中級(38〜62)・上級(44〜56)のそれぞれで、pedal 40、progress 0・0.5・1、noise -2・0・+2 のすべての組み合わせで、`zoneOf` が 'ok'。
6. `zoneOf`:範囲の境目(min ちょうど・max ちょうど)は 'ok'。
7. `SOUNDS.stop` が既存の決まり(周波数・gain・長さ)を満たす(既存の audio テスト1で確かめられるなら、それでよい)。
