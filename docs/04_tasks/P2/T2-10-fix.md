## 5. ドラムの上と下の端(管理者の指摘)

- いまは、上と下の両方に円盤の面(楕円の全体)が描かれている。
- 直し方:**上の端は、楕円の上半分の弧だけ**を描く(胴の上の縁が山なりになる。面は見せない)。**下の端は、楕円の面の全体**(灰色の金属の円盤と放射状の腕)を描く。胴の長方形は、上は楕円の中心の高さから、下は下の楕円の中心の高さまで。
- 放射状の腕は、下の円盤にだけ描き、`drumAngle` で回す(今の式のまま)。
- テスト:`ellipse` で全体を塗るのは下の端の1回だけ。上の端は、弧(`ellipse` の角度 π〜2π、または `arc`)を `stroke` か、胴と同じ色で塗る。

## 6. 結び目とピンも、ドラムと一緒に回る(管理者の指摘)

- いまは、ピンの横木と結び目が、ドラムの左の縁に止まったまま。ピンは実物ではドラムに付いていて、ドラムと一緒に回る。
- 直し方:
  - ピンの横木(縦の棒)・ピン・結び目の束は、ドラムの表面の**同じ1つの角度** `θpin = drumAngle + PIN_ANGLE0` にあるものとして描く。正面から見た x は `中心 + 半径 × sin θpin`、幅と大きさは `cos θpin` 倍。**`cos θpin ≤ 0`(裏側)のときは描かない。**
  - 帯の端を結ぶとき('cutting')は、結び目が見えるように、**ドラムがゆっくり回って、ピンが正面の少し左(`sin θpin = −0.5` 前後)に来てから**結ぶ演出を始める(回る時間 0.6〜1 秒、動き出しと止まりをなめらかに)。
  - 帯の結び目の輪の演出(T2-08 追加修正)は、そのピンの位置で描く。
- テスト:
  - `drumAngle` を変えると、結び目の束の x が変わる。`cos θpin ≤ 0` の角度では、結び目もピンも描かれない。
  - controller:'cutting' に入ると、`drumAngle` が動いて、ピンが正面の左側(`sin θpin < 0` かつ `cos θpin > 0`)に来てから、結ぶ演出が始まる。

## 7. 回り方のなめらかさ(イージング。管理者の指摘)

- いまは、ペダルの速さがそのまま回る速さになり、踏んだ瞬間に最高の速さで回り、止めた瞬間に止まる。
- 直し方:
  - 回る速さ(角速度)は、ペダルの速さから決まる目標の値へ、**なめらかに近づける**(重いドラムの手応え)。近づけ方:`ω += (目標 − ω) × min(1, dtMs / DRUM_EASE_MS)`。`DRUM_EASE_MS` は、速くなるとき 600、遅くなるとき 400(`params.ts`)。
  - 糸が切れたとき(機械が止まる)だけは、`DRUM_STOP_MS = 250` で急に止める。
  - 桟・帯の上の筋・ピン・結び目・下の円盤の腕は、すべて同じ `drumAngle` で動く。円筒の上の点なので、正面の中央では速く、左右の端では遅く見える(`sin` の式でそうなる)。
- テスト(controller):ペダルを 0 から 100 にした直後の1フレームでは、角速度が目標の半分より小さい。0.6 秒ほどで目標の 9 割以上になる。糸が切れると 0.25 秒ほどで 0 になる。
