## 作成・変更するファイル

`src/games/winding/panel.ts`、`src/games/winding/panel.test.ts`、`src/styles/base.css`(末尾に「/* winding */」の節を追加。既存の行は変えない)

## 型

```ts
export interface WindingPanel {
  update(s: WindingState): void;
  destroy(): void;
}
export function createWindingPanel(parent: HTMLElement, opts: {
  terms: { t(k: string): string };
  range: { min: number; max: number };
  onAction: (a: WindingAction) => void;
}): WindingPanel;
```

メッセージは GameFrame の message 欄を使う(controller が書く)。この部品はメッセージ欄を作らない。

## 区画(上から)

1. **帯の番号と長さ**:「帯 3 / 5」と、今の帯の巻いた割合(例「巻いた長さ 45%」)。
2. **張りのメーター**:`createTensionMeter`(label は `terms.t('tension')`)。
3. **ペダル**:`createPedalControl`(label は `terms.t('pedal')`)。onChange で `{ type: 'setPedal', value }`。phase が 'winding' のときだけ押せる。
4. **ボタン**(64px 以上):
   - 'ready':「巻き始める」(主ボタン)→ `start`。
   - 'cutting':「帯の端を結ぶ」(主ボタン)→ `cut`。
   - それ以外は、ボタンを出さない(場所は空けたままにして、配置がずれないようにする)。

## 配置

- 横長(1180×820・960×720):操作欄の中で、ペダルと張りのメーターを横に並べてよい。4区画すべてがスクロールなしで見えること(1180×820 は必須、960×720 は道具のボタンが常に見えること)。
- 縦長(412×915):操作欄の中だけ縦にスクロールしてよい。ペダル(横木)の溝の高さ 240px 以上を保つ。

## テスト(jsdom、先に書く)

1. 'ready' で「巻き始める」があり、押すと `start`。
2. 'cutting' で「帯の端を結ぶ」があり、押すと `cut`。
3. 'winding' 以外では、ペダルが押せない(`setEnabled(false)`)。
4. 「帯 2 / 5」の文字が current と sections に従う。
5. ペダルを動かすと `setPedal` が渡る。
6. destroy で DOM から消える。
