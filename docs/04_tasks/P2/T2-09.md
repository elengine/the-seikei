## A. 張りが自然に動く(T2-09a)

1. **適正な範囲を、難易度とお題ごとに変える。** 範囲は「中心」と「幅」で決める。中心は、お題を始めるときに乱数(State の種)で決める。

   | params | 初級 | 中級 | 上級 |
   |---|---|---|---|
   | 幅(`RANGE_WIDTH`) | 30 | 18 | 10 |
   | 中心の範囲(`RANGE_CENTER_MIN`〜`MAX`) | 45〜55 | 40〜60 | 35〜65 |

   範囲は State に持つ(`range: { min, max }`)。操作欄のメーターは、State の範囲を表示する(今は params の固定値)。
2. **張りの流れ(ドリフト)。** 張り = 基準 + ペダルによる上昇 + **流れ** + ぶれ。
   - 流れは、帯を巻いているあいだ、ゆっくり一方向に動き、ときどき向きが変わる(コーンの糸が減って張りが変わる様子)。1秒あたりの動きの上限 `DRIFT_PER_SEC`(初級 0.6・中級 1.0・上級 1.6)、向きが変わる確率(1秒あたり `DRIFT_TURN_RATE` 0.15)、流れの大きさの上限 ±`DRIFT_MAX`(初級 8・中級 12・上級 16)。
   - これまでの「progress による +4」はやめて、この流れに置き換える。
3. **引っかかり。** 1秒あたり `SNAG_RATE`(初級 0.02・中級 0.04・上級 0.06)の確率で、張りが急に `SNAG_SIZE`(初級 6・中級 9・上級 12)上がり、2秒かけて元に戻る。引っかかりが起きたら、メッセージ「糸が引っかかりました。張りに注意してください」を出す(すぐに切り替える)。
4. **ぶれ**(今の noise)は、初級 ±1・中級 ±1.5・上級 ±2。
5. 張りの計算は、これまでどおり `core/mechanics/pedal.ts` に置く(ビーミングでも使うため)。流れ・引っかかりの状態は `PedalState` に足す。すべて純粋関数で、乱数は State の種から。

## B. 目標の時間(T2-09a)

- 時間の制限は付けない(FR-G2-07)。そのかわり、**星3の条件に「目標の時間内に巻き終える」を加える。**
- 帯1本あたりの目標の時間 `TARGET_SEC_PER_SECTION`:初級 30 秒・中級 26 秒・上級 22 秒。全体の目標 = 1本あたり × 帯の数。数えるのは巻いていた時間と止まっていた時間の合計(糸切れを直している時間も含む。帯の端を結ぶ演出と、裏に回っていた時間は含まない)。
- 星:
  - 星3:適正な張りの割合の平均が 0.8 以上 **かつ** 目標の時間内。
  - 星2:平均が 0.6 以上(時間は問わない)。
  - 星1:それ以外。
- 結果の成績欄に「巻いた時間 1分20秒(目標 1分30秒)」を足す。
- 操作欄の「帯 1 / 3 巻いた長さ 45%」の横に、経過時間を「0:42 / 1:30」の形で出す(20px 以上。縦長で2行になるなら改行してよいが、行数が変わって部品がぶれないようにする)。

## C. 複数の糸切れ(T2-09b)

1. **切れる本数。** 張りが範囲の上を外れて切れたとき、切れる本数 = `1 + floor((張り − 上限) / BREAK_EXTRA_STEP)`、最大 `BREAK_MAX_THREADS`(3)。`BREAK_EXTRA_STEP` は初級 12・中級 9・上級 6。どの糸が切れるかは乱数(重ならない)。
2. **つなぎ方。** 切れた糸それぞれの「クリール側の端」と「ドラム側の端」を、**同じ糸どうし**でつなぐ。
   - 1手目:切れた糸の端(どちら側でもよい)を押す。その端に藍の丸印。
   - 2手目:同じ糸の反対側の端を押すと、その糸がつながる(効果音 `knot`)。
   - 2手目に**別の切れた糸の端**を押したら、「その端は別の糸です」と出し、1手目からやり直し(`mismatch` として数える)。
   - 切れていない糸を押したら、今までどおり「その糸は切れていません」(`wrongThread`)。
   - すべてつながったら、機械が動ける状態に戻る(ペダルは 0 のまま)。残りの本数をメッセージで出す(「あと 2 本です」)。
3. **`core/mechanics/breakage.ts` の型を変える:**

   ```ts
   export type BreakState =
     | { kind: 'running'; sinceCheckMs: number }
     | { kind: 'broken'; threads: number[]; tied: number[]; first: { thread: number; side: 'creel' | 'drum' } | null };

   export function tapEnd(s: BreakState, thread: number, side: 'creel' | 'drum'):
     { state: BreakState; result: 'first' | 'tiedOne' | 'tiedAll' | 'mismatch' | 'wrongThread' | 'ignored' };
   ```

   `stepBreak` は、切れたときに本数を決めて `threads` に入れる(`BreakParams` に `extraStep` と `maxThreads` を足す)。途中保存の形(`isValidResume`)も新しい形に合わせる。
4. 成績:`mismatch` は「違う端を結ぼうとした回数」として数え、結果の成績欄に出す(星には影響させない。FR-G1-05 と同じ考え)。
5. 盤面:切れた糸すべてを、今の難易度の見せ方で描く。つないだ糸は、ふつうの糸に戻す。

## テスト(先に書く)

- `pedal.test.ts`:
  - 同じ種と同じ操作なら、同じ張りの動きになる。
  - 流れの大きさが ±`DRIFT_MAX` を超えない。
  - **「置いておくだけではクリアできない」ことの確認:** どの難易度でも、ペダルをお題の最初に範囲の中心に合わせて動かさないと、60秒のうちに範囲から外れる時間がある(種をいくつか試す)。
  - **「調整すればクリアできる」ことの確認:** 上級でも、張りを見て毎秒ペダルを合わせ直す簡単なやり方(テストの中で書く)で、適正の割合が 0.8 以上になる(種をいくつか試す)。
- `logic.test.ts`:範囲の中心が、難易度ごとの範囲の中に入る。目標の時間内なら星3、超えると星2。糸切れを直している時間も時間に含まれる。
- `breakage.test.ts`:張りの外れ方で本数が 1〜3 になる。同じ糸の両端で `tiedOne`、最後の1本で `tiedAll`。別の切れた糸の端で `mismatch`、1手目がやり直しになる。切れていない糸で `wrongThread`。どちら側から押してもつながる。
- `controller.test.ts`:引っかかりのメッセージが出る。「あと N 本です」が出る。成績欄に時間と「違う端を結ぼうとした回数」が出る。
