## 決まり

- 「遊び方」(右上の「?」)を押して遊び方が開いたら、そのゲームの rAF のループを止める(**一時停止**)。止めているあいだは、張り・巻き量・経過時間・制限時間・アニメーション(糸割りの巻いている回、ドラム設定の試し巻き)が進まない。
- 遊び方を閉じたら(「始める」でも「×」でも。`showTutorial` の Promise が解決したら)、**自動で再開**する。ペダル・レバーの位置は、開く前のまま(裏に回ったときのようにペダルを 0 にはしない)。
- 再開した最初のフレームで、止めていた時間を経過時間に足さない(前の時刻を、再開した時刻で置き直す)。
- 遊び方を開いたまま画面を離れた(unmount)ときも、ループと購読がすべて解除される(今の決まりのまま)。
- 裏に回ったとき(`visibilitychange`)の今の動き(ペダルを 0 にして止める)は変えない。遊び方を開いたまま裏に回り、戻ってきたときは、遊び方を閉じるまで再開しない。
- クリール立ては、時間で進むものが無いので変えない。

## テスト(先に書く。各ゲームの controller.test.ts)

- 巻いている途中で「遊び方」を押すと、偽の rAF で 5 秒進めても、経過時間・巻き量(糸割りは巻いている回の進み)が変わらない。
- 遊び方を閉じると、ペダル・レバーの位置はそのままで、また進み始める。閉じた直後の1フレームで、止めていた 5 秒が経過時間に足されない。
- 遊び方を開いたまま unmount すると、rAF が止まる。
