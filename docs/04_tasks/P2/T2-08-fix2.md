## 1. 巻いている途中の帯の区画で、胴の桟が消える(不具合)

- 確かめたこと:帯を巻き始めると、その区画の木の桟が描かれず、薄い灰色の面だけになる(ドラムに穴が開いたように見える)。
- 原因:`renderer.parts.ts` の桟を描くループが、巻き始めた区画(`i === s.current && len > 0`)を飛ばしている。その上に縞を `globalAlpha` 0.15〜で重ねるので、下には何も無い。
- 直し方:**巻き終えていない区画(今の帯を含む)は、必ず桟を描き、その上に縞を重ねる。** 桟を飛ばしてよいのは、巻き終えた区画(`i < s.current` または `done`)だけ。
- テスト(renderer.test.ts):`phase 'winding'`・`current 0`・`lengths[0]` が帯の長さの 10% のとき、今の帯の区画の中に、桟の色(`COLORS.wood`)の `fillRect` がある。しかも、それが縞の `fillRect` より先に呼ばれている。

## 2. 960×720 で操作欄が横に 4px あふれる(不具合)

- 確かめたこと:960×720・帯を巻き終えた状態で、操作欄の `clientWidth` 309 に対して `scrollWidth` 313。はみ出しているのは `.meter__band`(313px)。
- 原因:`.meter__band` は `max-width: 100%` だが、`box-sizing` が `content-box` なので、左右の枠線 2px ずつが足されて 4px はみ出す。
- 直し方:`.meter__band` に `box-sizing: border-box` を付ける(ほかの部品は変えない)。
- テスト(tokens.test.ts などの base.css を読むテスト):`.meter__band` の規則に `box-sizing: border-box` がある。

## 3. 巻いた帯の縞が、太い帯1本ずつにしか見えない

- 確かめたこと:初級(柄 `p-pin-kon`)で帯を巻き終えると、区画が紺一色の上に、白い太い帯が1本だけになる。T2-08 追加修正a の仕様「柄の並びの色を、区画の高さの中で上から順に**繰り返す**」のうち、繰り返しが1回だけになっている。
- 直し方:柄の並びを、区画の高さの中で**繰り返す**。縞1本の高さを論理座標で `STRIPE_H = 6` 前後(`params.ts` に置く)にし、区画の高さを満たすまで並びを繰り返す。
- テスト:帯を巻き終えた区画の縞の `fillRect` の数が、柄の並びの色の数より多い。縞1本の高さ(論理座標)が `STRIPE_H` 以下。

## 4. 巻き終えた帯の結び目が、帯の色に埋もれて見えない

- 確かめたこと:紺の帯の左の端の結び目の束が、紺の上に紺で描かれ、拡大してもほとんど見えない。管理者の指摘「帯の端を結んでも絵があまり変わらない」が、まだ残っている。
- 直し方:結び目の束は、**墨色(`COLORS.sumi`)の輪郭線と、生成り(`COLORS.kinari`)の縁取り**を付けて描き、帯の色に関係なく見分けられるようにする。大きさは、区画の左の縁(ピンの横木)に少し重なる程度(論理座標で幅 24 以上)。
- テスト:巻き終えた区画の結び目で、`COLORS.sumi` の `stroke` がある。

## 5. 遊び方の1ページ目の絵が、軸が横のドラムのまま

- 確かめたこと:遊び方の1ページ目の略図は、ドラムの軸が横(円盤が左右、桟が縦)のまま。盤面の絵(T2-08 追加修正a で軸を縦に)と合わない。
- 直し方:`tutorial.ts` の `drawDrum` と1ページ目の絵を、盤面と同じ向きにする(円盤は上と下、桟は縦長の板を左右に並べる、巻いた帯は一番上の区画に横の縞)。
- テスト(tutorial.test.ts):1ページ目の絵で、ドラムの円盤(`ellipse` または横長の `fillRect`)が上と下にある。

## 6. 白っぽい色のコーンが、背景に溶けて見えにくい(改善。管理者の指摘)

- 出どころ:管理者の指摘(2026-09-30、会話、Fold 8)「クリールの糸が白っぽい色だと、背景と同化して見づらい」。
- 原因:盤面のクリールのコーン(`renderer.ts` の `drawCreel`)は、糸の色で塗るだけで、輪郭線が無い。白・生成りに近い色は、背景(生成り)と見分けにくい。
- 直し方:コーンに、**墨の薄い色(`COLORS.sumiSub`)の輪郭線**を付ける(線の太さは画面上 1.5px 以上。`fontPx` で決める)。すべての色のコーンに付ける(クリール立ての盤面と同じ考え)。
- テスト(renderer.test.ts):白(`#FFFFFF` に近い色)の糸のお題で、コーンの形を描いたあとに `COLORS.sumiSub` の `stroke` がある。
