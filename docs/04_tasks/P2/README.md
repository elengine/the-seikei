## 設計の補足(P2 で決めたこと)

### 画面の文言(大人向け。`00_rules.md` の決まり)

03 に書かれた文言は、子ども向けの書き方が混じっているので、次のとおりに読み替える。

| 03 の書き方 | P2 で使う文言 |
|---|---|
| 巻きはじめる | 巻き始める |
| 糸が切れました。切れた糸をさがして、つないでください | 糸が切れました。切れた糸を探して、つないでください |
| その糸はだいじょうぶです | その糸は切れていません |
| ちょうどよい(張りのメーター) | 適正 |
| やさしい / ふつう / むずかしい | 初級 / 中級 / 上級 |
| 帯を切って留める | 帯の端を結ぶ(実物に合わせた。下の「実物に合わせて決めたこと」3) |
| 「3 / 6 本目の帯」 | 「帯 3 / 6」 |

整経の用語(ペダル・ランプ・ドラム・帯・張り)は `terms.t()` で出す。

### 時間の進め方(iPad を含む全端末)

- 描画側(controller)が `requestAnimationFrame` で `{ type: 'tick', dtMs }` を送る。
- **1回の tick の `dtMs` は 100ms を上限にする**(logic 側で丸める)。Safari は、アプリが裏に回ると `requestAnimationFrame` を止め、戻ったときに大きな時間差が出るため。
- ページが裏に回ったら(`visibilitychange` の hidden)、controller は tick を止め、**ペダルを 0 にする**(戻ったときに機械が勝手に動かないように)。

### ペダルと張りの計算(`params` の初期値。T2-01)

- `speed = pedal / 100 × MAX_SPEED`(pedal 0 で停止)。
- `tension = TENSION_BASE + TENSION_PER_PEDAL × pedal + YARN_DRIFT × progress + noise`
  - 初期値:`TENSION_BASE = 30`、`TENSION_PER_PEDAL = 0.4`、`YARN_DRIFT = 4`(progress 0→1 で最大 +4)、noise は ±`NOISE_AMP = 2` の範囲でゆっくり動く。
- 適正範囲:初級 30〜70、中級 38〜62、上級 44〜56(03 のとおり)。
- **「ゆっくり踏めば必ず適正範囲に入る」の保証**:難易度ごとに `SAFE_PEDAL`(初級 40・中級 40・上級 40)を決め、pedal = SAFE_PEDAL なら、progress 0〜1・noise の最小〜最大のどの組み合わせでも適正範囲に入ることをテストで確かめる。上の初期値なら、pedal 40 で tension は 44〜52。
- 1本の帯の長さ:`SECTION_LENGTH` は、pedal 50 の速さで 20 秒で巻き終わる長さ(03 のとおり)。

### 糸切れ(T2-02)

- 判定は `BREAK_CHECK_MS = 500` ごと。適正範囲の上を外れたときだけ切れうる。確率は `BREAK_RATE × (tension − 上限)`(1回の判定あたり、上限 0.5)。`BREAK_RATE` は初級 0.01・中級 0.02・上級 0.04。適正範囲の中と下では切れない。
- 盤面に描く糸は、帯1本につき `THREAD_COUNT = 8` 本(実際の本数ではなく、見た目の代表)。切れる糸は乱数で1本選ぶ。
- 糸継ぎは2手:(1) クリール側の切れ端、(2) ドラム側の切れ端。1手目の後に別の糸を押したら1手目からやり直し。違う糸を押したら「その糸は切れていません」と出し、回数だけ数える(減点しない)。
- **糸が切れた瞬間に、ペダルを 0 に戻す**(実物に合わせた)。結んだあとも 0 のまま(再開はもう一度ペダルを踏む)。

### 帯の出来と採点

- 帯ごとの出来 = 巻いていた時間(speed > 0)のうち、適正範囲に入っていた時間の割合(0〜1)。巻いていない時間(止まっている・糸切れ中)は数えない。
- 星:全帯の平均が 0.8 以上で3、0.6 以上で2、それ未満で1(03 のとおり)。
- 結果の成績欄(summary):「適正な張りで巻いた割合 85%」「糸切れ 2回」「違う糸を押した回数 1回」。
- 成績は records(id = `winding`)。難易度ごとの星は `best['level:<1|2|3>']`。
- 図鑑に登録する柄は無い(`unlockedPatternIds: []`)。

### 難易度の一覧(お題一覧に当たる画面)

- 「初級」「中級」「上級」の3つの大きなボタン。ボタンの中は「初級」「帯 3本」と、クリア済みなら星。
- 選べるのは、クリア済みの難易度と、最初の未クリアの難易度まで(クリール立てと同じ)。
- 単独で遊ぶときの柄:初級 `p-pin-kon`、中級 `p-chalk-char`、上級 `p-alt-kon`(糸の色を描くのに使う)。仕事モードでは `job.patternId`・`job.sections`・`job.difficulty` を使う。

### 途中保存と再開

- 状態(State)をそのまま保存する。再開したときは、**ペダルを 0 にして**始める(糸切れ中なら糸切れ中のまま)。

### iPad(Safari)で気をつけること

- ペダル(横木)を指で動かしている間、画面がスクロールしたり戻る操作が起きたりしないように、ペダルの部品には `touch-action: none` を付け、`setPointerCapture` を使う(T2-03)。
- Canvas の文字や吹き出しの位置は、画面上の大きさ(`clientWidth`)で計算する(T1-10 追加修正4 の教訓)。
- 精細さ2倍(devicePixelRatio 2)と、縦横の回転を、ブラウザ確認に含める。

## 実物に合わせて決めたこと(2026-09-30 管理者の回答と写真)

出どころ:管理者の回答(2026-09-30、会話)と、管理者が見せた実物の写真2枚(クリールから来た帯がピンの並んだレールを通る所、ドラムに巻いた帯の端の結び目)。写真はリポジトリに入れない(公開されるため)。

1. **ペダルは「足踏みの横木」**:実物は、ドラムの下にある横長の木製のフットバーを踏み下げる量で速さを変える。画面でも、操作欄のペダルを**横長の木の棒**の形にし、**下に押し下げるほど速い**(一番上が 0、一番下が 100)。指を離しても位置を保つ。高齢の方でも操作しやすいよう、横に「踏み込む」(+10)「戻す」(-10)のボタンも置く(確認役の判断)。
2. **糸が切れた瞬間にペダルが 0 に戻る**:実物は、糸が切れたときにペダルが戻り、「ガシャン」という機械の音がする。画面でも、切れた瞬間にペダルを 0 にし、機械の止まる音(効果音 `stop`、T2-01)を鳴らす。結んだあとは 0 のまま(もう一度踏んで再開)。
3. **帯の終わりは「端を軽く結ぶ」**:実物は、帯の終わりの糸の端を、ほどけるように軽く結んで、ドラムの上に留めておく。次の帯は、開始の位置をずらして、前の帯のすぐ隣にきれいにつながるように巻く。画面では:
   - ボタンの文言は「帯の端を結ぶ」(03 の「帯を切って留める」の代わり)。押すと、帯の端が小さな輪の束(結び目)になってドラムの上に残る演出(1秒)をしてから、台が隣の区画へずれる。
   - 巻き終えた帯は、それぞれの区画の上に結び目の束が1つずつ並ぶ(写真のように、ドラムの上に結び目が横一列に並ぶ)。
4. **ドラムのピン**:写真の、灰みの緑の横木に並んだ鋼のピンは、**帯の巻き始めに、束ねた糸の端を引っ掛けるためのもの**(管理者の説明、2026-09-30)。ピンの横木はドラムの胴に付いていて、帯ごとに1本のピンに、その帯の糸の端の束を引っ掛けてから巻き始める。画面では、各帯の巻き始め(「巻き始める」と、次の帯に移ったとき)に、糸の端の束がピンに掛かった形を描く(T2-05)。
