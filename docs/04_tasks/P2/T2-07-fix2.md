## 1. 切れた糸をつなぐとき、押す位置が糸とずれる(不具合)

- 管理者の指摘:「画面の下の方の糸はだいたい合っているが、上の方の糸は、実際の位置より下を押さないと反応しない」。
- 原因:糸を描く位置と、当たりを調べる位置を、別々の計算で決めている。
  - `renderer.ts` の `coneY`:`CREEL_AREA.y + 60` 〜 `CREEL_AREA.y + CREEL_AREA.h − 60`(論理 150〜630)に並べて描く。
  - `geometry.ts` の `endPoint`:`END_Y_TOP = 300` 〜 `END_Y_BOTTOM = 620` に並べて当たりを調べる。
  - 上の糸ほど、描いた位置と当たりの位置が離れる(1本目は 150 と 300)。
- 直し方:糸の縦の位置を決める関数を `geometry.ts` に1つだけ置く(例:`threadY(thread, threadCount)`)。`endPoint` も `renderer.ts` も、これを使う。`renderer.ts` の `coneY` は消す(座標の計算は geometry.ts だけで行う決まり)。
- テスト:
  - `geometry.test.ts`:すべての糸で、`endPoint(t, 'creel').y` と `endPoint(t, 'drum').y` が `threadY(t)` と同じ。
  - `renderer.test.ts`:'broken' のとき、切れた糸の朱の線の y(論理座標)が、その糸の `endPoint` の y と同じ。

## 2. メッセージが1行と2行を行き来して、下の部品が上下にぶれる(不具合)

- 管理者の指摘:「『適正な張りです』は1行だが、張りが強すぎると2行のメッセージになる。適正と強すぎのちょうど境目では、1行と2行が高速に入れ替わり、下の部品が上下にぶれる」。
- 原因:(a) メッセージ欄の高さが、文の行数で変わる。縦長の画面では、T2-07 追加修正b で `min-height: 0` にしている。(b) 張りが境目の近くで細かく動くたびに、メッセージが入れ替わる。
- 直し方(両方とも行う):
  - (a) ドラム巻きのメッセージ欄は、**いつも2行ぶんの高さ**を取る(`min-height: calc(2 * 1.3em)` のように、行の高さの2倍。縦長の画面も同じ)。1行の文でも、下の部品の位置が変わらない。
  - (b) 張りのメッセージ(適正・強すぎ・弱め)は、**新しい状態が 0.5 秒続いてから**切り替える。数値は `params.ts` に `MESSAGE_HOLD_MS = 500` として置く。時刻は requestAnimationFrame の時刻を使う。糸が切れた・帯を巻き終えたなどのメッセージは、すぐに切り替える。
  - あわせて、「張りが強すぎます。ペダルを戻してください」が、1180×820 と 412×915 で2行以内に収まることを確かめる。
- テスト(`controller.test.ts`):偽の rAF で、張りが適正と強すぎを 100ms ごとに行き来するように進めても、メッセージの文が変わらない。強すぎが 500ms 続くと、強すぎのメッセージになる。
