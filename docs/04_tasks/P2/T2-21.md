# T2-21 ドラム巻き:制限時間の計算を直す(二重に足していた 5 秒・ペダルの 1.5 秒をやめる・スパイク 1 秒)、帯留めを左から 30% で止める

- 目的:管理者の実機確認(2026-10-08、Fold 8、会話)「揺れやスパイクの感じは悪くない。制限時間が長すぎる」。確認役が調べたら、計算に誤りがあった。

- 進め方:1つのコミット。テストを先に書いて RED を確認してから直す。**push の前に `npm run check`。`git pull --rebase` のあと、version が main より大きいことを確かめる。**

## 見つかった誤り(確認役)

- `timeLimit.ts` の `bandTargetMs` が、帯ごとに 1.5 秒(ペダル)+ 3.5 秒(ハサミ)を足している。
- そのうえ `logic.ts` の `targetMs` の計算(`+ sections * TIME_PER_SECTION_MS`)で、**帯ごと 5 秒をもう一度**足している(T2-18a の足し方が残った)。レベル1 で約 15 秒、レベル2 で約 25 秒、レベル3 で約 35 秒長い。

## 新しい計算(管理者の決定)

- 1本の帯の目標の時間 = **範囲の真ん中のペダルで巻いた時間** + **ハサミで切って結ぶ 3.5 秒** + **スパイク1回につき 1 秒**。
  - ペダルを動かし始めてから範囲に入るまでの **1.5 秒は足さない**(管理者「巻く時間を範囲の真ん中にしているので不要」)。
  - スパイクの分は、糸が切れるまでの猶予(`SPIKE_GRACE_MS` 2 秒)とは別の数 `TIME_PER_SPIKE_MS = 1000` を `params.ts` に置いて使う(猶予の 2 秒は変えない)。
- 制限時間 = 全部の帯の目標の時間の合計(**`TIME_PER_SECTION_MS` の足し算はやめる**。使わなくなった `TIME_PEDAL_START_MS`・`TIME_PER_SECTION_MS`・`TIME_ANCHOR` は消す)。
- 例(レベル1、帯 3 本、範囲の真ん中 50、スパイク 0 回):12 秒 × 3 + 3.5 秒 × 3 = 46.5 秒。

## 帯留めの止まる位置

- 管理者「巻き終わったときの帯(帯留め)の位置は、左から 40% ではなく **左から 30%**」。T2-19b の止める位置の割合を 0.4 → **0.3** にする(`params.ts` に割合を置く。手前側・逆回りしない、は今のまま)。

## テスト(先に書く)

- 制限時間 = Σ(帯の長さ ÷ 範囲の真ん中の速さ)+ 3.5 秒 × 帯の数 + 1 秒 × スパイクの回数(二重に足していない)。レベル1・真ん中 50・スパイク 0 で 46.5 秒。
- 範囲の真ん中のペダルで巻き、スパイクのたびに 10 下げて戻す遊び方で、制限時間に間に合う(種 20 通り。ハサミの動きの時間も含めて)。
- 100% で止まったあとの竿の x が「左の端 + 幅 × 0.3」(差 1 以下)、手前側。
