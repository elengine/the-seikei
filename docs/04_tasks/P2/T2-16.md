## T2-16a:張りと適正の範囲

管理者の言葉:「テンション確認バーの動きが分かりづらい。適正エリアの幅はレベルごとに固定(レベルが高いほど狭い)。適正エリアの中心位置は確認バーの中心と合わせる。適正エリアは、帯を結んで次の帯が始まるタイミングで変わることがある。ドラムが動いているあいだは動かない。操作バーを動かさなくても、テンションは上がったり下がったりする。糸が引っかかった感じを出すため、テンションが急に上がることもあり、その場合は徐々に戻す」。

- **適正の範囲の幅**:レベルごとに固定(`RANGE_WIDTH`:レベル1 が広く、3 が狭い)。巻いているあいだに幅を変えない(今の「息をするように幅が変わる」動きをやめる)。
- **適正の範囲の位置**:最初の帯は、メーターの**中央**。**帯が変わるとき(帯の端を結んで次の帯が始まるとき)だけ**、位置が変わることがある(`RANGE_SHIFT_ON_SECTION`:レベル1 は変えない、2 は ±10 まで、3 は ±15 まで。乱数は State の種から)。巻いているあいだは動かさない(今の「範囲が動く」動きをやめる)。ペダルで必ず範囲に届く決まり(T2-11)は守る。
- **張りの揺れ**:ペダルを動かさなくても、張りがゆっくり上下する(今のぶれと流れ。レベルが上がるほど大きい)。
- **引っかかり**:ときどき張りが**急に上がり**(0.2 秒ほどで +15〜25)、そのあと**1〜2 秒かけて徐々に戻る**。レベルが上がるほど起きやすい。
- テスト:巻いているあいだ範囲が変わらない/帯が変わると(レベル2・3 で)位置が変わることがある・幅は同じ/ペダル一定でも張りが変わる/引っかかりで急に上がって徐々に戻る/どのレベル・どの位置でも、ペダル 10〜100 で範囲の中心に届く。

## T2-16b:制限時間

- 管理者「制限時間が現実的ではない。適正のテンションが遅すぎて、制限時間内に終わらないことがある。適正の限界値くらいで達成できる時間を制限時間にする」。
- 1本の帯の目標の時間 = 帯の長さ ÷(**適正の範囲の上の端の張りになるペダルの速さ**)× `TIME_MARGIN`(1.1)。全体の目標は、帯ごとの合計(帯ごとに範囲の位置が変わるので、帯が始まるときに計算して足す)。
- テスト:範囲の上の端ちょうどで巻くと、目標の時間の 91% ほどで終わる/範囲の下の端で巻くと目標を超える(下の端では足りないことを示す)/どのレベルでも、範囲の中で巻けば目標の時間内に終わる道がある。

## T2-16c:ハサミで帯の端を結ぶ

- 管理者「『帯の端を結ぶ』ボタンを廃止して、ハサミのアイコンを表示する。ハサミの位置は、ドラム巻きしている位置に応じて上部だったり下部だったりする。上部の場合は下向きのアイコン、下部の場合は上向き。アイコンをドラム巻きしている位置までスワイプすると、糸が切れて帯の端を結ぶ」。
- 帯を巻き終えたら(今の 'cutting' の手前)、「帯の端を結ぶ」ボタンの代わりに、盤面にハサミのアイコン(64px 以上)を出す。
  - いま巻いている帯がドラムの上半分なら、ハサミは筬とドラムのあいだの**上の方**に、**刃が下向き**で出る。下半分なら**下の方**に**刃が上向き**で出る。
  - ハサミを、いま巻いている帯の糸(筬からドラムへ向かう糸の束)の所まで**引っぱる**と、糸が切れて、帯の端を結ぶ演出(今の 'cutting')に進む。外れた所で離すと元の位置に戻る。引っぱるあいだは画面がスクロール・拡大しない(`touch-action: none`)。
  - ハサミは、軽く上下に動く(押せることを示す)。最初のお題では `notify` で「ハサミを糸の所まで引っぱって切ります」を1回出す。
- 座標の変換は `geometry.ts`(ハサミの位置・糸の束の当たり判定)。
- テスト:帯の位置でハサミの位置と向きが変わる/糸の束の上で離すと 'cutting' へ/外れたら戻る/「帯の端を結ぶ」ボタンが無い。
