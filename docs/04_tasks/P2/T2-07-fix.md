## 追加修正a

1. **糸が切れた途中・帯を巻き終えた直後で再開すると、時間が進まない(不具合)。** `controller.ts` は、始めたときの phase が 'ready' か 'winding' のときだけ `startLoop()` を呼ぶ。'broken' や 'cutting' で保存・再開すると、アニメーションが動かず、糸を結んでも巻き直せない。
   - 直し方:'done' 以外なら、どの phase でも `startLoop()` を呼ぶ(tick は reduce 側で 'winding' 以外は何もしないので問題ない)。
   - テスト:'broken' の状態で resume して開き、tapEnd で結んで、ペダルを動かして rAF を進めると、帯の長さが増える。
2. **プレイ画面の「戻る」でホームに戻る。** クリール立て(T1-15)と同じく、難易度の一覧に戻るようにする。T2-07 の仕様書に書き漏らしたもの(確認役の見落とし)。
   - 確認の画面:「難易度の一覧に戻りますか?(途中の状態は保存されます)」、ボタン「一覧に戻る」(右)「やめる」(左)。「一覧に戻る」で状態を保存(`props.onStateChange`)してから、プレイ画面を片付けて一覧を出す。
   - 一覧で、途中の状態がある難易度のボタンに「途中」を出す。押すとその状態から再開する(ペダル 0)。別の難易度を押したときに途中があれば、「途中の難易度があります。新しく始めると、途中の状態は消えます。始めますか?」を出す(「始める」「やめる」)。
   - **resume の渡し方は、T1-15 追加修正の教訓どおりにする**:プレイ画面を開く処理を1つの関数にまとめ、`resume` を明示して渡す(mount の `props.resume` を流用しない)。一覧を開くときに `onStateChange(null)` を送らない。
   - 仕事モード(`mode: 'job'`)は今までどおり `props.onExit()`。
   - テスト:クリール立ての T1-15 と T1-15 追加修正のテスト(戻る → 一覧、「途中」、再開、別の難易度で確認、resume のあとに別の難易度を選ぶとその難易度になる)と同じ形のものを、ドラム巻きにも書く。再開の確かめは、最初の状態と違う状態(例:帯の長さが 0 より大きい)で行う。
3. **時刻を `Date.now()` で直接取っている。** 盤面の揺れ(`timeMs`)と、帯の端を結ぶ演出の時間で使っている(00_rules.md の「時刻は clock を使う」に反する)。
   - 直し方:どちらも `requestAnimationFrame` の時刻(loop の引数 `ms`)を使う。帯の端を結ぶ演出も `setInterval` ではなく、同じ loop の中で進める(経過時間を足していき、1000ms で `cut` を送る)。
   - テスト:偽の rAF で 1000ms 進めると `cut` が送られ、次の帯に進む。unmount の後に進めても何も起きない。
4. **盤面が、状態が変わったときしか描き直されない。** 初級で切れた糸を朱色でゆっくり揺らす表示(T2-05)は、糸切れ中は状態が変わらないので、描き直されず揺れない。
   - 直し方:loop の中で、phase が 'winding'・'broken'・結ぶ演出中のときは、毎フレーム盤面を描く(操作欄の update は状態が変わったときだけでよい)。

## 追加修正b

5. **縦長(412×915)で、ペダルが画面の外に出る。** 縦長では、盤面が枠の高さの 60% を使うが、盤面は横長の形(4:3)なので、上下に大きな空きができる。そのぶん操作欄が狭く、一番大事なペダルが、操作欄をスクロールしないと見えない。
   - 直し方:`gameFrame` の opts に `portraitStageRatio?: number`(縦長のときに盤面が使う高さの割合。無ければ今までどおり 0.6)を足す。ドラム巻きは 0.4 にする。クリール立ては変えない。
   - 確かめ方:412×915 で、操作欄のスクロールなしに、張りのメーターとペダルの横木・「踏み込む」「戻す」が見える(操作欄の `scrollHeight` と `clientHeight`、ペダルの溝の下端の位置を報告する)。盤面(4:3)は、幅いっぱいで欠けずに見える。
   - テスト(`gameParts.test.ts`):`portraitStageRatio: 0.4` を渡すと、縦長で盤面の高さが本体の高さの 40%。渡さないと 60%(今までどおり)。
6. **縦長で、盤面の「帯 1 / 3」の文字が赤ランプに重なる。** 文字は画面 px(20px)、位置は論理座標なので、盤面が小さいと隣のランプに重なる。
   - 直し方:盤面の「帯 N / M」は描かない(操作欄に同じ表示がある)。「停止」は赤ランプの**下**に、ランプの中心にそろえて描く。
   - テスト:盤面に「帯」を含む `fillText` が無い。'broken' のとき「停止」の y がランプの中心の y より大きい(下にある)。
