// id 'winding'、titleTermKey 'game.winding'、phase 'P2'、embeddable true、tutorial は tutorial.ts

## 仕様:controller.ts(プレイ画面)

- `createGameFrame`(題名は `terms.t('game.winding')`、論理 1000×750)。盤面に `drawBoard`、操作欄に `createWindingPanel`。メッセージは `frame.message`。
- **時間**:`requestAnimationFrame` で前のフレームからの経過を測り、`{ type: 'tick', dtMs }` を送る。毎フレーム盤面を描き直し、操作欄を update する。
- **裏に回ったとき**:`visibilitychange` の hidden で、アニメーションを止め、`pausePedal` を送る。visible で再開する(経過時間は測り直す。大きな差を送らない)。
- **タップ**:盤面の `pointerdown` で `fromPx` → `hitEnd`。当たれば `tapEnd`。'broken' 以外のときは何もしない。
- **効果音**:糸が切れた `stop`(機械が止まる音)、1手目 `tap`、結んだ `knot`、違う糸 `gentleNo`、帯の端を結んだ `knot`、全部巻き終えた `fanfare`。
- **帯の端を結ぶ演出**:`cut` を送る前に、1秒かけて今の帯の端が結び目の束に変わる様子を描く(`drawBoard` の `tieProgress` を 0→1)。演出中はボタンを押せない。タイマーは unmount で解除する。
- **メッセージ**(大人向けの文言。`terms.render`):
  - 'ready':「{{pedal}}を踏むと巻き始めます。「巻き始める」を押してください」
  - 'winding':張りが範囲内なら「適正な張りです」、上なら「張りが強すぎます。{{pedal}}を戻してください」、下なら「張りが弱めです」。
  - 'broken':「糸が切れました。切れた糸を探して、つないでください」。1手目の後は「もう一方の切れ端を押してください」。違う糸は「その糸は切れていません」。
  - 'cutting':「帯を巻き終えました。「帯の端を結ぶ」を押してください」
- **途中保存**:操作のたび(tick を除く)と、1秒に1回まで、`props.onStateChange(state)`。
- **done**:ドラムの表面を出来で描き分けて1.5秒見せ、`props.onFinish`(gameId 'winding'、stars は `starsOf`、stats は `{ breaks, wrongTaps, okRate(%) , 'level:<n>': stars }`、unlockedPatternIds `[]`、summary は P2/README の3行)。
- 「戻る」は `props.onExit()`、「遊び方」は `showTutorial`。
- **unmount**:アニメーション(`cancelAnimationFrame`)、タイマー、`visibilitychange`、盤面のリスナー、panel、frame をすべて解除する。

## 仕様:tutorial.ts

3ページ(Canvas の略図。文は大人向け):

1. 「クリールの糸を帯にまとめて、ドラムに巻いていきます」
2. 「{{pedal}}を踏むと巻き始めます。速すぎると張りが強くなり、糸が切れやすくなります」
3. 「糸が切れたら機械が止まります。切れた糸の両端を順に押して、つないでください」

## テスト(controller.test.ts、jsdom、偽の Canvas と偽の rAF)

1. 一覧:記録が無いと初級だけ押せる。初級の星があると中級まで押せる。
2. プレイ:初級で「巻き始める」→ ペダル 40 → rAF を進めて帯を巻き終え、「帯の端を結ぶ」を3回(演出の1秒ずつ、偽のタイマーを進める) → onFinish が1回、stars 3。
3. `visibilitychange` の hidden で、状態のペダルが 0 になり、rAF が止まる。
4. unmount の後に rAF・タイマーが残っていない。
5. resume でペダルが 0 から始まる。
