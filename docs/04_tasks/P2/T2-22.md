## 決まり(確認役が設計した。数値はすべて `params.ts`)

1. **数え始める条件**:**ペダルの位置**(= 張り − 揺れの量 − スパイクの量)が、適正の範囲の**上の端を超えている**あいだ、時間を数える。
   - 理由:揺れはペダルの位置を起点に範囲の幅の半分まで上下し、上がって戻るのに最大 約4秒かかる。張りそのもので数えると、範囲の中にペダルを置いているのに揺れで切れてしまい、「真ん中に置けば外れない」(管理者の裏技)とも、遊ぶ人の感覚とも合わない。**強く踏みすぎたときだけ危なくなる**ようにする。
   - スパイクのあいだ(スパイクの量が 0 より大きいあいだ)は数えない(スパイクは T2-20 の「2秒以内にペダルを 10 下げる」の決まりだけで扱う)。
   - 範囲の下に外れているとき(弱すぎ)は数えない(出来が下がるだけ)。
2. **猶予**:数えた時間が猶予を超えたら、糸が1本切れる(今の糸切れの扱い・つなぎ方と同じ。数えた時間は 0 に戻す)。ペダルの位置が範囲の中(上の端以下)に戻ったら、数えた時間を 0 に戻す。
   - レベルで短くする:`OVER_GRACE_MS` = レベル1 **3000**・レベル2 **2500**・レベル3 **2000**。
   - 糸の種類で変える:今は使われていない `YARN_FEEL` の `breakRateMul` を、猶予の倍率に置き換える(`overGraceMul`:細い糸 `fine` **0.8**、標準 1.0、太い糸 `thick` **1.2**)。
3. **知らせ方**:数えているあいだ、張りのランプの橙の「▲」を**点滅**させる(0.25 秒ごと。色だけに頼らず点滅と記号で)。猶予の残りが 1 秒を切ったら点滅を速く(0.12 秒ごと)。
4. **片付け**:前の「範囲の外にいると確率で切れる」仕組みの使われていない数(`BREAK_RATE`・`breakRate`・`BREAK.rate`・`breakExtraStepDelta` など、どこからも使われていないもの)を消す(使っている所が無いことを `grep` で確かめて、報告に書く)。
5. 遊び方に1文足す:「ペダルを強く踏みすぎたまま(ランプの▲が点滅)にしておくと、糸が切れます」(00_rules)。
6. 制限時間の計算は変えない。

## テスト(先に書く)

- ペダルを範囲の上の端より上に置き続けると、レベル1 で 3 秒、2 で 2.5 秒、3 で 2 秒で切れる。細い糸は 0.8 倍、太い糸は 1.2 倍。
- 猶予の前にペダルを範囲の中に戻すと切れず、数えた時間が 0 に戻る。
- ペダルを範囲の**上の端ちょうど**に置いて揺れで張りが上に外れても、切れない(種 20 通り、30 秒)。
- 範囲の真ん中に置けば切れない(スパイクに正しく反応する遊び方で、種 20 通り)。
- 範囲の下に外れていても切れない。スパイクのあいだは数えない。
- 数えているあいだ、ランプの描き方が点滅になる(時刻で表示・非表示が変わる)。
