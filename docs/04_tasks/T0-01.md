# T0-01 プロジェクトの土台

- 目的:以降のタスクが動く土台(ビルド、テスト、リンター)を作る。
- 関連要件:NFR-M-04、02_architecture 2章・4章
- 前提:T0-00(リポジトリに `docs/`、`public/icons/`、`PROGRESS.json` がある)

## 作成するファイル

`package.json`、`tsconfig.json`、`vite.config.ts`、`vitest.config.ts`、`eslint.config.js`、`index.html`、`.gitignore`、`src/main.ts`、`src/styles/base.css`、`tests/smoke.test.ts`(PROGRESS.json は手順どおり更新のみ)

## 仕様

1. `package.json`
   - `"type": "module"`、`"private": true`、name は `the-seikei`。
   - scripts:
     - `dev`: `vite`
     - `build`: `tsc --noEmit && vite build`
     - `preview`: `vite preview`
     - `test`: `vitest run`
     - `check`: `tsc --noEmit && eslint .`
   - dependencies:`dexie`、`gsap`。devDependencies:00_rules.md の開発用ライブラリすべて。バージョンは現時点の最新安定版を `^` 付きで。
2. `tsconfig.json`:`strict: true`、`noUncheckedIndexedAccess: true`、`target` と `lib` は ES2022 と DOM、`moduleResolution: "bundler"`、`resolveJsonModule: true`、`include` は `src`、`tests`。
3. `vite.config.ts`:`base: '/the-seikei/'`(GitHub Pages のサブパス = リポジトリ名)。PWA の設定は T0-17 で行うので、ここでは入れない。
4. `vitest.config.ts`:`environment: 'jsdom'`、`include: ['src/**/*.test.ts', 'tests/**/*.test.ts']`。
5. `eslint.config.js`(flat config):`@eslint/js` と `typescript-eslint` の推奨設定。加えて、`src/core/**` のファイルに対して `no-restricted-imports` で次のパターンを禁止する:`**/app/**`、`**/games/**`、`**/zukan/**`。`dist`、`node_modules` は無視。
6. `index.html`:`lang="ja"`。`<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1, user-scalable=no, viewport-fit=cover">`。`<meta name="theme-color" content="#4F5B47">`。`<link rel="apple-touch-icon" href="icons/apple-touch-icon.png">`。本文は `<div id="app"></div>` と `src/main.ts` の読み込みのみ。タイトルは「整経ゲーム」。
7. `src/styles/base.css`:背景 `#F7F3E8`、文字色 `#2B2A24`、`html, body` の余白0・高さ100%、`touch-action: manipulation`、`-webkit-user-select: none`、`user-select: none`、`-webkit-touch-callout: none`、`overscroll-behavior: none`。(色は T0-08 で CSS 変数に置き換える)
8. `src/main.ts`:`base.css` を import し、`#app` に「整経ゲーム 準備中」と表示するだけ。
9. `tests/smoke.test.ts`:`1 + 1 === 2` を確かめるだけのテスト。
10. `.gitignore`:`node_modules`、`dist`、`.vite`、`*.log`、`.DS_Store`、`.hermes/`

## 完了条件

- `npm install`、`npm run check`、`npm test`、`npm run build` がすべて成功する。
- `npm run dev` で開いた画面に「整経ゲーム 準備中」が表示される。
- `src/core/sample.ts` に `import '../app/x'` と書くとリンターがエラーを出すことを一度確かめ、そのファイルは消してから完了とする(報告に結果を書く)。
