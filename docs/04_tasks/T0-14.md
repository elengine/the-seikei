## 仕様:settings.ts

```ts
export interface SettingsData {
  playerName: string;
  shopName: string;
  fontScale: FontScale;
  soundOn: boolean;
  volume: number;                                   // 0〜1
  tutorialSeen: Partial<Record<GameId, boolean>>;
}
export const DEFAULT_SETTINGS: SettingsData = {
  playerName: '', shopName: '整経所', fontScale: 'large', soundOn: true, volume: 0.7, tutorialSeen: {},
};
export interface SettingsService {
  get(): SettingsData;                               // 同期的に返す(キャッシュ)
  update(patch: Partial<SettingsData>): Promise<void>;
  onChange(cb: (s: SettingsData) => void): () => void;
}
export async function createSettingsService(repo: Repository, clock: Clock): Promise<SettingsService>;
```

- 保存先は settings コレクションの id `'main'`。data は SettingsData に `_updated: Record<string, string>` を足したもの。
- `update` では、patch に含まれるキーだけ `_updated[キー] = clock.now()` にする。
- 読み込み時、保存データにないキーは DEFAULT_SETTINGS で補う(将来キーが増えても壊れないように)。
- `get()` は `_updated` を含めずに返す。

## 仕様:app/context.ts

```ts
export interface AppContext {
  repo: Repository & RawStore;
  clock: Clock;
  deviceId: string;
  terms: Terms;
  settings: SettingsService;
  audio: AudioPlayer;
  navigate(path: string): void;
}
export async function createAppContext(opts: {
  dbName: string; clock: Clock; navigate: (path: string) => void;
}): Promise<AppContext>;
```

- repo は `createLocalRepository({ dbName, clock })` で作る(deviceId は指定しない。repo が meta から読むか作る)。`deviceId` には `repo.deviceId` を入れる。
- settings の soundOn と volume を audio に反映し、変更時にも追従させる。
- settings の fontScale を `applyFontScale(document.documentElement, …)` で反映し、変更時にも追従させる。

## テスト(settings.test.ts、fake-indexeddb)

1. 初回は DEFAULT_SETTINGS を返す。
2. `update({ shopName: '山田整経' })` 後、作り直したサービスでも '山田整経'。
3. update したキーだけ `_updated` が付く(repo から Rec を直接読んで確かめる)。
4. 保存データに一部のキーしかない場合も、残りは既定値で補われる。
5. onChange が呼ばれる。
