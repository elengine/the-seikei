# T1-15 クリール立て:プレイ画面の「戻る」でお題の一覧に戻る

- 目的:プレイ画面で「戻る」を押すと、いまはホームに戻る。お題の一覧(クリール立ての最初の画面)に戻るようにする。お題の一覧の「戻る」は、今までどおりホームに戻る。
- 関連要件:FR-C-06〜08、03_basic_design 1.2・7、T1-06、T1-10
- 前提:T1-14
- 出どころ:管理者の Fold 8 での実機確認(2026-09-30、会話)。「段階を選んで『戻る』を押すと、クリール立ての最初の画面ではなくホームに戻るのはなぜか」。
- いまの動きになっている理由:全ゲーム共通のゲーム画面(T1-06 の `gameScreen`)が、ゲームの「戻る」を「ゲームを出てホームへ」と扱う作りで、クリール立てのようにお題の一覧を持つゲームの場合を考えていなかった(確認役の見落とし)。

## 変更してよいファイル

`src/games/creel/index.ts`、`src/games/creel/listView.ts`、`src/games/creel/controller.test.ts`、`src/styles/base.css`(creel の節のみ)、`PROGRESS.json`、`docs/progress_log.md`

## 動き

1. **プレイ画面の「戻る」**(お題の一覧から始めたときも、「続きから」で再開したときも同じ):
   - 確認を出す:「お題の一覧に戻りますか?(途中の状態は保存されます)」、ボタン「一覧に戻る」「続ける」(`core/ui` の `confirmDialog`)。
   - 「一覧に戻る」:今の状態を `props.onStateChange(state)` で保存してから、プレイ画面を片付け(`unmount`)、お題の一覧を表示する。
   - 「続ける」:何もしない。
   - 仕事モード(`mode: 'job'`)のときは、今までどおり `props.onExit()`(一覧は出さない)。
   - 実装は `index.ts` で行う。`createController` に渡す props の `onExit` を包んで、上の動きにする(`controller.ts` は変えない)。
2. **お題の一覧**:
   - 途中の状態が保存されているお題には、ボタンの中に「途中」と表示する(星の横)。
   - 「途中」のお題を押すと、保存した状態から再開する。
   - ほかのお題を押したときに途中のお題があれば、確認を出す:「途中のお題があります。新しいお題を始めると、途中の状態は消えます。始めますか?」、ボタン「始める」「やめる」。「始める」なら新しく始める(途中の状態は、新しいお題の状態で上書きされる)。
   - 一覧の「戻る」は、今までどおり `props.onExit()`(ホームへ)。一覧のあいだは `suspend()` が null なので、`gameScreen` は確認を出さずにホームへ戻り、**保存した途中の状態は消さない**。次にクリール立てを開いたときは、`gameScreen` の「前回の続きから始めますか?」が出る。
3. **途中の状態を消さない**:いまは、一覧を開くときに `props.onStateChange(null)` を送って途中の状態を消している(`index.ts` の「お題一覧のあいだは途中保存を消しておく」)。これをやめる。途中の状態が消えるのは、クリアしたとき(`gameScreen` の onFinish)と、「最初から」を選んだとき(`gameScreen`)と、上の「始める」で上書きされたときだけ。
4. `index.ts` は、途中の状態(最後に受け取った状態、または `props.resume`)を覚えておき、一覧に渡す(`createListView` の opts に `savedPuzzleId: string | null` を足す)。`onStateChange` を包んで、プレイ中の状態を覚える。

## テスト(controller.test.ts。先に書いて RED を確認する)

1. お題の一覧から s1 を始め、何か操作してから「戻る」→ 確認で「一覧に戻る」→ お題の一覧が表示され、`props.onExit` は呼ばれない。s1 のボタンに「途中」がある。
2. 1 の後に s1 を押すと、操作した状態から再開する(`suspend()` の状態が同じ)。
3. 途中のお題があるときに別のお題を押すと確認が出て、「やめる」なら一覧のまま、「始める」なら新しいお題が始まる。
4. 一覧を開いても `onStateChange(null)` が呼ばれない(前のテスト「お題一覧では null」の期待値は変える。理由:管理者の指摘で戻り先を変えたため)。
5. 一覧の「戻る」で `props.onExit` が1回呼ばれる。
6. resume で開いたプレイ画面の「戻る」→「一覧に戻る」でも一覧が出て、そのお題に「途中」がある。
7. unmount の後にダイアログやタイマーが残っていない。

`confirmDialog` の答えは、既存のテスト(`gameScreen.test.ts`)と同じく `vi.mock` で決めてよい。
