# T1-03 帯の並びの計算

- 目的:柄とクリールの大きさから「帯の並び」を作り、依頼書の表や判定に使う純粋関数をまとめる。
- 関連要件:FR-G1-01、FR-G1-04、P1/README の設計の補足
- 前提:T1-02

## 作成するファイル

`src/core/domain/stripe.ts`、`src/core/domain/stripe.test.ts`

## 仕様

```ts
// 柄の並び(1リピート)を繰り返して、length 本ぶんの糸の列にする。length 未満で打ち切る
export function expandPlan(plan: StripePlan, length: number): YarnTypeId[];

// 糸の列を、同じ糸が続くところで1つにまとめる(依頼書の表用)
export function toRuns(seq: YarnTypeId[]): StripeRun[];

// 帯の番号 ⇔ クリールの位置(上の段から、各段は左から)
export function indexToCell(i: number, cols: number): { row: number; col: number };
export function cellToIndex(row: number, col: number, cols: number): number;

// お題から、正解の帯の並び(rows*cols 本)を作る
export function answerFor(puzzle: CreelPuzzle, pattern: Pattern): YarnTypeId[];

// 置いた並びと正解を比べ、間違い(違う糸)と空きの帯番号を返す
export function compare(placed: (YarnTypeId | null)[], answer: YarnTypeId[]): { wrong: number[]; empty: number[] };
```

- plan が空、または length が 0 以下なら空の配列を返す。
- `compare` は placed と answer の長さが違えば例外を出す。

## テスト

1. `expandPlan([kon×7, shiro×1], 8)` が kon 7本 + shiro 1本。`length 20` なら2回目の途中(kon 4本)で打ち切られる。
2. `toRuns(expandPlan(…))` で元の並びに戻る(同じ糸が続けば1つにまとまる)。
3. `indexToCell(9, 8)` は `{ row: 1, col: 1 }`、`cellToIndex` と往復して一致する(0〜23 すべて)。
4. `compare` で、違う糸は wrong、null は empty に入り、正しいものはどちらにも入らない。
5. 本物の内容データの5つのお題すべてで、answerFor の長さが rows*cols と一致する。
