## C. バックアップの書き出しで、データの読み出しに失敗したときに記録が残らない

- T1-11c で、書き出しの処理の外側の `try/catch` が外れた。`ctx.repo.exportAll()` などが失敗すると、ログに何も残らず、処理されない Promise の失敗になる。
- 直し方:`onClick` の中身全体を、もう一度 `try/catch` で囲む。外側の catch では `ctx.logger.log('error', 'バックアップの書き出しに失敗: …')` を残す。`share()` の `AbortError`・`NotAllowedError` の扱い(T1-11c)は、今のまま残す。
- テスト:`exportAll` が失敗する偽の repo で「バックアップを書き出す」を押すと、例外が外に出ず、ログに error が1件残る。
