## A. 遊び方の説明文に `{{spindle}}` などがそのまま出る

- 原因:クリール立ての遊び方の2ページ目は「品番の書かれた箱を選び、{{spindle}}に触れると{{cone}}が立ちます」で、`{{…}}` を呼び名(軸・コーン)に置き換える必要がある(T1-10 の仕様書「`{{…}}` は terms.render で置き換える」)。ところが `showTutorial` は、ページの文をそのまま表示していて、どこでも置き換えていない。
- 直し方:
  - `showTutorial` の opts に `renderText?: (text: string) => string` を足す(無ければ文をそのまま出す)。各ページの文は `renderText` を通してから表示する。
  - 呼び出す2か所で、呼び名の置き換えを渡す:`gameScreen.ts`(初回の遊び方)は `ctx.terms.render`、`games/creel/controller.ts`(「遊び方」ボタン)は `deps.terms.render`。
  - 呼び名を設定で変えた場合も、変えた呼び名で表示される(`terms.render` がそうなっている)。
- テスト:
  - `gameParts.test.ts`:`renderText` を渡すと、表示される文が置き換わる。渡さないと、そのまま。
  - `controller.test.ts` か `gameScreen.test.ts`:クリール立ての遊び方の2ページ目の文に `{{` が含まれず、「軸」と「コーン」が含まれる。

## B. 「ヒント」ボタンが、押せないのに理由が分からない

- いまの動き(仕様どおり):「ヒント」は、「確認する」を2回押して、まだ ✕ があるときだけ使える(`canHint`、段階の数値は `params.ts` の `HINT_MIN_CHECKS = 2`)。それまでは押せない(`disabled`)。押せないときは薄い緑の地になるが、理由が書かれていないので、壊れているように見える。
- 直し方(確認役の判断):押せないあいだは、ボタンの文字に条件を出す。
  - `checks < HINT_MIN_CHECKS` のとき:「ヒント(あと N 回)」。N は `HINT_MIN_CHECKS − checks`(「確認する」をあと何回押すと使えるか)。
  - 使えるとき:「ヒント」。
  - 完成したあと、または ✕ が無いとき(`checks` は足りているが使えない):「ヒント」のまま押せない。
  - 文字は今までと同じ大きさ(20px 以上)。ボタンの高さは変えない。
- テスト(`panel.test.ts`):最初は「ヒント(あと 2 回)」で押せない。1回確認して ✕ があると「ヒント(あと 1 回)」。2回で「ヒント」になり押せる。

## C. 遊び方に、ヒントの説明のページを足す

- クリール立ての遊び方(`src/games/creel/tutorial.ts`)に、4ページ目を足す。
  - 文:「『確認する』を2回押しても ✕ が残るときは、『ヒント』で1か所を直せます(ヒントを使うと星は1つになります)」
  - 絵:3ページ目の略図(✕ の付いたマス)の横に、「ヒント」と書いたボタンの形を描き、✕ の1つが正しい色のマスに変わる様子(矢印でよい)を描く。
  - 星の決まりは `logic.ts` の `starsOf` のとおり(ヒントを1回でも使うと星1)。文の内容が `starsOf` と食い違わないこと。
- あわせて、`tutorial.ts` の中の直書きの色(`'#B03A2E'` など)を、`core/ui/tokens.ts` の `COLORS` に置き換える(色は tokens の決まり)。
- テスト:クリール立ての遊び方が4ページで、4ページ目の文に「ヒント」と「確認する」が含まれる。`tutorial.ts` に `'#` で始まる色の値が無い(ファイルを読んで確かめるテストでよい)。
