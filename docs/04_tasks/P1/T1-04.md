# T1-04 生地の見本(FabricPreview)

- 目的:帯の並び(経糸)と緯糸の色から、織り上がった生地の見た目を Canvas に描く部品を作る。クリール立て・図鑑・経営で共用する。
- 関連要件:FR-G1-06、03_basic_design 2.5
- 前提:T1-02

## 作成するファイル

`src/core/ui/fabricPreview.ts`、`src/core/ui/fabricPreview.test.ts`

## 仕様

```ts
export interface FabricSpec {
  warp: ColorHex[];     // 経糸の色を左から順に(1リピートぶん)
  weft: ColorHex;       // 緯糸の色
}
type ColorHex = string;

// Canvas(CSS px の座標で描ける ctx)の x, y, w, h の範囲に生地を描く
export function drawFabric(ctx: CanvasRenderingContext2D, spec: FabricSpec, rect: { x: number; y: number; w: number; h: number }, opts?: { threadPx?: number }): void;

// 内容データから FabricSpec を作る
export function fabricSpecFor(pattern: Pattern, content: Content): FabricSpec;
```

- 経糸1本の幅は `threadPx`(既定 3px)。warp を左から右へ繰り返して rect の幅を埋める。
- 平織りに見えるよう、縦 `threadPx` ごとに、経糸と緯糸を市松に交互に描く(経糸の色のマスと緯糸の色のマス)。見本として雰囲気が分かれば十分で、正確な組織の再現は不要。
- 生地の外周に 1px の sumiSub の枠線を描く。
- 描画は rect の外にはみ出さない(`ctx.save()` → `rect` で clip → 描画 → `ctx.restore()`)。

## テスト

jsdom では Canvas が使えないため、`fillRect` と `fillStyle` の設定を記録する偽の ctx を渡して確かめる。

1. warp が2色(赤・白)、threadPx 4、幅 16px のとき、経糸の色のマスが「赤・白・赤・白」の順に左から並ぶ。
2. 描画の前後で save / clip / restore が呼ばれる。
3. `fabricSpecFor` で、柄の plan が色の配列に展開される(kon×7, shiro×1 → 紺7つ・白1つ)。
