## 仕様:index.ts

```ts
export function createCreelModule(deps: GameDeps): GameModule;
// id 'creel'、titleTermKey 'game.creel'、phase 'P1'、embeddable true、tutorial は tutorial.ts
```

`mount(container, props)`:

- `props.resume` が `isValidResume` を満たせば、その状態でプレイ画面を開く。
- そうでなければ、お題一覧を開く。
- `mode: 'job'` のときは、`job.patternId` の柄で、difficulty 1→1段、2→2段、3→3段・8軸のお題をその場で作ってプレイ画面を開く(お題一覧は出さない)。経営シミュレーション(P5)まで使われないが、形だけ用意する。

## 仕様:listView.ts(お題一覧)

- 見出しは「お題をえらぶ」。上に「もどる」(`props.onExit`)。
- お題を段階の順に大きなボタンで並べる。ボタンの中は「段階 N」「柄の名前」「段×軸」(例「2段 × 8本」)と、クリア済みなら星(★☆)。
- 星は `deps.records.get('creel').best['puzzle:<id>']`。
- 選べるのは、クリア済みのお題と、最初の未クリアのお題まで。その先は「まだ」と表示し、押せない見た目にする。

## 仕様:controller.ts(プレイ画面)

- `createGameFrame`(題名は `deps.terms.t('game.creel')`、論理 1000×750)を作り、盤面に `drawBoard`、操作欄に `createCreelPanel` を置く。
- 盤面の `pointerdown` で `fromPx` → `hitTest` → `tapCell`。当たりが無ければ何もしない。
- 操作のたびに `reduce` → 盤面を描き直す → 操作欄を update → `props.onStateChange(state)`。
- 効果音:箱を立てたとき `tap`、はずすとき `tap`、たしかめるで間違いがあれば `gentleNo`、正解なら `fanfare`、ヒントで `ok`。
- メッセージ:最初は「依頼書のとおりに、{{cone}}を立ててください」(`terms.render`)。間違いがあったら「✕ のところを直してください」。2回目の失敗の後は「ヒントも使えます」を添える。
- done になったら:操作欄を隠し、盤面の上に生地の見本(`drawFabric`)を大きく重ねて「できあがりました」と表示する。1.5秒後に `props.onFinish(result)` を呼ぶ。
  - result:gameId 'creel'、mode、stars は `starsOf`、stats は `{ checks, hints, 'puzzle:<id>': stars }`、unlockedPatternIds は `[お題の patternId]`、finishedAt は `deps.clock.now()`。
- 「もどる」は `props.onExit()`、「あそびかた」は `showTutorial`。
- `suspend()`:プレイ中は状態を、お題一覧では null を返す。
- `unmount()`:frame.destroy、パネルの destroy、登録したイベントとタイマー(1.5秒の待ちを含む)をすべて解除する。

## 仕様:tutorial.ts

3ページ。絵は Canvas で簡単に描く(コーン・軸・依頼書の表の略図)。

1. 「依頼書を見て、どの糸を何本立てるか確かめます」
2. 「品番の書かれた箱をえらんで、{{spindle}}をさわると{{cone}}が立ちます」
3. 「全部立てたら『たしかめる』。まちがいは ✕ で教えてくれます」

(`{{…}}` は terms.render で置き換える)

## テスト(controller.test.ts、jsdom、偽の Canvas)

1. お題一覧:記録が無いと s1 だけ押せる。records に s1 の星があると s2 まで押せる。
2. プレイ:s1 で全部の軸をタップして立て、たしかめるを押すと、1.5秒後(偽のタイマー)に onFinish が1回呼ばれ、stars 3・unlockedPatternIds が ['p-muji-kon']。
3. onStateChange が操作のたびに呼ばれる。suspend がプレイ中は状態、お題一覧では null。
4. unmount の後にタイマーが残っていない(1.5秒進めても onFinish が呼ばれない)。
