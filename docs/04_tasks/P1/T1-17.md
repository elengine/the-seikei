## A. 確認の画面:「続ける」を「やめる」に、「やめる」を左に

- 管理者の指摘:「一覧やホームに戻るときの確認の画面の『続ける』は、『戻る操作を続ける』と読み違えそう」。
- 文言:次の2か所の `cancelLabel` を「続ける」から「やめる」に変える。
  - `gameScreen.ts`:「ホームに戻りますか?(途中の状態は保存されます)」の確認。
  - `games/creel/index.ts`:「お題の一覧に戻りますか?(途中の状態は保存されます)」の確認。
- 配置:**すべての確認の画面**(`confirmDialog` と `textInputDialog`)で、取り消しのボタン(「やめる」「最初から」など、`cancelLabel`)を**左端**、決める側のボタン(「ホームに戻る」「一覧に戻る」「決定」など、`okLabel`)を**右端**に置く。
  - ボタンの並び順(取り消しが先、決める側が後)は、いまの `widgets.ts` のままでよい。`.dialog__actions` を `justify-content: space-between` にする。
  - 2つのボタンの間は 24px 以上空ける(`gap` を `calc(var(--gap) * 2)` にする)。押し間違いを防ぐため。
  - 画面の幅が狭くて折り返すときも、取り消しが左、決める側が右の順を保つ。
- テスト:
  - `widgets.test.ts`:`confirmDialog` の `.dialog__actions` の最初の子が取り消しのボタン、最後の子が決める側のボタン。
  - `tokens.test.ts`(`base.css` を読むテスト):`.dialog__actions` に `justify-content: space-between` がある。
  - `gameScreen.test.ts`・`controller.test.ts`:確認の画面の取り消しのボタンの文字が「やめる」(期待値の変更の理由:管理者の指示で文言を変えたため)。

## B. 設定画面:項目名の文字を大きくする

- 管理者の指摘:「項目名の文字サイズが、ほかと比べると小さい」。いまは、項目名(`.settings__label`)が 20px の普通の太さで、隣の「変更」ボタンの文字(22px の太字)より小さく見える。
- 新しい文字の大きさ `label` を足す:`tokens.ts` の `FONT` に `label`(large 24、xlarge 28)を足し、`base.css` の `:root` に `--fs-label: 24px`、`:root[data-font='xlarge']` に `--fs-label: 28px` を足す。
- `.settings__label` を `font-size: var(--fs-label); font-weight: 700;` にする。
- テスト(`tokens.test.ts`):`--fs-label` が `FONT.large.label`・`FONT.xlarge.label` と一致する(既存の --fs-* のテストに足す)。

## C. 設定画面:「管理者」ボタンを押し間違えにくくする

- 管理者の指摘:「『管理者』ボタンが、『変更』ボタンと『戻る』ボタンに隣接していて、誤って押しそう」。いまは、画面の下の方に「管理者」(右寄せ、高さ 48px)があり、そのすぐ下に「戻る」がある。「変更」ボタンも右の列に並んでいる。
- 直し方:
  1. **「戻る」を画面の上に移す。** 題名「設定」と同じ行の左に置く(呼び名の変更の画面やお題の一覧と同じ形)。画面の下には置かない。
  2. **「管理者」は、画面の一番下の左に置く。** 最後の設定の行との間に、区切りの線(1px、`--c-steel`)と、その上下に 48px 以上の余白を入れる。「変更」ボタンの列(右)から離す。
  3. 「管理者」ボタンの高さは 64px 以上にする(いまの 48px は、押せる部品の決まり 64px を満たしていない)。副ボタンの見た目のまま、文字は `--fs-body`。
- テスト(`settingsScreen.test.ts`):
  - 「戻る」ボタンが、題名と同じ見出しの要素の中にあり、「管理者」ボタンより前(DOM の順で先)にある。
  - 「管理者」ボタンが画面の最後の要素の中にある。
  - `tokens.test.ts`:`.settings__admin-btn` の `min-height` が `var(--btn-min-h)`。

## D. ホーム画面:「○○さん、こんにちは」を大きくする

- 管理者の指摘:「『○○さん、こんにちは』の文字サイズが、ほかと比べると小さい」。いまは 20px で、下のゲームのボタンの文字(22px の太字)より小さい。
- `.home__greeting` を `font-size: var(--fs-label);` にする(24px)。屋号(`.home__shop`、28px)より小さく、ボタンより大きい。
- テスト(`tokens.test.ts`):`.home__greeting` の `font-size` が `var(--fs-label)`。
