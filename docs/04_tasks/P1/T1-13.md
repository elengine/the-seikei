# T1-13 画面の文言を大人向けにする

- 目的:画面の文言が、子ども向けのひらがな書きになっている。遊ぶのは大人(引退した整経の職人)なので、大人が読む前提の文言に直す。
- 関連要件:NFR-U 系、03_basic_design 2章、`docs/04_tasks/00_rules.md` の「守ること」(画面の文言は大人向け)
- 前提:T1-12
- 出どころ:管理者の指示(2026-09-30、会話)。「このゲームは大人が遊ぶ。ひらがなが多すぎるので、大人が前提の文言にする。今後作るゲームも同じ」。一覧は、確認役が `b2badd4` 時点のコードから作った。
- 進め方:1つのコミットにしてよい。テストで文言を見ているもの(ボタンの文字を探すテストなど)は、先に期待値を新しい文言に変えて RED を確認してから直す。期待値を変える理由は「管理者の指示で文言を変えたため」と書く。
