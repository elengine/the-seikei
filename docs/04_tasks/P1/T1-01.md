# T1-01 今すぐ新しい版に切り替えるボタン

- 目的:新しい版が届いているのに、タブやアプリをすべて閉じないと切り替わらない問題を、管理者が1回の操作で解消できるようにする(P0 の実機確認でつまずいたため)。
- 関連要件:NFR-A-02
- 前提:P0 完了

## 変更するファイル

`src/main.ts`、`src/app/diagnostics.ts`、`src/app/diagnostics.test.ts`、`src/app/screens/adminScreen.ts`、`PROGRESS.json`

## 仕様

1. `main.ts` の `registerSW` に `onNeedRefresh` を渡し、呼ばれたら「新しい版が届いている」ことを記録する。`registerSW` が返す関数(更新を実行する関数)も保持する。記録と保持は `diagnostics.ts` に次の関数を追加して行う。

```ts
export function setUpdateAvailable(apply: (reload?: boolean) => Promise<void>): void;
export function isUpdateAvailable(): boolean;
export async function applyUpdateNow(): Promise<void>; // 保持した関数を reload=true で呼ぶ。未記録なら何もしない
```

2. 管理者メニューの診断欄に「新しい版」の行を追加する。値は「届いている」または「なし」。
3. 診断欄の下(「アプリとしてインストール」の近く)に「今すぐ新しい版に切り替える」ボタンを置く。新しい版が届いているときだけ押せる。押したら確認ダイアログ(「切り替える」「やめる」)を出し、「切り替える」で `applyUpdateNow()` を呼ぶ(画面が再読み込みされる)。ログに info で「新しい版へ切り替え」を残す。
4. お父さん向けの画面(ホーム・設定・ゲーム)には、更新の案内を出さない(これまでどおり次回起動時に自動で切り替わる)。

## テスト

1. `setUpdateAvailable` 前は `isUpdateAvailable()` が false、後は true。
2. `applyUpdateNow()` で、保持した関数が reload=true で1回呼ばれる。未記録なら例外を出さず何もしない。

## 完了条件

- `npm run check` と `npm test` が成功する。
- 本番ビルド(vite preview)で、一度開いた後に再ビルドして配信し直すと、管理者メニューの「新しい版」が「届いている」になり、ボタンで切り替わって「ビルドの識別」が新しい時刻になることを確かめて報告する。
