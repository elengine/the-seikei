# T1-09 クリール立て:操作欄

- 目的:依頼書の表、いまの帯の並び、品番の書かれた箱、道具とボタンを、操作欄(DOM)として作る。
- 関連要件:FR-G1-01〜FR-G1-05、NFR-U-01〜06、03_basic_design 2章・6.1、P1/README
- 前提:T1-07

## 作成するファイル

`src/games/creel/panel.ts`、`src/games/creel/panel.test.ts`

CSS が必要な場合は、`panel.ts` の中で `creel-` で始まるクラスを使い、`src/styles/base.css` の末尾に「/* creel */」の節を追加してよい(追加のみ。既存の行は変えない)。

## 仕様

```ts
export interface CreelPanel {
  update(s: CreelState): void;   // 状態に合わせて表示を更新
  setMessage(text: string): void;
  destroy(): void;
}
export function createCreelPanel(parent: HTMLElement, opts: {
  content: Content;
  onAction: (a: CreelAction) => void;
}): CreelPanel;
```

上から順に、次の4つの区画を置く。

- **横長(最優先)**:1180×820 と 960×720 で、4つの区画すべてがスクロールなしで見えるようにする。収まらない場合は、箱を2列に並べる、依頼書といまの帯の並びを横に並べる、などで詰める(文字を 20px 未満にしたり、ボタンを 64px 未満にしたりして詰めてはいけない)。
- **縦長**:412×915 では、操作欄の中だけが縦にスクロールしてよい。

1. **依頼書**:見出し「依頼書」。`toRuns(answer)` を1行ずつ表にする。列は「品番」「色」(記号と色名)「本数」(例「× 7」)。選んでいる箱と同じ品番の行を、藍の太い枠で囲む。
2. **いまの帯の並び**:見出し「いまの帯の並び」。帯の番号の順に小さな四角を横に並べ(折り返してよい)、立っている糸は色で塗って記号を重ね、空きは点線の枠にする。marks の wrong・empty は shu の ✕ を重ねる。1マスは 28px 四方以上。
3. **箱**:見出し「箱」。boxes の順に、段ボール箱をかたどったボタン(薄い茶色の地、sumi の文字)を並べる。ボタンの中は、上に品番を `--fs-number` の大きさで、下に「記号 色名」。選んでいる箱は、設定画面と同じく藍の地・白文字・先頭に「✓ 」。
4. **道具とボタン**:「はずす」「しらべる」(選んでいる方は藍の地・白文字・✓)、「たしかめる」(主ボタン)、「ヒント」(`canHint` が false の間は押せない見た目にする)。

- すべてのボタンは 64px 以上の高さ、押すと `onAction` に対応する操作を渡す。
- 色だけに頼らず、記号と文字を必ず併記する(NFR-U-05)。
- `setMessage` は操作欄の一番上に1〜2行で表示する(GameFrame の message 欄があればそれを使う)。

## テスト(jsdom、本物の内容データ)

1. s2 の状態で update すると、依頼書が2行(W-4812 × 7、W-2200 × 1)。
2. 箱のボタンを押すと `onAction({ type: 'selectBox', yarn })` が呼ばれる。選んでいる箱だけに「✓」が付く。
3. 選んでいる箱と同じ品番の依頼書の行にだけ、選択中を表すクラスが付く。
4. いまの帯の並びのマスの数が rows*cols と同じ。marks の wrong の数だけ ✕ が付く。
5. `canHint` が false の状態ではヒントボタンが disabled、true になると押せる。
6. destroy で DOM から消える。

見た目(スクロールなしで収まるか)は T1-10 のブラウザ確認で確かめる。
