# T1-19 設定画面の今の値の大きさ、呼び名の変更画面の区分け

- 目的:管理者の実機確認の指摘2点を直す。あわせて、呼び名の変更画面で見つかった小さな点も直す。
- 前提:T1-18
- 出どころ:管理者の指示(2026-09-30、会話)。「設定画面のお名前・屋号の登録データの文字が小さい。項目と同じか、少し大きくてもよさそう」「呼び名の変更画面は、用語とゲーム名をセクションに分けてほしい」。C は確認役がコードを読んで見つけた。
- 進め方:1つのコミット。テストを先に書いて RED を確認してから直す。

## A. 設定画面:お名前・屋号の今の値を大きくする

- いまは、今の値(`.settings__value`)が 20px・薄い色(`--c-sumi-sub`)で、項目名(24px の太字)より小さく見える。
- `.settings__value` を `font-size: var(--fs-label);`(24px。特大では 28px)、色を `--c-sumi`(濃い色)にする。太さは普通のまま(項目名の太字と区別する)。
- 値が無いときの「(未設定)」だけは、今までどおり薄い色(`--c-sumi-sub`)にする(`settings__value--empty` などのクラスを付けて分ける)。
- テスト(`tokens.test.ts`):`.settings__value` の `font-size` が `var(--fs-label)`。(`settingsScreen.test.ts`):お名前が空のとき、値の要素に空を表すクラスが付き、入れたあとは付かない。

## B. 呼び名の変更画面:「整経の用語」と「ゲームの名前」に分ける

- いまは、用語(コーン、クリールなど)とゲームの名前(クリール立て、ドラム巻きなど)が、1つの一覧に混ざって並んでいる。
- 2つの区画に分ける:
  1. 見出し「整経の用語」:キーが `game.` で始まらないもの(初期値ファイルの順)。
  2. 見出し「ゲームの名前」:キーが `game.` で始まるもの(初期値ファイルの順)。
- 見出しは `h2`、文字は `--fs-label` の太字。区画のあいだに区切りの線(1px、`--c-steel`)と、上下 24px 以上の余白。
- テスト(`termsScreen.test.ts`):見出しが2つあり、1つ目の区画に `game.` で始まるキーの行が無く、2つ目の区画には `game.` で始まるキーの行だけがある。

## C. 呼び名の変更画面の小さな直し(確認役が見つけた)

1. **入力の画面の題名が、プログラム用の名前になっている。** 「変更」を押すと出る入力の画面の題名が `entry.key`(例:`cone`、`game.creel`)で、英字のキーがそのまま見える。
   - 直し方:題名を「『今の呼び名』の呼び名」(例:「『コーン』の呼び名」)にする。
2. **「戻る」の位置が、設定画面とそろっていない。** T1-17 で設定画面の「戻る」は題名と同じ行の左に移したが、呼び名の変更画面は題名の下の行にある。
   - 直し方:設定画面と同じ形(題名と同じ行の左に「戻る」)にする。
- テスト:入力の画面の題名に `cone` などのキーが含まれず、今の呼び名が含まれる(`textInputDialog` の呼び出しの引数で確かめてよい)。「戻る」が題名と同じ見出しの要素の中にある。
