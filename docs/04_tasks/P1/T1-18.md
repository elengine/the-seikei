# T1-18 設定画面:縦長の細い画面で、今の値が縦に折れる

- 目的:T1-17 で項目名を 24px の太字にしたため、412×915 などの細い画面で、今の値(お名前・屋号)の列が細くなり、「(未設定)」「整経所」が1〜2文字ずつ縦に折れて読みにくい。直す。
- 前提:T1-17
- 出どころ:確認役が T1-17(`854cc96`・`8ffd3fa`、報告 `6503d8b`、Discord のルビーのスレッド 2026-09-30 9:55)を 412×915 で確かめたときに見つけた。
- 進め方:1つのコミット。

## 変更してよいファイル

`src/styles/base.css`(設定画面の節のみ)、`src/core/ui/tokens.test.ts`、`PROGRESS.json`、`docs/progress_log.md`

## 直し方

- 画面の幅が 600px 未満のとき(`@media (max-width: 599px)`)、設定の各行(`.settings__row`)を2段にする:
  - 1段目:項目名(`.settings__label`)を行の幅いっぱいに。
  - 2段目:左に今の値(`.settings__value`)、右にボタン(`.settings__actions`)。
  - 例:`grid-template-columns: 1fr auto;` と、項目名に `grid-column: 1 / -1;`。
- 600px 以上(iPad の横・縦、Fold を開いた状態)は、今の3列のまま変えない。
- 今の値は、単語の途中で1文字ずつ折れないようにする(`overflow-wrap: anywhere` をやめ、`overflow-wrap: break-word` にする)。

## テスト

- `tokens.test.ts`(`base.css` を読むテスト):`@media (max-width: 599px)` の中に `.settings__row` と `.settings__label` の規則があり、`.settings__label` に `grid-column: 1 / -1` がある。

## ブラウザ確認(本番と同じビルド、ポートは固定)

- 412×915 と 360×800:項目名が1段目、今の値とボタンが2段目。「(未設定)」「整経所」が1行で読める。横のはみ出しが無い。
- 1180×820 と 820×1180:今までどおり3列。
- スクリーンショットを添える。
