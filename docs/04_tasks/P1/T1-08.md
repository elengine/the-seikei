# T1-08 クリール立て:座標と盤面の描画

- 目的:クリールの盤面を Canvas に描き、タップした位置から軸を割り出す。
- 関連要件:FR-G1-01〜FR-G1-05、02_architecture 7章(描画の規則)、03_basic_design 2章・6章、P1/README
- 前提:T1-07

## 作成するファイル

`src/games/creel/geometry.ts`、`src/games/creel/geometry.test.ts`、`src/games/creel/renderer.ts`、`src/games/creel/renderer.test.ts`

## 仕様:geometry.ts

論理座標は 1000×750。変換は **このファイルの関数だけ** が行う(02_architecture 7章)。

```ts
export const LOGICAL_W = 1000;
export const LOGICAL_H = 750;
export const CREEL_AREA = { x: 60, y: 90, w: 880, h: 600 };   // クリールの枠の内側

export function toPx(fit: StageFit, p: { x: number; y: number }): { x: number; y: number };
export function fromPx(fit: StageFit, p: { x: number; y: number }): { x: number; y: number };
export function cellRect(index: number, rows: number, cols: number): { x: number; y: number; w: number; h: number };  // 論理座標
export function hitTest(p: { x: number; y: number }, rows: number, cols: number): number | null;  // 論理座標 → 帯の番号
export function fontPx(fit: StageFit, screenPx: number): number;  // 画面上で screenPx になる論理サイズ
```

- CREEL_AREA を rows×cols の格子に等分し、`cellRect` はその1マス。帯の番号と位置の対応は `indexToCell`(T1-03)を使う。
- `hitTest` はマス全体を当たりとする(見た目のコーンより広い)。CREEL_AREA の外は null。

## 仕様:renderer.ts

```ts
export function drawBoard(ctx: CanvasRenderingContext2D, fit: StageFit, s: CreelState, content: Content, terms: { t(k: string): string }): void;
```

描く順番:

1. 背景を kinari で塗る。
2. クリールの枠:CREEL_AREA の左右に太い柱、各段の下に横の棒を machine 色で描く。影や明るい面に machineLight を使ってよい。
3. 各マスの中央に軸(steel 色の短い縦線)。
4. 立っているコーン:マスの中に収まる台形(下が広い)を糸の色で塗り、sumi の輪郭線を引く。コーンの中央に色の記号(symbol)を、糸の色に対して読みやすい色(明るい色なら sumi、暗い色なら white)で描く。
5. 品番:`showHinbanOnCone(stage)` が true なら、立っているコーンの下に品番を描く。
6. 空いている軸:コーンの形を点線の輪郭だけで描く。
7. 帯の番号:段階 1〜3 は各マスの左上に番号(1 始まり)、段階 4〜5 は各段の最初のマスだけ。
8. marks:wrong と empty のマスに shu の太い ✕ を重ねる。
9. inspected:そのコーンの上に吹き出し(白地・sumi 枠)で品番と糸の説明(spec)を描く。

- 文字は `fontPx(fit, 20)` 以上の大きさにする(画面上で 20px 以上。NFR-U-01)。
- 色は `COLORS` と内容データの hex だけを使い、数値を直接書かない。

## テスト

geometry:
1. `toPx` と `fromPx` が往復して一致する(複数の fit で)。
2. rows 3・cols 8 で、各マスの中心を hitTest すると、その帯の番号が返る。CREEL_AREA の外は null。
3. `fontPx(fit, 20)` を toPx の倍率で画面に戻すと 20 になる。

renderer(呼び出しを記録する偽の ctx):
4. s1 の空の状態で描くと、エラーなく終わり、点線の輪郭が 6 マスぶん描かれる(`setLineDash` の呼び出しで確かめてよい)。
5. marks に wrong が 2つあると、✕ の線が 2組描かれる(shu 色で `stroke` が呼ばれた回数で確かめてよい)。
6. 描画で使った文字の大きさ(`font` の設定値)が、すべて fontPx(fit, 20) 以上。
