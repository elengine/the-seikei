# T1-07 クリール立て:ルール

- 目的:クリール立てのルールを、画面を持たない純粋な関数(reducer)として作る。
- 関連要件:FR-G1-01〜FR-G1-07、03_basic_design 6.1、P1/README の設計の補足
- 前提:T1-03

## 作成するファイル

`src/games/creel/logic.ts`、`src/games/creel/logic.test.ts`、`src/games/creel/params.ts`

## 型

```ts
export type Tool = { kind: 'box'; yarn: YarnTypeId } | { kind: 'remove' } | { kind: 'inspect' };

export interface CreelState {
  puzzleId: string;
  stage: 1 | 2 | 3 | 4 | 5;
  rows: number;
  cols: number;
  answer: YarnTypeId[];              // 正解の帯の並び(rows*cols 本)
  boxes: YarnTypeId[];               // 操作欄に出す箱
  placed: (YarnTypeId | null)[];     // 軸ごとに立っている糸
  tool: Tool;
  checks: number;                    // 「たしかめる」を押した回数
  hints: number;
  marks: { wrong: number[]; empty: number[] } | null;   // 最後の判定の✕
  inspected: number | null;          // 「しらべる」で吹き出しを出している軸
  done: boolean;
}

export type CreelAction =
  | { type: 'selectBox'; yarn: YarnTypeId }
  | { type: 'selectRemove' }
  | { type: 'selectInspect' }
  | { type: 'tapCell'; index: number }
  | { type: 'check' }
  | { type: 'hint' }
  | { type: 'clearInspect' };

export function init(puzzle: CreelPuzzle, content: Content): CreelState;
export function reduce(s: CreelState, a: CreelAction): CreelState;   // 元の s は変更しない
export function canHint(s: CreelState): boolean;
export function starsOf(s: CreelState): 1 | 2 | 3;
export function showHinbanOnCone(stage: number): boolean;           // 段階 1〜3 は true
export function isValidResume(x: unknown, content: Content): x is CreelState;
```

## ルール

- **init**:answer は `answerFor`、placed はすべて null、tool は answer の最初の糸の箱、checks・hints は 0。
- **boxes**:answer に出てくる糸を、最初に出てくる順に並べる。段階 4 以上では、それに加えて「answer の糸と同じ色だが answer に無い糸」を品番の昇順で後ろに足す(紛らわしい箱)。
- **selectBox / selectRemove / selectInspect**:tool を切り替える。
- **tapCell**(index が範囲外なら何もしない):
  - 箱:placed[index] をその糸にする。marks があれば、その index を wrong・empty から取り除く。
  - はずす:placed[index] を null にする。
  - しらべる:placed[index] が null でなければ inspected = index、null なら inspected = null。
- **check**:checks を 1 増やし、`compare(placed, answer)`。wrong も empty も無ければ done = true・marks = null。あれば marks にその結果を入れる。
- **hint**:`canHint` が false なら何もしない。wrong と empty を合わせた中で一番小さい index を正解の糸にし、hints を 1 増やし、その index を marks から取り除く。hint だけでは done にしない(最後は「たしかめる」を押す)。
- **canHint**:done でなく、checks が 2 以上で、marks に wrong か empty がある。
- **clearInspect**:inspected = null。また、しらべる以外の操作をしたときも inspected は null に戻す。
- done の後は、どの操作でも状態を変えない。
- **starsOf**:checks が 1 かつ hints が 0 なら 3。checks が 3 以下かつ hints が 0 なら 2。それ以外は 1。
- **isValidResume**:途中保存の形が正しく、puzzleId が内容データに存在し、placed・answer の長さが rows*cols と一致し、done が false のときだけ true。

`params.ts` には、星の境目(1回・3回)と、紛らわしい箱を足す段階(4)を定数として置く。

## テスト(本物の内容データを使う)

1. s1 の init で、軸 6、箱 1つ(kon-a)、tool は kon-a の箱。
2. s4 の boxes が kon-a, kon-c, kon-b の順(kon-b は紛らわしい箱)。
3. 箱で全部正しく立てて check → done、starsOf が 3。
4. 1つ違う糸・1つ空きで check → marks の wrong と empty にそれぞれ入る。その軸に正しい糸を立てると marks から消える。
5. check 1回ではヒント不可、2回目の失敗の後はヒント可。hint で一番小さい間違いが直り、hints が 1。その後 check で done になっても starsOf は 1。
6. はずすで null になる。しらべるで inspected が付き、次に箱を選ぶと null に戻る。
7. done の後の tapCell は状態を変えない。reduce が元の状態を書き換えない(元のオブジェクトを JSON で比べる)。
8. isValidResume:正しい途中状態は true、存在しない puzzleId・長さ違い・done の状態は false。
