# T1-06 ゲーム画面の土台(開始・再開・結果)

- 目的:すべてのゲームに共通する「開く → チュートリアル → 再開の確認 → 遊ぶ → 結果 → 記録」の流れを、ゲーム画面として1か所にまとめる。
- 関連要件:FR-C-01、FR-C-02、FR-C-06、FR-C-07、03_basic_design 1章・7章、P1/README「ゲーム画面の流れ」
- 前提:T1-05

## 作成・変更するファイル

`src/app/screens/gameScreen.ts`(新規)、`src/app/screens/gameScreen.test.ts`(新規)、`src/core/game/types.ts`(1行追加のみ)、`src/app/context.ts`(zukan と records の追加のみ)、`src/app/screens/homeScreen.ts`(ボタンの移動先のみ)、`src/main.ts`(ルート追加のみ)

## 仕様

1. `src/core/game/types.ts` に追加する(既存の項目は変えない)。

```ts
// GameProps に1行追加
onStateChange?: (state: unknown) => void; // 途中保存してほしい状態が変わったとき(ゲームが呼ぶ)

// ゲームが使ってよい共通の道具。ゲームは AppContext を直接受け取らず、これだけを使う
export interface GameDeps {
  terms: Terms;
  audio: AudioPlayer;
  records: Records;
  clock: Clock;
  log: (level: 'info' | 'warn' | 'error', message: string) => void;
}
```

2. `AppContext` に `zukan: ZukanRegistry` と `records: Records` を追加し、`createAppContext` で作る。あわせて `context.ts` に `export function gameDepsFrom(ctx: AppContext): GameDeps` を追加する。各ゲームは `createXxxModule(deps: GameDeps): GameModule` の形で作り、`main.ts` で boot の後に `registerGame(createXxxModule(gameDepsFrom(ctx)))` として登録する(T1-10 で最初の登録を行う)。
3. ホーム画面のゲームのボタンを押したら `#/games/<id>` へ移る。
4. `createGameScreen(ctx): Screen` を作り、ルート `/games/:id` に登録する。mount 時の流れ:
   1. 登録簿から id のゲームを取る。無ければホームへ。
   2. `settings.tutorialSeen[id]` が true でなければ、`showTutorial` で遊び方を見せ、終わったら true にする。
   3. sessions に id の途中保存があれば、確認ダイアログ(「つづきから」「はじめから」)。「はじめから」なら途中保存を消す。
   4. `module.mount(container, { mode: 'standalone', resume, onStateChange, onFinish, onExit })` を呼ぶ。
   5. `onStateChange(state)`:sessions(id = ゲームの id)に `{ state, savedAt }` を保存する。1秒に1回までにまとめる。`state` が null なら途中保存を消す。
   6. `onFinish(result)`:途中保存を消す → `records.add(result.gameId, result.stars, result.stats の中で 'puzzle:' で始まるキー)` → `unlockedPatternIds` をすべて `zukan.unlock` し、新しく入手した柄の名前を集める → `showResult`(againLabel「つづけて遊ぶ」、homeLabel「ホームへ」)→ 'again' ならゲームを mount し直す、'home' ならホームへ。
   7. `onExit()`:`instance.suspend()` が null 以外なら確認ダイアログ(「ホームにもどる」「つづける」)を出し、「ホームにもどる」なら suspend() の結果を途中保存してホームへ。null ならそのままホームへ。
5. ページが裏に回ったとき(`visibilitychange` で hidden)にも、`suspend()` の結果を途中保存する。
6. unmount では instance.unmount() と、登録したイベントをすべて解除する。

## テスト(jsdom、fake-indexeddb)

テスト用の偽の GameModule(mount 時に受け取った props を外から呼べるもの)を登録して確かめる。

1. tutorialSeen が無ければチュートリアルが出て、終わると tutorialSeen が true で保存される。
2. 途中保存があるとき「つづきから」を選ぶと、mount に resume が渡る。
3. onFinish で、途中保存が消え、records と zukan に記録され、結果の表示で「ホームへ」を押すと `/` へ移る。
4. onExit で suspend() が値を返すと確認が出て、「ホームにもどる」で途中保存される。
5. onStateChange を短い間に3回呼んでも、保存は最後の1回だけになる(時間は偽のタイマーで進めてよい)。
