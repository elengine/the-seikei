# T0-05 端末内保存(Dexie)

- 目的:IndexedDB に保存する Repository を作り、契約テストに合格させる。Dexie は既存プロジェクトで使っていない新規ライブラリなので、ここで動作を確かめる。
- 関連要件:DR-01〜DR-05、02_architecture 5.2・6章
- 前提:T0-04

## 作成するファイル

`src/core/storage/localRepository.ts`、`tests/contract/localRepository.test.ts`

## 仕様

```ts
export async function createLocalRepository(opts: {
  dbName: string;          // 本番は 'seikei-game'。テストでは毎回別名
  clock: Clock;
  deviceId?: string;       // 指定があればそれを使う(テスト用)
}): Promise<Repository & RawStore>;
```

- deviceId の指定がない場合は、データベースを開いた後に meta 'deviceId' を読み、なければ `clock.uuid()` で作って保存する。結果を `deviceId` プロパティに入れる。
- 契約テストに1件追加する:deviceId を指定せずに作ると `deviceId` が UUID になり、同じ dbName で作り直しても同じ値になる(このテストは localRepository.test.ts に書く)。

- Dexie のデータベース定義:
  - version 1
  - `recs`:主キー `[collection+id]`、索引 `collection`、`updatedAt`
  - `meta`:主キー `key`(値は `{ key, value }`)
- `importAll` はこのタスクでは `throw new Error('T0-07 で実装')` とする。
- 購読は、このインスタンス内の変更だけを通知すればよい(他のタブの変更は扱わない)。
- `put` は、既存の Rec を読み、`createdAt` を引き継いで保存する。既存が削除済みの場合は `deletedAt` を消して復活させる。

## テスト

`tests/contract/localRepository.test.ts` の先頭で `import 'fake-indexeddb/auto'` し、`runRepositoryContract('LocalRepository', ...)` を呼ぶ。`dbName` はテストごとに `clock.uuid()` などで別名にする。
