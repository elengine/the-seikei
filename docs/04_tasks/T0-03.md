# T0-03 時刻・乱数・ID(clock)

- 目的:時刻・乱数・ID の生成を1か所にまとめ、テストで固定できるようにする。
- 関連要件:NFR-M-04、DR-02、03_basic_design 6章「共通の約束」
- 前提:T0-01

## 作成するファイル

`src/core/clock/clock.ts`、`src/core/clock/clock.test.ts`

## 仕様

```ts
export interface Clock {
  now(): string;        // 現在時刻。ISO 8601 の UTC(例 '2026-10-01T11:00:00.000Z')
  uuid(): string;       // UUID v7
}
export function createSystemClock(): Clock;
export function createFixedClock(startIso: string, stepMs?: number): Clock;
// now() を呼ぶたびに stepMs(既定 1000)ずつ進む。uuid() は now() の時刻を使い、残りを連番で埋める(再現性のため)。

// ---- 擬似乱数(純粋関数)----
export type RngState = number;                        // 32bit 符号なし整数
export function seedFrom(n: number): RngState;        // n を 32bit に丸める
export function nextFloat(s: RngState): [number, RngState];           // [0,1) と次の状態
export function nextInt(s: RngState, min: number, max: number): [number, RngState]; // min 以上 max 以下
export function pick<T>(s: RngState, items: readonly T[]): [T, RngState];           // items が空なら例外
```

- 擬似乱数のアルゴリズムは mulberry32 とする。
- UUID v7:先頭 48 bit にミリ秒の Unix 時刻、バージョン 7、バリアント 10、残りは `crypto.getRandomValues` の乱数(system の場合)。
- `createSystemClock` の中でだけ `Date` と `crypto` を使ってよい。

## テスト(先に書く)

1. `createFixedClock('2026-01-01T00:00:00.000Z')` の `now()` を2回呼ぶと1秒ずつ進む。
2. system の `uuid()` が UUID v7 の形式(`/^[0-9a-f]{8}-[0-9a-f]{4}-7[0-9a-f]{3}-[89ab][0-9a-f]{3}-[0-9a-f]{12}$/`)に合う。
3. 後から作った UUID v7 の方が、文字列として大きい(時刻順に並ぶ)。1ミリ秒以上あけて作る。
4. 同じ種から `nextFloat` を100回回した列が、2回とも同じになる。
5. `nextFloat` の値がすべて 0 以上 1 未満。
6. `nextInt(s, 1, 6)` を1000回回すと、1〜6 のすべてが出て、範囲外は出ない。
7. `pick` に空配列を渡すと例外。
