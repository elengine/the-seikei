# T0-02 自動デプロイ

- 目的:main に push したら、検査とテストに合格した場合だけ GitHub Pages に公開する。
- 関連要件:C-02、02_architecture 8.1
- 前提:T0-01

## 作成するファイル

`.github/workflows/deploy.yml`

## 仕様

- トリガー:`push`(main)と `workflow_dispatch`。
- permissions:`contents: read`、`pages: write`、`id-token: write`。concurrency は `group: pages`、`cancel-in-progress: true`。
- build ジョブ(ubuntu-latest):
  1. `actions/checkout@v4`
  2. `actions/setup-node@v4`(node 22、npm キャッシュ)
  3. `npm ci`
  4. `npm run check`
  5. `npm test`
  6. `npm run build`
  7. `actions/upload-pages-artifact@v3`(path: `dist`)
- deploy ジョブ:build の後、`actions/deploy-pages@v4`。environment は `github-pages`。
- Supabase の環境変数は P6 まで入れない。

## 完了条件

- push 後、Actions が成功し、`https://elengine.github.io/the-seikei/` に「整経ゲーム 準備中」が表示される。
- わざと失敗するテストを入れた場合にデプロイされないことは、管理者が必要に応じて確認する(実装担当は行わなくてよい)。
- Pages の設定は T0-00 で済んでいる。デプロイが権限エラーで失敗した場合は、エラー内容を報告する。
