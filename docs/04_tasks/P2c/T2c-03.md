## 操作欄(上から)

1. メッセージ(今までの決まり。例「羽の角度を選んで、送り量を合わせてください」「羽の角度を選んでください」「試し巻きをしています」「潰れました。送り量が少なすぎます」「崩れました。送り量が多すぎます」「その糸には、この角度は使えません」)
2. **依頼書**(節の見出し):番手(`GRADE_LABEL`)・帯の本数・帯の幅・柄の名前
3. **計算のメモ**(節の見出し):段階に応じて見せる(1:密度・厚み・角度ごとの tan、2:厚み・tan の表、3:密度・係数の表・tan の表、4:係数の表・tan の表、5:何も無し。「表は電卓から見られます」)。数は小数第2位まで(厚みは第3位)。
4. **羽の角度**(節の見出し):`createChoice`(5°・7°・9°・11°)。その糸に使えない角度も選べる(選ぶと試し巻きで崩れる。T2c-01 の決まり)。段階1〜2 だけ、使える角度に小さく「○」を添える。
5. **送り量**(節の見出し):大きな数字(「1.07 mm」、数字は 32px 以上)と、「−0.1」「−0.01」「+0.01」「+0.1」の4つのボタン(64px 以上)。数字を押すと、電卓の答えをそのまま入れる(下の電卓)。
6. 一番下に固定:「電卓」(secondary)と「試し巻き」(primary、右・広く)。試し巻きのあいだは両方とも押せない形(`lockedReason`「試し巻きの途中です」)。星3 でないときは、結果のあとに「ここで終える」(secondary)を出す(押すと結果の画面へ)。

## 電卓(`calculator.ts`、`openSheet` の中)

- 四則(+ − × ÷)、小数点、`C`、`=`、数字のボタン(64px 以上、文字 24px 以上)。表示は右寄せの大きな数字。小数第4位まで。
- 「tan の表」「係数の表」のボタン:押すと、表を電卓の上に出す(5°〜11° の tan、3つの番手の係数)。
- 「この答えを送り量に入れる」(primary):答えを小数第2位に丸めて送り量にし、重ね表示を閉じる。
- 純粋な計算部分(`calc(state, key)`)をテストできるようにする。

## controller

- ドラム巻きと同じ形(rAF、unmount ですべて解除、裏に回ったら試し巻きの絵を止めて結果だけ決める)。試し巻きの `progress` を renderer に渡す。終わったら `trialEnd`。
- 音:試し巻きの始まりと終わりに今ある音(`tap`、`ok` または `gentleNo`)。
- 結果の画面(`GameResult`):`resultLines`「羽の角度 9°」「送り量 1.07mm(正しい値 1.07mm)」「試し巻きの回数 2回」、`starHint`「送り量の誤差が5%以内で星3です」、答え合わせとして「正しい計算」(密度 → 厚み → 送り量の3行)を `resultLines` に足す。`next`「次のお題へ」、`again`、`toList`。題名の下は「段階N 柄の名前」。
- 途中保存(`DrumSetupState` をそのまま)と再開。成績は `best['puzzle:<id>']`。

## 一覧・遊び方・組み立て

- 一覧はドラム巻きの一覧と同じ形(段階ごとの節・15題・星/次はこれ/鍵・補足は「2/48・帯 400本」)。解放の決まりも同じ。
- 遊び方(4ページ):(1)「ドラムに巻く前に、羽の角度と、1回転で帯を横に送る量を機械に設定します」(2)「帯は1回転ごとに少し太ります。太る厚みは、帯の密度(本数÷幅)と糸の太さで決まります」(3)「送り量 = 厚み ÷ tan(羽の角度)。電卓と表を使えます」(4)「試し巻きで、帯がきれいに羽を登れば成功です。少なすぎると潰れ、多すぎると崩れます」。絵は Canvas で、色は tokens。
- `index.ts`:`createDrumSetupModule(deps)`(ドラム巻きの `index.ts` と同じ形)。ホームのカードの説明「羽の角度と送り量を計算して合わせる」、状態「お題 15」。
