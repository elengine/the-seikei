## 盤面(論理座標 1000×750)

- **横から見た断面**:下の端に、ドラムの表面(横に長い板。木の色 `wood`、穴の並び)。左側に、帯の区画(これから糸を巻く場所)。右側に、**羽**(表面から右上へ登る斜面。角度は選んだ羽の角度。角度の違いが分かるよう、見た目の角度は実際の角度の 4 倍で描いてよい。倍率は `geometry.ts` の定数)。羽は板の色で、厚みを持たせる。
- 角度が未選択のときは、羽を薄い点線で描く。
- **帯の断面**:`trialLayers` の点の並びから、層を1つずつ細い帯(糸の色。柄のいちばん多い色)で積み上げて描く。1回転の厚みは見た目で 8px 以上になるよう、縦にも倍率をかける(定数)。
  - 試し巻きのあいだ(`phase 'trial'`)は、約5秒(`TRIAL_MS` を params に足してよい)で回転 0 から `TRIAL_TURNS` まで、1層ずつ積み上げる(rAF の時刻で進める。controller から `progress 0〜1` を渡す)。
  - 結果に応じて:`good` は層の右端が斜面に沿う(斜面の線と層の端がそろう)。`crush` は層が斜面を越えて重なり、上の層ほど横にはみ出す(はみ出した部分を少し濃く)。`collapse` は層と斜面の間にすき間が残り、端が段になる。`badAngle` は層が斜面の途中で右へずり落ちる絵(数層だけ斜めにずらす)。
  - 結果の印:`crush` は朱の文字「潰れ」、`collapse` は「崩れ」、`good` は藍の文字「きれいに登った」を、断面の右上に(20px 以上。色だけに頼らず文字で)。
- 盤面の上の端に、小さく「1回転 送り ○.○○mm/羽 ○°」を出す(今の設定)。
- テスト:
  - `geometry.test.ts`:羽の斜面の線の傾きが、角度×倍率と合う。層 k の y が下から積み上がる(k が大きいほど上)。
  - `renderer.test.ts`:角度 null で点線の羽、選ぶと実線。`progress 0.5` で、描く層の数がおよそ半分。`crush`・`collapse`・`good` の印の文字。色の直書きが無い。
