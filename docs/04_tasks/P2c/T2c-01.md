## logic.ts

```ts
/** 正しい値(角度ごと) */
export function density(p: DrumSetupPuzzle): number;            // 本/cm = ends ÷ widthCm
export function thicknessPerTurn(p: DrumSetupPuzzle): number;   // h mm = density × YARN_COEF[grade]
export function correctFeed(p: DrumSetupPuzzle, angleDeg: number): number; // s mm = h ÷ tan(angle)。小数第2位に丸める

export interface DrumSetupState {
  puzzleId: string;
  angle: number | null;      // 選んだ羽の角度(未選択は null)
  feed: number;              // 合わせた送り量 mm(0〜FEED_MAX、小数第2位)
  trials: number;            // 試し巻きの回数
  phase: 'setting' | 'trial' | 'done';
  lastResult: TrialResult | null;
}
export type TrialOutcome = 'good' | 'crush' | 'collapse' | 'badAngle';
export interface TrialResult { outcome: TrialOutcome; errRatio: number; correct: number; stars: 1 | 2 | 3 }

export type DrumSetupAction =
  | { type: 'selectAngle'; angle: number }
  | { type: 'stepFeed'; delta: number }      // ±0.01・±0.1。0〜FEED_MAX に収める。小数第2位に丸める
  | { type: 'setFeed'; value: number }
  | { type: 'trial' }                        // 試し巻き → phase 'trial'、結果を決める
  | { type: 'trialEnd' }                     // 試し巻きの絵が終わった → 星3なら 'done'、それ以外は 'setting' に戻る
  | { type: 'retry' };                       // 'done' からもう一度

export function init(p: DrumSetupPuzzle): DrumSetupState;  // angle null、feed 0
export function reduce(s: DrumSetupState, p: DrumSetupPuzzle, a: DrumSetupAction): DrumSetupState;
export function judge(p: DrumSetupPuzzle, angle: number | null, feed: number): TrialResult;
```

- `judge`:
  - 角度が null か、`ALLOWED_ANGLES[grade]` に無い → `badAngle`、星1。
  - 誤差の割合 = (feed − 正しい値) ÷ 正しい値。絶対値が `STAR3_ERR` 以下 → `good`・星3。`STAR2_ERR` 以下 → 星2、それより大きい → 星1。星2・1 のとき、feed が小さければ `crush`(潰れ)、大きければ `collapse`(崩れ)。
- `trial` は角度が null のときは何もしない(画面が「羽の角度を選んでください」と出す)。
- 「星3 でなくても結果は出す」:`trialEnd` で、星3なら `done`、星2・1 は `setting` に戻ってやり直せる(結果は `lastResult` に残す)。**ゲームの完了(結果の画面)は、星3 のとき、または「ここで終える」を選んだとき**(T2c-03 で画面が `finish` を呼ぶ。logic には `{ type: 'finish' }` を足して `done` にする)。
- 試し巻きの絵のための積み上げ(T2c-02 が使う):

```ts
/** 試し巻きで、回転 k(0〜TRIAL_TURNS)までの帯の断面の形。各回転の層の左端の x(mm)と高さ(mm)の並び */
export function trialLayers(p: DrumSetupPuzzle, angle: number, feed: number, turns: number): { x: number; y: number }[];
```

  - 層 k の左端の x = k × feed、高さ y = k × h。羽の斜面の上の点は x = y ÷ tan(angle)。層の左端が斜面より内側(feed が小さい)なら、層は斜面を越えて重なる(潰れ)。外側(feed が大きい)なら、斜面との間にすき間ができる(崩れ)。この関数は、点の並びを返すだけで、判定はしない。

## テスト(先に書く)

- `puzzles.test.ts`:15題、id と柄がクリール立てと同じ、番手の決め方(2/60・紡毛 1/20・2/48)、段階ごとの本数と幅。
- `logic.test.ts`:
  - 段階1・2/48・9° の例:密度 20、厚み 0.17、送り量 1.07(0.17 ÷ 0.1584 = 1.073… → 1.07)。
  - `judge`:ぴったりで good・星3、+4% で星3、+10% で星2・collapse、−10% で星2・crush、−20% で星1・crush、使えない角度で badAngle・星1。
  - `stepFeed` が 0 未満・`FEED_MAX` 超えにならない、小数第2位に丸まる(0.1 を 3 回足して 0.3 になる)。
  - `trial` → `trialEnd` で、星3 なら `done`、星2 なら `setting` に戻り `lastResult` が残る。角度 null の `trial` は何もしない。
  - `trialLayers`:回転 0 は原点、回転 k の y = k × h、x = k × feed。
