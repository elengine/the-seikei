## T2c-04a

### 1. 羽は左に開き、太く(盤面と遊び方の両方)

- 管理者の指摘:「羽が右側に開いている。羽が細くて見づらい。羽は左側に開くようにする。羽を太くする(土台の 3 分の 2 程度の太さ)」。
- 盤面を左右反転する:**羽はドラムの表面から左上へ登る斜面**、帯の区画は羽の右側。層は羽の斜面に沿って**左へ**登る(T2c-03 追加修正の「層の右の端を斜面と同じ決まりで」は、左右を入れ替えて「層の左の端」にする)。
- 羽の板の厚みを、土台(ドラムの表面の板)の厚みの **3 分の 2** にする(`WING_THICK_PX` = `DRUM_RECT.h × 2/3`)。
- テスト:羽の上の端の x が、根元の x より小さい(左へ開く)。羽の厚み = 土台の厚み × 2/3(±1)。正しい送り量のとき、層の左の端と斜面の差が 2px 以内。

### 2. 羽の角度と送り量のボタンを、1行に4つ

- 管理者の指摘:「羽の角度や送り量の調整ボタンが、カバー画面で改行されたり横スクロールになって使いづらい。どちらもボタン数は4個なので、1行を4分割した幅で」。
- 羽の角度(5°・7°・9°・11°)と、送り量の「−0.1」「−0.01」「+0.01」「+0.1」を、**どちらも1行に4つ、同じ幅で**並べる(`grid-template-columns: repeat(4, minmax(0, 1fr))`。T2c-03 追加修正の 2×2 はやめる)。ボタンの高さは 64px 以上、文字は折り返さない(`white-space: nowrap`)。入りきらない幅では、文字の大きさを部品の中だけ一段小さくしてよい(20px は下回らない)。
- 「○」(使える角度の印、レベル1〜2)は、角度の右ではなく**下**に小さく出す(幅を取らないため)。
- テスト:2つの入れ物に4列の格子。ボタンの文字に `white-space: nowrap`。

### 3. 「試し巻き」→「巻く」

- 主な操作の文字を「**巻く**」にする(2行に折れないため)。メッセージの「試し巻きをしています」は「巻いています」に。遊び方の文の「試し巻き」も「巻く」に合わせる。
- テスト:主な操作の文字が「巻く」。

### 4. 遊び方の絵

- 管理者の指摘:「説明内の画像の文字が小さい。画像に被って見えづらい」「羽が右側に開いている(遊び方も)」。
- 遊び方の絵の文字(「潰れ」「崩れ」など)は 24px 以上にし、絵の線や層に**重ならない位置**(絵の上の余白か、層から離した所)に置く。羽は左に開き、太く(1 と同じ)。
- テスト:遊び方の絵の文字の大きさが 24px 以上(`font` の指定で確かめる)。

## T2c-04b:電卓を大きなポップアップに(PU-11 の後)

- 管理者の指摘:「電卓がカバー画面で使いづらい。ポップアップにして表示領域を広げる(クリール立ての依頼書と同様に)。使いやすい UI に」。
- 電卓を `openSheet({ size: 'tall' })`(見出しの行の下から画面の下まで)で開く。
- 並び:上に表示(右寄せ、40px 以上)、その下に**4列×5段のボタン**(`7 8 9 ÷` / `4 5 6 ×` / `1 2 3 −` / `0 . C +` / `=` は横に2つ分)、一番下に「この答えを送り量に入れる」(primary)。ボタンはすべて同じ幅で、64px 以上。tan の表と係数の表は、ボタンで開閉する小さな表(小数第4位)として表示の下に出す。
- 横長の低い画面(915×412 など)では、左に表示と表、右にボタンの格子を並べる。
- テスト:電卓の重ね表示に `sheet--tall`。ボタンの格子が4列。tan の表が小数第4位(「0.1584」)。
