# PU-26 ビーミング:ドラムをドラム巻きと同じ見た目で大きく、ドラムとビームが正しい向きに回る

- 目的:管理者の実機確認(2026-10-09、会話)。
  - 「ドラムのデザインはドラム巻きのドラムと同じに。実物はビームよりドラムのほうが大きいので、そのイメージを出す」
  - 「巻いているとき、ドラムの回る向きが逆。今は上から下へ回っているが、下から上が正しい」
  - 「ビームが回っていないので、回るアニメーションを足す。ビームは上から下へ回る」
- 前提:**T3-06(ルビー)が main に入ってから始める**。T3-06 で、流れ(幅合わせ → 糸を付ける → 巻く)、張りのメーター、糸を付ける当たり判定が入る。
- 進め方:1つのコミット+「PU-26 の報告」。テストを先に書き、RED を確かめてから直す。version を patch で上げる(main より大きく、package-lock もそろえる)。

- `src/games/beaming/renderer.ts`・`renderer.test.ts`、`geometry.ts`・`geometry.test.ts`、`controller.ts`(回る角度のみ)・`controller.test.ts`、`params.ts`(絵の数値のみ)

## 決まり

1. **ドラム**:ドラム巻きのドラムと同じ見た目にする。
   - 同じにするもの:胴の色、帯の筋、端の円盤(フランジ)、斜めから見た構図、左の端の見え方。
   - 大きさ:直径を**ビームの円盤の直径の 1.5 倍以上**にする。「ドラムのほうがビームより大きい」が一目で分かるように。
   - 糸のシートは、ドラムの下からビームへ続く(今のまま)。
2. **回る向き**(巻いている間。速さに比例。速さ 0 で止まる):
   - ドラムは**手前の面が下から上へ**動く向き。帯の筋や模様が上へ流れて見えること。
   - ビームは**手前の面が上から下へ**動く向き。
   - ビームには、回っていることが分かる印を足す。円盤の面の放射の線か、巻いた糸の筋が流れる形。軸の両端の位置は今のまま固定。
   - 回る角度は controller が時間で進める(今のドラムの角度と同じ仕組み)。描く向きの符号は `geometry.ts` か `params.ts` の定数にし、テストで確かめる。
3. **糸を付ける(`attach`)の絵**:T3-06 で入った、引っぱる糸の線は残す。大きさと位置が変わったドラムに合わせる。
   - 当たり判定は T3-06 の `geometry.ts` の関数を使い、今の絵と合っていること。
   - 押さえる所の幅は 64px 以上(T3-06 の決まり)。
4. 盤面は、Fold 8 の4通り・1180×820・iPhone 393×852 と 852×393 で、ドラムとビームと円盤が切れずに収まること。

## テスト(先に書く)

- ドラムの直径 ≥ ビームの円盤の直径 × 1.5。
- 角度が進むと、ドラムの筋の y が上へ動く。ビームの印は下へ動く。速さ 0 では角度が変わらない。
- 色の直書きが無い。
- (共通にした場合)winding の renderer のテストが、期待値を変えずに通る。

## 確認

- 本番と同じビルドで上の大きさを、文字の大きさ最大でも見る。
- スクリーンショットは2枚まで。回る向きは、2つの時刻の筋の位置を JavaScript で測ってよい。
- 最終確認は管理者が Fold 8 で行う。
