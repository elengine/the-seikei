## 決まり

1. **ドラム**:ドラム巻きのドラムと同じ見た目にする。
   - 同じにするもの:胴の色、帯の筋、端の円盤(フランジ)、斜めから見た構図、左の端の見え方。
   - 大きさ:直径を**ビームの円盤の直径の 1.5 倍以上**にする。「ドラムのほうがビームより大きい」が一目で分かるように。
   - 糸のシートは、ドラムの下からビームへ続く(今のまま)。
2. **回る向き**(巻いている間。速さに比例。速さ 0 で止まる):
   - ドラムは**手前の面が下から上へ**動く向き。帯の筋や模様が上へ流れて見えること。
   - ビームは**手前の面が上から下へ**動く向き。
   - ビームには、回っていることが分かる印を足す。円盤の面の放射の線か、巻いた糸の筋が流れる形。軸の両端の位置は今のまま固定。
   - 回る角度は controller が時間で進める(今のドラムの角度と同じ仕組み)。描く向きの符号は `geometry.ts` か `params.ts` の定数にし、テストで確かめる。
3. **糸を付ける(`attach`)の絵**:T3-06 で入った、引っぱる糸の線は残す。大きさと位置が変わったドラムに合わせる。
   - 当たり判定は T3-06 の `geometry.ts` の関数を使い、今の絵と合っていること。
   - 押さえる所の幅は 64px 以上(T3-06 の決まり)。
4. 盤面は、Fold 8 の4通り・1180×820・iPhone 393×852 と 852×393 で、ドラムとビームと円盤が切れずに収まること。

5. **T3-06 の確認で見つかった不足(2026-10-09 確認役。ルビーが止まっているので、ここで一緒に直す)**:
   - 張りのランプ:T3-06 ではドラムの胴の真ん中に重なっている(`lampY` = ドラムの縦の中央)。ドラム巻きと同じく、**ドラムの胴に重ならない所**(ドラムの上の空き)に置く。ランプの直径は今のまま(半径 22)。
   - 糸を離してよい所 `hitBeamWind`:今は目標の巻き幅 `widthCm` で円盤の位置を決めている。**実際の円盤の位置 `leftCm`・`rightCm`** を使う(引数を state から取る形でよい)。テストも合わせる。
   - controller のテストが足りない(T3-06 の仕様で求めたもの)。次の3つを足す:①ドラムの端を押さえて、ビームでない所で離すと `attach` のまま、②糸を引っぱっている途中の `pointercancel` で `attach` のまま・糸の線が消える、③糸を引っぱっている途中で unmount しても例外が出ず、そのあとの pointerup で何も起きない。

- 角度が進むと、ドラムの筋の y が上へ動く。ビームの印は下へ動く。速さ 0 では角度が変わらない。
- 色の直書きが無い。
