# PU-34 スタート画面のカード:ドラム巻きも「お題 N」にする

- 目的:管理者の質問(2026-10-10、会話)「スタート画面でドラム巻きだけ『お題 15』ではなく『初級・中級・上級』にしている理由は?」。
  - 理由(確認役が調べた):PU-03a(2026-10-01)でスタート画面のカードを作ったとき、ドラム巻きにはお題の一覧が無く、レベルが3つだけだった。T2-14(2026-10-03)でお題を15題にしたが、カードの文を直し忘れていた。
- 前提:PU-33(main)。
- 担当:ルビー。
- 進め方:1コミット+「PU-34 の報告」(`docs/progress_log.md`)。テストを先に書いて RED を確かめる。push の前に `npm run check`・`npm test`・`npm run build`。version は main より大きく、package-lock もそろえる。一時的なファイルをコミットに入れない。

## 変更してよいファイル

`src/app/screens/homeCards.ts`・`homeCards.test.ts`(無ければ `homeScreen.test.ts`)、`package.json`・`package-lock.json`、`docs/progress_log.md`

## 決まり

1. `gameStatusText('winding')` を「お題 N」にする。N はドラム巻きのお題の数(`windingPuzzles(getContent()).length`)。
2. ほかのゲームも、**それぞれのゲームのお題の一覧の数**を使う(今はクリール立ての数を流用している所がある)。ドラム設定・ビーミング・糸割りに、お題の一覧を返す関数があればそれを使う。無ければ今のまま(クリール立ての数)にして、報告に書く。

## テスト(先に書く)

- `gameStatusText('winding')` が「お題 15」(今のお題の数)。「初級」の字が無い。
- ほかのゲームの文が「お題 N」で、N がそのゲームのお題の数。
