## PU-09a:詰めた形の枠

- **詰めた形にする条件:** 画面の幅が 600px 未満、または高さが 560px 未満(CSS の px。回転のたびに判定し直す)。`viewport.ts` に `isCompact(w, h): boolean` を置き、`gameFrame` が使う。`game-frame--compact` のクラスを付ける。
- 詰めた形のとき:
  - 見出しの行は1段・低く(上下の余白 8px)。丸い「戻る」・題名(1行。入らなければ「…」で切る)・丸い「?」。**お題の名前(subtitle)は出さない。**
  - **メッセージ欄は、操作欄から盤面のカードの上の端へ移し、盤面に重ねる**(盤面の上に、`messageBg` の地・角 8・左右の余白 8px、最大2行。盤面の絵の上端の一部が隠れてよい)。操作欄の高さを使わないため。
  - 縦(幅 < 600px かつ 縦長):盤面は上、使える高さの **45%**。操作欄はその下。
  - 横(高さ < 560px かつ 横長):盤面は左、使える幅の **55〜60%**(ゲームが決める)。操作欄は右。
  - 操作欄の主な操作の区画は、画面の一番下に固定(今の sticky のまま)。
- 詰めた形でないとき(iPad・Fold 8 のメイン画面・1180×820 など)は、今の形のまま変えない。
- テスト:`isCompact` の境目(599/600、559/560)。詰めた形で `game-frame--compact` が付き、メッセージ欄の親が盤面のカードになる。詰めた形でないときは今のまま(操作欄の中)。回転(大きさを変えて `resize`)で切り替わる。

## PU-09b:クリール立て

- **依頼書の重ね表示:** 詰めた形のときだけ、操作欄の依頼書を「依頼書を見る」ボタン(secondary)にする。押すと、**下から出る重ね表示**(`core/ui/sheet.ts`。画面の下半分の高さ、白地・上の角 16・上端に縞・見出し「依頼書」・右上に丸い × で閉じる)で依頼書を出す。盤面は上に見えたまま。重ね表示の外の盤面を押しても閉じない(× か「依頼書を見る」をもう一度押して閉じる)。開いたまま箱からチーズを引っぱれる必要はない(閉じてから操作する)。
- **糸の箱:** 詰めた形の縦では、箱を**横一列**に並べ、指で横に送れる(`overflow-x: auto`。箱は幅 120px・高さ 72px)。**箱の上で横に送る動き(スクロール)と、箱からチーズを引っぱる動きがぶつからないように**:箱の上で指を置いて、まず**上方向**(盤面の方)へ動いたら引っぱり、**横方向**へ動いたらスクロールにする(最初の 8px の動きの向きで決める。`touch-action: pan-x` を箱に付け、引っぱりと決まったら `setPointerCapture`)。横の形では、箱を縦に並べて縦に送る(引っぱりは左方向=盤面の方)。
- 一番下の区画:「ヒント」と「確認する」(今のまま)。
- 詰めた形でないときは、今の操作欄のまま。
- テスト:詰めた形で「依頼書を見る」が出て、押すと重ね表示が開き、× で閉じる。依頼書の行が重ね表示の中にある。詰めた形でないときは「依頼書を見る」が無い。箱の上で横に 20px 動かしても引っぱりにならない、上に 20px 動かすと引っぱりになる(縦の詰めた形)。

## PU-09c:横向きのペダル(すべての画面)

- `createPedalControl` を横向きにする:**横長の溝**(高さ 64px、幅は操作欄いっぱい)の中を、**横木(つまみ)が左右に動く**(左が 0・右が 100)。溝の左に「戻す」、右に「踏み込む」のボタン(今のまま押すたびに一段ずつ)。溝の上を指で左右に動かしても合わせられる(今の縦の溝と同じ操作を横にしたもの)。指を離してもその位置を保つ(今のまま)。
- 押せないとき(巻いていないとき)の点線の形と理由の出し方(PU-05c)は今のまま。
- 速さの表示(「速さ 40」)は溝の右上に小さく(20px)。
- テスト:横木の位置が `left` の割合で決まる(0 で左端、100 で右端)。溝の上で左右に動かすと値が変わる。「戻す」「踏み込む」の動きは今のまま。

## PU-09d:ドラム巻き

- 操作欄の並び(すべての画面):メッセージ(詰めた形では盤面の上)→ 1行の情報(帯・巻いた長さ・時間)→ 張りのメーター(横いっぱい)→ 横向きのペダル → 一番下に主な操作。
- 詰めた形の縦:盤面は上 45%、横:盤面は左 55%。
- テスト:操作欄に横向きのペダルがある。詰めた形の縦で、操作欄の中身(情報・メーター・ペダル・主な操作)が、スクロールなしで高さ 915 − 盤面 − 見出しに収まる(jsdom で寸法を決めて確かめる形でよい)。

## 確認(本番と同じビルド)

- **Fold 8 のカバー画面に近い大きさ**:縦 412×915 と、横 915×412(どちらも文字の大きさ 段階1 と 段階3)。クリール立て(段階5)とドラム巻き(上級)で、操作欄の全部の部品が、スクロールなしか、箱の横送りだけで使えること。メッセージが盤面の上に見えること。依頼書の重ね表示が開いて閉じること。
- 1180×820 と 960×720:今の形が崩れていないこと(ペダルは横向きになる)。
- JavaScript の計測で、横のはみ出し無し、20px 未満の文字無し、64px 未満の押す部品無し。スクリーンショットが取れない場合は、そう書く。
