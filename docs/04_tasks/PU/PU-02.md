## PU-02a の部品(`layout.ts`)

```ts
export function createScreenHeader(opts: {
  title: string;             // 明朝で中央
  subtitle?: string;         // 題名の下に小さく(20px・muted)
  onBack?: () => void;       // 左の「戻る」(icon 'back')。無ければ空の枠
  right?: HTMLElement;       // 右の枠(「遊び方」のボタンなど)。無ければ空の枠
}): HTMLElement;             // 上端の縞を含む

export function createPage(opts: { width: 'form' | 'list' | 'full' }): HTMLElement;
// form: 中身の幅 820px で中央、list: 左右に --page-pad、full: 余白なし(ゲームの画面)

export function createCard(): HTMLElement;
export function createSectionHeading(text: string, opts?: { underline?: boolean }): HTMLElement;

export function createListRow(opts: {
  swatch?: HTMLElement;      // 左の 40px の見本(柄や色)
  name: string;
  meta?: string;             // 補足(例「1段×6本」)
  status:
    | { kind: 'stars'; stars: 0 | 1 | 2 | 3 }
    | { kind: 'next' }       // 「次はこれ」と藍の枠
    | { kind: 'locked'; reason: string }; // 鍵と地の色。押すと onLocked(reason)
  onClick: () => void;
  onLocked?: (reason: string) => void;
}): HTMLButtonElement;

export function createStars(n: 0 | 1 | 2 | 3, size: 'list' | 'result'): HTMLElement; // aria-label="星n"
```

- 見た目・大きさ・余白は 07 のとおり。**数値は PU-01 の変数(`--sp-*`・`--r-*`・`--c-*`)だけを使う。**
- 見出しの行の3つの枠は `display: grid; grid-template-columns: 180px minmax(0, 1fr) 180px`(600px 未満は 120px)。題名は 2 行まで折り返し、小さくしない。
- テスト(`layout.test.ts`):
  - 見出しの行:`onBack` を渡すと左に「戻る」、渡さなければ左の枠は空。右の枠は `right` が無くても存在する。題名の要素に見出し用の書体のクラス。上端の縞の要素がある。
  - 一覧の行:3つの状態で、正しいクラスと文字(「次はこれ」、鍵のアイコンと理由)。locked を押すと `onLocked(reason)` が呼ばれ、`onClick` は呼ばれない。
  - 星:`aria-label` と、取った数だけ `.stars__on`。
  - (`base.css` を読むテスト)`.screen-header` の `grid-template-columns`、600px 未満の上書き。

## PU-02b の部品

- **ダイアログ**(`confirmDialog`・`textInputDialog`):**見出しを必須にする**(`title: string`。今の `message` は本文として残す)。上端に縞、見出しは明朝、本文 22px。ボタンは左に取り消し(`secondary`)、右に決定(`primary`)。背景を押しても閉じない(今のまま)。
- **結果の画面**(`showResult`):07 の 7 節のとおり。

  ```ts
  export function showResult(parent: HTMLElement, opts: {
    stars: 1 | 2 | 3;
    preview?: HTMLElement;          // 仕上がりの絵(柄やドラム)。呼び出し側が作る
    lines: { label: string; value: string }[]; // 成績(左に項目、右に値)
    hint?: string;                  // 星3の条件(例「1回目で合えば星3です」)
    newPatternNames: string[];
    next?: { label: string };       // あれば右に primary。無ければ「一覧へ」が primary
  }): Promise<'list' | 'again' | 'next'>;
  ```

  - 見出し「完了しました」(明朝)と「お疲れ様でした」(22px・muted)は部品の中に固定で書く。今の `praise`(ほめる一言)は使わない(大人向けの決まり)。
  - 星は1つずつ 0.3 秒で現れる。`prefers-reduced-motion: reduce` では、すぐに全部出す。
  - ボタンの並び:左から「一覧へ」「もう一度」(secondary)、右に `next`(primary)。
  - **今の呼び出し(`praise`・`againLabel`・`homeLabel`・`lines: string[]`)も、PU-05 までは型の上で通るようにしておく**(`lines` が文字列の配列なら「値なし」の行として出す、`'home'` は `'list'` として返す、など。やり方は報告に書く)。
- **遊び方**(`showTutorial`):ダイアログの形。上端に縞、見出し(明朝。遊び方の題名)、ページ番号「1 / 3」、左に「前へ」(1ページ目は出さない)、右に「次へ」(最後は「始める」を primary)。
- テスト:
  - ダイアログ:見出しと本文が出る、取り消しが左・決定が右、決定が primary。
  - 結果:見出しと「お疲れ様でした」、成績の行が「項目・値」の2つの要素、`next` があると右に primary で押すと `'next'`、無いと「一覧へ」が primary。
  - 遊び方:「前へ」で前のページに戻る、1ページ目に「前へ」が無い、最後のページで「始める」。
