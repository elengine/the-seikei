## PU-05a:枠と結果のつなぎ

- `createGameFrame` の上の帯を `createScreenHeader` に置き換える(左「戻る」、中央にゲーム名と、その下に今のお題 `subtitle`、右に「遊び方」)。`setSubtitle(text)` を `GameFrame` に足す。
- 盤面:`kinariDeep` の地・`line` の枠・角 14 のカードの中に Canvas。操作欄:白いカード(角 14、中の余白 20)。2つのあいだは 24px(横長は左右、縦長は上下)。盤面と操作欄の幅の割合(`splitWidths`)は今のまま。
- メッセージ欄は操作欄の一番上(07 の 7 節の見た目。2行ぶんの高さを保つ決まりは今のまま)。
- 主な操作の区画は、操作欄の一番下(`position: sticky; bottom: 0` の今の決まりを保つ)。
- **結果の画面のつなぎ:** `GameResult` に `resultLines?: { label: string; value: string }[]`・`starHint?: string`・`next?: { label: string; start: () => void }` を足す(今の `summary` は、`resultLines` が無いときの代わりとして残す)。`gameScreen` は `showResult` の新しい形で出し、`'next'` なら `next.start()`、`'list'` なら一覧へ、`'again'` なら同じお題をやり直す。
- 今の `praise`(ほめる一言)は使わない。
- テスト:枠に見出しの行と2つのカード。`setSubtitle` で文字が変わる。結果で `'next'` を選ぶと `next.start` が呼ばれる。

## PU-05b:クリール立ての操作欄

- 見本の「A ゲームの画面」の操作欄の並び:メッセージ → 依頼書(節の見出し「依頼書」・今選んでいる箱と同じ品番の行を藍の枠)→ 糸の箱(節の見出し「糸の箱」・箱は `woodLight` の枠の白いボタン、選んでいる箱は藍の塗り・白文字・✓)→ 一番下に「ヒント」(`secondary`。使えないときは `lockedReason`「2回確認すると使えます」)と「確認する」(`primary`、右、幅を広く)。
- **「立てる・外す・調べる」の切り替えは、この PU-05b では残す**(PU-07 で無くす)。見た目は `createChoice`。
- ゲームの中の `audio.play('tap')` を消す(ボタンの部品が鳴らす)。
- 結果:`resultLines`(「確認した回数」「ヒント」)、`starHint`「1回目で合えば星3です」、`next`(次のお題があれば「次のお題へ」)。
- **「現在の帯の並び」の欄は無くす**(管理者の了承、2026-09-30、会話。盤面と同じ情報の繰り返しで、軸の番号で足りるため)。`gameFrame` の `footer` をクリール立てで使わなくなる(部品は残してよい)。
- 代わりに、**依頼書の各行に、その糸が何本目から何本目かを書き添える**(例「W-4812 紺 × 4(1〜4本目)」「W-2200 白 × 1(5本目)」。20px・`muted`)。
  - 依頼書が「1リピート分 + ↻ くりかえし × N」の形(T1-10 追加修正)のときは、1リピート分の行に番号を付け、くりかえしの行に「(7本目から同じ並びを N 回)」のように書く。
  - **段階1〜3だけ出し、段階4・5では出さない**(手応えを残すため。管理者の決定)。出す段階の上限は `src/games/creel/params.ts` に `ORDER_RANGE_MAX_STAGE = 3` として置く(遊んでから調整する)。
  - テスト:段階2のお題で「(1〜4本目)」の形の文字が出る。段階4のお題では出ない。くりかえしの行の番号が正しい。
- テスト:「確認する」が primary で操作欄の一番下の右。ヒントが使えないとき、押すと理由が出る。

## PU-05c:ドラム巻きの操作欄

- メッセージ → 帯の番号・巻いた長さ・経過時間(1行、20px)→ 張りのメーター(節の見出し「張り」)→ ペダル(節の見出し「ペダル」。溝と「戻す」「踏み込む」は `secondary`)→ 一番下に主な操作(「巻き始める」「帯の端を結ぶ」、`primary`)。
- ペダルの溝・横木・メーターの色を tokens の新しい色に合わせる(横木は `wood`、適正の帯は `machineLight`、針は `sumi`)。T2-08 追加修正の「状態の文字の幅を固定」「横にあふれない」の決まりは保つ。
- ゲームの中の `audio.play('tap')` を消す。
- 結果:`resultLines`(「適正な張りで巻いた割合」「巻いた時間」「糸切れ」「違う糸を押した回数」「違う端を結ぼうとした回数」)、`starHint`「適正な張りが8割以上、目標の時間内で星3です」、`next`(次の難易度が解放されていれば「中級へ」など)。
- テスト:主な操作が primary で一番下。結果の行の数。
