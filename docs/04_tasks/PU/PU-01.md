## PU-01b:書体の埋め込み

- **Shippori Mincho(Bold 700)**と **BIZ UDPGothic(Regular 400・Bold 700)**を使う。どちらも SIL Open Font License 1.1。
- 入手先は Google Fonts の公式のリポジトリ(`github.com/google/fonts` の `ofl/shipporimincho`、`ofl/bizudpgothic`)の TTF。ほかの配布元から取らない。
- **文字を絞った woff2 を作る**(`fonttools` の `pyftsubset`、`--flavor=woff2`)。含める文字:ASCII、かな(ひらがな・カタカナ)、全角の英数字と記号、JIS 第1・第2水準の漢字、`src/content/*.json` と `src/**/*.ts` の中に出てくる文字すべて(漏れを防ぐため)。
  - 作り方(コマンドと、含めた文字の範囲)を `public/fonts/README.md` に書く。
  - `pyftsubset` が使えない環境なら、作業を止めて報告する(絞らない大きなファイルを入れない)。
- 置き場所:`public/fonts/ShipporiMincho-Bold.woff2`、`public/fonts/BIZUDPGothic-Regular.woff2`、`public/fonts/BIZUDPGothic-Bold.woff2`、`public/fonts/OFL.txt`(両方の著作権表示を含む)。
- `base.css` の先頭に `@font-face`(`font-display: swap`、`src: url('/the-seikei/fonts/…')` ではなく、`base` に依存しない相対の書き方にする。ビルド後に読めることを確かめる)。
- `tokens.ts`:`FONT_FAMILY = '"BIZ UDPGothic", "Hiragino Sans", "Noto Sans JP", sans-serif'`、`FONT_FAMILY_HEADING = '"Shippori Mincho", "Hiragino Mincho ProN", serif'`。`base.css` の `--font-family` と `--font-family-heading` も同じ。
- `vite.config.ts` の `globPatterns` に `woff2` を足す(オフラインで書体が出るように、事前保存に入れる)。
- 容量:3つの woff2 の合計が 8MB を超えたら、報告に書く(超えてもよいが、確認役が判断する)。
- テスト:`tokens.test.ts` に「`FONT_FAMILY` と `--font-family`、`FONT_FAMILY_HEADING` と `--font-family-heading` が一致」「`base.css` に3つの `@font-face` があり、`font-display: swap`」。
- 確認:ビルドしたものを開き、開発者ツールで3つの書体が読み込まれていること、機内モード相当(オフライン)で再読み込みしても書体が出ることを確かめる。

## PU-01c:ボタンの作り直し

- `createButton` を次の形にする(今の呼び出しは、`variant` の既定を `secondary` にしても動くようにする):

  ```ts
  interface ButtonOpts {
    label: string;
    variant?: 'primary' | 'secondary' | 'danger'; // 既定は 'secondary'
    size?: 'normal' | 'large'; // 既定: primary は 'large'(72px)、ほかは 'normal'(64px)
    icon?: 'back' | 'next' | 'check' | 'settings'; // 線の SVG。文字の前(back・check・settings)か後ろ(next)
    lockedReason?: string; // 指定すると「押せない」形。押すと onLocked(lockedReason) を呼ぶ
    onLocked?: (reason: string) => void;
    sound?: boolean; // 既定 true
    onClick: () => void;
    testId?: string;
  }
  export function createButton(opts: ButtonOpts): HTMLButtonElement;
  export function setLockedReason(btn: HTMLButtonElement, reason: string | null): void;

  interface ChoiceOpts<T extends string> {
    options: { value: T; label: string }[];
    value: T;
    onChange: (v: T) => void;
    ariaLabel: string;
  }
  export function createChoice<T extends string>(opts: ChoiceOpts<T>): { root: HTMLElement; setValue(v: T): void };

  /** boot で1回だけ呼ぶ。ボタンを押したときの音 */
  export function setButtonSound(play: () => void): void;
  ```

- 見た目は 07 の 6 節のとおり(`primary`・`secondary`・`danger`・押せない形・`choice`)。押している間は 4px 沈み、厚みが 1px(`:active`)。0.1 秒。
- `click` で動く(`pointerdown` で動かさない)。音は `click` の中で鳴らす(`sound: false` なら鳴らさない)。**各画面の `audio.play('tap')` は、この後のタスクで消す**(PU-01c では消さない。音が2回鳴らないよう、PU-01c の時点では `setButtonSound` を boot で設定しない。PU-03 で設定し、同時に各画面の `play('tap')` を消す)。
- 押せない形:`lockedReason` があるとき、`.btn--locked`(点線の枠)。`disabled` 属性は付けない。押すと `onClick` ではなく `onLocked` を呼ぶ。
- iPad Safari:`.btn` に `-webkit-appearance: none`、`touch-action: manipulation`、`-webkit-tap-highlight-color: transparent`。`boot.ts` で `document.addEventListener('touchstart', () => {}, { passive: true })` を1回(`:active` を効かせるため)。
- `:focus-visible` の輪(藍 3px)は残す。
- テスト(`widgets.test.ts`):
  - 3つの種類で、正しいクラスが付く。既定は `secondary`。`primary` の既定の大きさは `large`。
  - `lockedReason` があると `.btn--locked` が付き、`disabled` 属性が無く、押すと `onLocked` が理由付きで呼ばれ、`onClick` は呼ばれない。`setLockedReason(btn, null)` で元に戻る。
  - `setButtonSound` を設定すると、押すたびに1回呼ばれる。`sound: false` なら呼ばれない。
  - `createChoice`:選んだものに `aria-pressed="true"` と ✓、押すと `onChange`。`setValue` で表示が変わり、`onChange` は呼ばれない。
  - (`base.css` を読むテスト)`.btn:active` に `transform: translateY(4px)`。`.btn` に `-webkit-appearance: none` と `touch-action: manipulation`。
