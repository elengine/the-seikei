## 動き

- **引っぱって置く:** 糸の箱の上で指を置き(`pointerdown`)、動かし始める(8px 以上動いたら)と、指より 40px 上にチーズが現れて指について来る。
  - 盤面の上では、指を離す位置から一番近い軸(軸の間隔の 0.6 倍以内)を「吸い付く先」として、`aiTint` の地と藍の輪で示す。
  - 離すと、その軸にチーズが嵌まる(0.15 秒で吸い込まれる動き)。音は `knot` に近い短い音(今ある音から選ぶ。新しく作るなら `sounds.ts` を変えてよいが、そのときは報告に書く)。
  - 吸い付く先が無い所で離すと、チーズは箱へ戻る(0.2 秒)。
  - すでにチーズがある軸に嵌めると、入れ替え(前のチーズは箱へ戻る)。
- **引っぱって外す:** 立っているチーズの上で指を置いて 8px 以上動かすと、そのチーズを持ち上げる。クリールの外(盤面の外、または操作欄の上)で離すと外れる。ほかの軸の上で離すと、その軸へ移す(入れ替えの決まりは同じ)。
- **押すだけでも置ける:** 箱を押す(動かさずに離す)と、その箱を選ぶ(藍の塗り・✓。今の決まり)。そのあと空いた軸を押すと立つ。チーズのある軸を押すと、品番の吹き出し(今の「調べる」)。
- **「立てる・外す・調べる」の切り替えは無くす。**
- 横長では、箱は盤面の右(操作欄の中)、縦長では下。どちらからでも、操作欄から盤面へ引っぱれる。**引っぱっているチーズは、盤面(Canvas)と操作欄(DOM)の両方の上を通るので、画面全体の上の重ね(`position: fixed` の要素)で描く。** 盤面の上に来たら、Canvas の吸い付く先の表示と同期する。
- **iPad Safari への備え:** 盤面と箱に `touch-action: none`。`pointerdown` で `setPointerCapture`。引っぱっている間は画面をスクロール・拡大させない。`pointercancel`(着信や通知で指が外れたとき)では、チーズを箱へ戻す。2本目の指は無視する。
- 裏に回ったとき(`visibilitychange`)は、引っぱっている途中の動きを取り消す。unmount で、すべての監視を外す。

## `drag.ts`(純粋な関数)

```ts
export type DragSource = { kind: 'box'; yarn: YarnTypeId } | { kind: 'peg'; index: number };
export interface DragState { source: DragSource; start: { x: number; y: number }; current: { x: number; y: number }; moved: boolean }
export function beginDrag(source: DragSource, p: { x: number; y: number }): DragState;
export function moveDrag(s: DragState, p: { x: number; y: number }): DragState; // 8px 以上で moved
/** 離したとき。論理座標の点と盤面の形から、どうなるかを返す */
export function dropResult(s: DragState, pLogical: { x: number; y: number } | null, rows: number, cols: number):
  | { kind: 'place'; index: number }      // その軸に嵌める(入れ替えを含む)
  | { kind: 'remove'; index: number }     // 軸から外す(peg から盤面の外へ)
  | { kind: 'move'; from: number; to: number }
  | { kind: 'cancel' }                    // 箱へ戻す / 元の軸に戻す
  | { kind: 'tap' };                      // 動かさずに離した(押すだけの操作)
```

- テスト(`drag.test.ts`):8px 未満は `tap`。箱から軸の近くで離すと `place`。遠くで離すと `cancel`。軸から盤面の外(`pLogical` が null)で離すと `remove`。軸から別の軸で `move`。同じ軸で離すと `cancel`。
