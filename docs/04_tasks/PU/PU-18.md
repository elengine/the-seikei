# PU-18 管理者メニュー:すべてのお題を開ける(確認用の鍵の解除)

- 目的:管理者の依頼(2026-10-07、会話)「各ゲームの一覧で、クリアしなくてもすべて遊べるようにする(鍵の解除)。これが無いと、すべてクリアしないと高いレベルの動作を確かめられない」。
- 前提:PU-17。
- 進め方:1つのコミット。テストを先に書き、RED を確かめてから直す。version を patch で上げる。報告のコミットには `docs/progress_log_pu.md` だけを入れる。
- ルビーは同時に `src/games/winding/` の logic・panel・controller などを作業している。この PU で触ってよいのは `src/games/winding/listView.ts`・`listView.test.ts`・`index.ts`(一覧に設定を渡す所だけ)のみ。

## 決まり

- 設定に `unlockAll: boolean`(初期値 false)を足す(`SettingsData`・`DEFAULT_SETTINGS`・読み込みの直し。古い保存データに無いときは false)。端末の中だけの設定(バックアップには今の設定と同じ扱いで入ってよい)。
- 管理者メニュー(設定の一番下の「管理者」→ 暗証番号のあと)に、切り替え「**すべてのお題を開ける(確認用)**」を置く(今の部品の切り替え。64px 以上)。説明の1行「クリアしていないお題も遊べます。記録(星)は変わりません」。
- `unlockAll` が true のとき、**すべてのゲームの一覧**(クリール立て・ドラム巻き・ドラム設定・ビーミング・糸割り)で、鍵の付いたお題(`kind: 'locked'`)を、押せば遊べる形にする。見た目は、星の無いふつうの行(「次はこれ」も鍵も出さない。`createListRow` に `kind: 'open'` が無ければ足してよい)。星を取ったお題・「次はこれ」・「途中」の表示は今のまま。
- 一覧のほかに鍵で止めている所(お題を始めるとき・「次へ」で次のお題に進むとき・仕事のモードなど)があれば、同じ設定で開ける(`grep` で探して報告に書く)。
- 記録(星・最高記録)の付け方は変えない。切り替えを false に戻せば、元の鍵の表示に戻る(記録は消さない)。
- 設定が変わったら、開いている一覧を読み直す(`repo.subscribe` の今の仕組み)。

## 変更してよいファイル

`src/core/settings/settings.ts`・`settings.test.ts`、`src/app/screens/adminScreen.ts`・`adminScreen.test.ts`、`src/core/ui/layout.ts`・`layout.test.ts`(`kind: 'open'` を足すときのみ)、各ゲームの `listView.ts`・`listView.test.ts` と `index.ts`(一覧に設定を渡す所・鍵で止めている所のみ)、`package.json`・`package-lock.json`(version)、`docs/progress_log_pu.md`

## テスト(先に書く)

- 設定:`unlockAll` の初期値が false、古い保存データでも false。
- 管理者メニュー:切り替えがあり、押すと設定が true になる。
- 各ゲームの一覧:`unlockAll` が true なら鍵の行が無く、すべての行が押せる。false なら今のまま(最初の未クリアが「次はこれ」、その先は鍵)。星の表示は変わらない。
