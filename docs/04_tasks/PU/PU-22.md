# PU-22 設定画面:ゲームの記録を消す(2回の確認つき)

- 目的:管理者の依頼(2026-10-08、会話)「設定画面に、ゲームの進み具合のデータを消す機能を足す。データを消す操作なので確認も必要」。
- 前提:PU-21(main の最新から)。
- 進め方:1つのコミット。テストを先に書き、RED を確かめてから直す。version を patch で上げる(main より大きく)。報告のコミットには `docs/progress_log_pu.md` だけを入れる。

## 消すもの・残すもの(確認役が決めた)

- **消す**:すべてのゲームの記録(`records`。星・最高記録・次はこれ・鍵の進み)、途中の状態(`sessions`。「続きから」)、図鑑(`zukan`。仕上げた柄)。
- **残す**:設定(`settings`。お名前・屋号・文字の大きさ・音・管理者メニューの「すべてのお題を開ける」など)、呼び名(`terms`)、`shop`・`memories`。
- 消し方は今の保存の仕組みの `repo.remove`(削除の印 `deletedAt` を付ける形。将来の同期と合う)で、上の3つの集まりの行を1つずつ消す。データベースそのもの(`seikei-game`)は消さない・作り直さない。
- 消したあと、記録を覚えている部品(一覧・ホームのカードの状態など)が、`repo.subscribe` の今の仕組みで読み直されること(画面を開き直さなくても、ホームに戻れば星が消えている)。

## 画面

- 設定画面の**下のほう**(「管理者」の上)に、節「記録」と、ボタン「**ゲームの記録を消す**」(危険のボタンの見た目:白地・朱の枠。64px 以上)。説明の1行「星・途中の状態・図鑑を消します。お名前や設定は残ります」(20px 以上)。
- 押すと、**1回目の確認**(今の確認の重ね表示):題名「ゲームの記録を消しますか」、本文「すべてのゲームの星と途中の状態、図鑑が消えます。お名前・屋号・設定は残ります」、ボタン「はい」「いいえ」。
- 「はい」を押すと、**2回目の確認**:題名「本当に消しますか」、本文「消した記録は元に戻せません。残しておきたいときは、先にバックアップを書き出してください」、ボタン「**消す**」(危険の見た目)と「やめる」。※2回目は、押し間違いを防ぐため「はい」「いいえ」ではなく、何が起きるか分かる言葉にする。
- 「消す」を押したら消して、短いお知らせ(今の部品)「記録を消しました」。失敗したら「消せませんでした。もう一度お試しください」(記録をログに残す)。
- どちらかの確認で「いいえ」「やめる」・重ね表示の外を押した場合は、何も消さない。
