## PU-24a:立体に見える絵(管理者の指摘)

- **ドラム**:管理者「ドラムの両側が丸い灰色の台になっているが、立体なら片側しか側面は見えない。ドラム巻きのゲームを見ればわかる」。→ ドラム巻きと同じく、**少し斜めから見た構図**にする。横に寝かせたドラムの**片側の端だけ**が楕円の面として見え(例:右の端。手前に回り込んだ側)、反対の端は円筒の輪郭の曲線だけ。胴の糸の筋は、円筒の丸みに沿って曲がる(ドラム巻きの `surfaceY` と同じ考え。ビーミング用に `geometry.ts` に置く)。
- **ビーム**:管理者「ビームの円盤の真ん中に軸が通っている形でなければならないのに、今は円盤の上に棒が乗っているように見える」。→ 軸は**円盤の中心を貫く**(円盤の楕円の中心の高さ = 軸の中心の高さ)。軸は円盤の手前では円盤の後ろに隠れ、外側へ飛び出して見える(円盤は穴の空いた楕円の面、厚みを少し付ける)。巻いた糸は、軸のまわりに、円盤と同じ向きの楕円の端を持つ円筒として太る。
- **軸の長さは変えない**:管理者「円盤の位置を左右に動かして幅を調整する仕組みなので、軸の長さは変えないでほしい」。→ 軸の両端の位置は**いつも同じ**(盤面に対して固定)。円盤だけが軸の上を左右に動く。
- ドラムからビームへの糸のシートは、ドラムの下からビームの巻いた糸の上へ、斜めの面として続く(今の考えのまま、構図に合わせて直す)。
- 「乗り上げ」の朱の文字と縁は、T3-05 で偏りが無くなるので描かない。
- テスト:ドラムの端の楕円の面が片側だけ/軸の中心の高さ = 円盤の中心の高さ/円盤を動かしても軸の両端の x が変わらない/巻いた糸の太り方が軸を中心に上下対称/色の直書きが無い。

## PU-24b:茶色の棒を引っぱって速さを変える

- 管理者「速さの調整は、今は茶色い横棒の下にボタンが3つあるが、そのボタンは要らない。茶色い横長の棒そのものを指で左右に引っぱって速さを変える。速さ 0 のときは茶色い棒が左に少し寄っている。右にずらすほど速くなる。今の速さを画面のどこかに 0〜100 の数字で出す」。
- 茶色の棒(ガイドの棒)を、**横に動く**部品にする:速さ 0 で、棒の真ん中が盤面の中心より左へ寄った位置(`SPEED_BAR_SHIFT_MAX` の分だけ左)。右へ動かすほど速く、いちばん右で 100。指で棒のどこを押さえても引っぱれる(当たり判定は棒の上下 32px ずつ。64px 以上)。引っぱるあいだは画面がスクロール・拡大しない。`pointercancel` では引っぱる前の速さに戻す。今の「停止・50%・100%」の3つの丸いボタンと「適正」の札は無くす。
- **速さの数字**:操作欄の「巻き量」の下に「**速さ 63**」(0〜100 の整数。32px 以上)。適正な速さのときは藍、外れているときは朱の文字に「▲」(速すぎ)か「▼」(遅すぎ)を添える(色だけに頼らない)。
- 幅合わせの段階では棒は動かない(押せない形。引っぱっても動かない)。
- テスト:棒を右へ引っぱると `setSpeed` の値が増える/いちばん左で 0・右で 100/3つのボタンが無い/速さの数字と、適正・外れの表示/幅合わせの段階では動かない/`pointercancel` で戻る。
