# PU-04 クリール立てとドラム巻きの一覧を、共通部品で組み直す

- 目的:2つのゲームの一覧を同じ形にする(今は幅・「未解放」の出し方・行の高さが違う)。
- 関連:`docs/07_ui_design.md` の 5.3・7 節。見本の「A お題の一覧」。
- 前提:PU-02
- 進め方:1つのコミット。テストを先に書く。

## 変更してよいファイル

`src/games/creel/listView.ts`、`src/games/creel/listView.test.ts`(新規可)、`src/games/winding/listView.ts`、`src/games/winding/listView.test.ts`(新規可)、`src/styles/base.css`(`.creel-list`・`.winding-list` の節を消し、共通部品に置き換え)、`PROGRESS.json`、`docs/progress_log.md`

## 形

- `createScreenHeader`(題名はゲーム名、左に「戻る」、右に「遊び方」)+ `createPage({ width: 'list' })`。
- **クリール立て:** 段階ごとに節の見出し(茶・下線。例「段階1 無地」。段階の名前は `creelPuzzles.json` にあればそれを、無ければ「段階N」)。各お題は `createListRow`:
  - 見本:お題の柄の小さな四角(`fabricPreview` の描き方を使ってよい。40px)。
  - 名前:お題の名前。補足:「1段×6本」。
  - 状態:クリア済みは星(取った数)、次に遊ぶお題は「次はこれ」、未解放は鍵と理由「前のお題をクリアすると遊べます」。
  - 「次に遊ぶお題」=解放済みで、まだ星が無いお題のうち、一番先のもの。
- **ドラム巻き:** 節は1つ(見出し「難易度」)。各難易度を `createListRow`:見本はその難易度の柄、名前「初級」など、補足「帯 3本」、状態は同じ決まり。
- 列:幅 900px 以上は 2 列(段階の節ごとに左右に並べる)、未満は 1 列。
- 途中のお題(続きから)がある場合の今の動き(T1-15 追加修正)は変えない。
- テスト:
  - 未解放の行を押すと理由が出て、ゲームは始まらない。
  - 「次はこれ」が1つだけ付く。すべてクリア済みなら付かない。
  - クリール立ての節の数が、段階の数と同じ。
