## 決まり

### 1. 横から見た形を数値で持つ(`side.ts`、a)

- 奥行き `z`(手前が +)と高さ `h`(上が +)の平面に、ドラム・鉄の棒1・鉄の棒2・ビーム・速さの木の棒を、上の表の**比率のまま**置く。数値は `params.ts`(`SIDE` のようにまとめる)。ビームの半径は巻き量で太る(今の `woundRadius` の考え。円盤の半径は固定)。
- **糸の通り道**(横から見た線)を、円と接線でつくる:
  1. ドラムの円 → 鉄の棒1:ドラムの**下側**から出て、鉄の棒1の**上側**に接する線。
  2. 鉄の棒1 → 鉄の棒2:両方の**上側**に接する線。
  3. 鉄の棒2 → ビーム:鉄の棒2の**手前側**から、ビームの巻いた糸の円の**手前側**に接する線。
  4. それぞれの円の上は、接する点と点のあいだの円弧。
  - 角が無い(接線と円弧なので、向きが急に変わらない)。
- 関数の例:`sidePath(progress): { z: number; h: number }[]`(細かい点の列。ドラムの接点から、ビームの手前の面を下の端まで回る所まで)。

### 2. 横から見た形を正面の絵へ写す(投影、a)

- 正面の絵は、**手前の少し上・少し右から**見た形(今の絵と同じ考え)。式は次の形にし、係数は `params.ts`:
  - 画面の y = `Y0 − KH × h + KZ × z`(奥ほど上に見える。`KZ` は見下ろす角度)
  - 画面の x = 幅の位置(cm → `cmToX`) `− KX × z`(手前ほど左に見える。今の「(」の考えと同じ)
- ドラム・ビーム・鉄の棒・木の棒の**円筒は、両端の円をこの式で写した楕円と、そのあいだの面**で描く。ドラムの「(」や、ビームの巻いた糸の左の端の曲線は、この写した円の形になる(今の `drumArcX`・`beamArcX` は、この式で置き換える)。
- **糸の帯**は、横から見た糸の通り道(1)を、巻き幅の左の端と右の端でそれぞれ写した2本の線のあいだを塗る。縞も、柄の各位置で同じ通り道を写した線にする。
  - これで、帯の左の端は管理者の①の青の線のような、**なめらかに流れる1本の線**になる(鉄の棒の上で曲がり、ビームの手前を回り込む)。
- 隠れる所:奥のものから順に描く(ドラム → ドラムの下から出る帯 → 鉄の棒1 → 帯 → 鉄の棒2 → 帯 → ビームの左の円盤 → ビームと巻いた帯 → 右の円盤)。帯が棒やビームに乗る所は、乗っている側だけが見える。
- 盤面に収める:式の `Y0`・`KH`・`KZ`・`KX` と全体の大きさは、ドラムの上の端からビームの下の端と目標の点線までが、今の盤面の高さに収まるように決める。ドラムの直径はビームの円盤の直径の 1.5 倍以上(PU-26 のまま)。

### 3. 糸を付ける段階(`attach`)と速さの木の棒(b)

- 糸を付ける前(`setup`・`attach`):糸の帯は、ドラム → 鉄の棒1 → 鉄の棒2 まで来て、鉄の棒2から**まっすぐ下へ垂れ**、端に木の棒(PU-27)が付いている。木の棒を下へ引っぱって、ビームの手前の上の所まで来たら離すと付く(今の決まりのまま。当たり判定は写した位置で)。
- 速さの木の棒は、横から見た図の茶の位置(鉄の棒2の上)を写した所に置く。左右に動く決まり・当たり判定の大きさ(上下 64px 以上)は今のまま。
- 円盤の当たり判定・目標の点線・ランプは、写した位置に合わせる。動かし方の決まりは変えない。
