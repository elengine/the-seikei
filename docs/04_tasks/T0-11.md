# T0-11 用語辞書

- 目的:画面に出る整経用語とゲーム名を、利用者が変更できる辞書から引けるようにする。
- 関連要件:FR-C-04、03_basic_design 5章
- 前提:T0-05

## 作成するファイル

`src/content/terms.default.json`、`src/core/terms/terms.ts`、`src/core/terms/terms.test.ts`

## 仕様:terms.default.json

03_basic_design 5章の表のキーと初期値すべて。形式:

```json
{
  "drum": { "value": "ドラム", "description": "帯を順に巻き重ねる大きな円筒" },
  "game.knotting": { "value": "糸継ぎ", "description": "ゲームの名前" }
}
```

説明は 01_requirements 10章を参考に、1行で書く。ゲーム名の説明は「ゲームの名前」でよい。

## 仕様:terms.ts

```ts
export interface TermEntry { key: string; value: string; defaultValue: string; description: string; overridden: boolean; }
export interface Terms {
  t(key: string): string;                 // 上書きがあればそれ、なければ初期値。未知のキーはキー名をそのまま返す
  render(text: string): string;           // '{{drum}}に巻く' → 'ドラムに巻く'。未知のキーは '{{キー}}' のまま残す
  set(key: string, value: string): Promise<void>;   // 上書きを保存(terms コレクション、id = キー、data = { value })
  reset(key: string): Promise<void>;      // 上書きを消す(論理削除)
  entries(): TermEntry[];                 // 初期値ファイルの順
  onChange(cb: () => void): () => void;
}
export async function createTerms(repo: Repository, defaults: Record<string, { value: string; description: string }>): Promise<Terms>;
```

- 起動時に terms コレクションを読み込んでキャッシュし、`t()` は同期的に返す。
- `set` と `reset` の後はキャッシュを更新し、onChange を呼ぶ。
- 前後の空白は取り除いて保存する。空文字になる場合は `set` せずに `reset` と同じにする。
- 初期値ファイルにないキーの `set` は例外。

## テスト(fake-indexeddb と T0-05 の実装を使う)

1. 上書きがなければ初期値を返す。
2. `set('drum', '大枠')` の後、`t('drum')` が '大枠'。作り直した Terms でも '大枠'(保存されている)。
3. `reset` で初期値に戻り、`entries()` の overridden が false になる。
4. `render('{{drum}}に{{section}}を巻く')` の置き換え。未知のキーは残る。
5. 未知のキーの `t` はキー名を返す。未知のキーの `set` は例外。
6. `set` で onChange が呼ばれる。

- テストが通り、`npm run check` が成功する。
