## 2つの場面(お題の種類)

| 場面 | レベル | 困りごと | すること |
|---|---|---|---|
| チーズを分ける(`split`) | 1〜2 | 届いたチーズの数が、クリールに立てる数の半分 | チーズを口にかけ、空のコーンにチーズの長さの**半分**を巻く |
| 足りないコーンを作る(`refill`) | 3〜5 | ドラムに巻いている途中で、クリールの本数が足りなくなった | 残っているコーンの**余り**(あと巻く長さを超えたぶん)を、空のコーンに巻き取って本数をそろえる。足りなければ糸を継いで次のコーンから続ける |
