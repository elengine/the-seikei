## 長さの計算(`logic.ts` に関数で置く)

```ts
/** 番手から 1g あたりの長さ(m/g)。'2/48' → 24、'1/48' → 48、'2/60' → 30 */
export function metersPerGram(count: string): number;
/** 正味の長さ(m)=(重さ − 紙の芯の重さ)× m/g。小数は切り捨て */
export function lengthOf(grossG: number, coreG: number, count: string): number;
```

- 番手は糸のデータ(`yarns.json` の `spec`、例「ウール 2/48」)から読む。

## お題(`puzzles.ts`)

- クリール立てのお題 15 題から作る(柄と糸を同じにする。ほかのゲームと同じ考え)。糸は、その柄の**最初の糸**。
- レベル1〜2 は `split`、レベル3〜5 は `refill`。数は乱数を使わず、お題ごとに決まった値にする(同じお題は毎回同じ)。

```ts
export interface ItowariPuzzle {
  id: string; stage: 1 | 2 | 3 | 4 | 5; patternId: string; name: string;
  yarnId: string; count: string;          // 番手(例 '2/48')
  kind: 'split' | 'refill';
  coreG: number;                          // 紙の芯の重さ(レベル1〜4 は 0 として扱い、はかりは正味を出す。レベル5 は 20)
  sources: { id: string; grossG: number }[]; // 元のチーズ・コーン(はかりに載せた重さ)
  needCount: number;                      // クリールに要る本数(split:チーズの数 × 2。refill:元の本数 + 作る本数)
  needM: number;                          // 1本あたり要る長さ(m)
}
```

- 数の目安(`params.ts` の表。下は例。遊んで調整する):
  - レベル1(split):チーズ 6 個、どれも同じ重さ(正味 500g・2/48 → 12,000m)。クリールに要る本数 12(作るのは 6)。1本あたり要る長さ 5,500m。
  - レベル2(split):チーズ 15 個・要る本数 30(口は 12 なので 2 回に分けてかける)、重さが 3 通り(450・500・550g)。1本あたり要る長さは、いちばん軽いチーズの半分より少し短い値。
  - レベル3(refill):残りのコーン 6 本、クリールに 8 本要る、あと 1,200m。余りが 1,200m 以上のコーンが 2 本以上ある(1本から1本作れる)。
  - レベル4(refill):残り 6 本、要る 9 本、あと 1,500m。1本の余りでは足りず、**継いで**作る必要がある組み合わせを含む。
  - レベル5(refill):レベル4 と同じ形で、紙の芯 20g を引いて計算する。
  - どのお題も**解ける**こと(テストで確かめる:余りの合計 ≥ 作る本数 × 要る長さ)。

## ルール(`logic.ts`)

```ts
export interface Spindle {            // 口(最大 SPINDLES = 12)
  sourceId: string | null;            // 上の段にかけた元の糸
  running: boolean;                   // 握りを下ろして巻いているか
  woundM: number;                     // 下の空のコーンに巻いた長さ(m)
  ties: number;                       // この口で糸を継いだ回数
  needsTie: boolean;                  // 元の糸を替えたあと、継ぐ前
}
export interface ItowariState {
  puzzleId: string;
  phase: 'setup' | 'winding' | 'done';
  spindles: Spindle[];                // 長さ SPINDLES
  remaining: Record<string, number>;  // 元の糸ごとの残りの長さ(m)
  weighed: string[];                  // はかりに載せた元の糸の id
  made: number[];                     // 外した(仕上がった)コーンの長さ(m)
  meterM: number;                     // メーター(巻き始めてからの長さ)
  slow: boolean;                      // 低速
  batches: number;                    // 「巻き始める」を押した回数
  emptied: number;                    // 元の糸を空にしてしまった回数
}
export type ItowariAction =
  | { type: 'weigh'; sourceId: string }
  | { type: 'mount'; spindle: number; sourceId: string }  // 上の段にかける(止まっている口だけ。かけていた糸は箱へ戻る。巻いた途中なら needsTie)
  | { type: 'unmount'; spindle: number }                  // 上の段から箱へ戻す(止まっている口だけ)
  | { type: 'tie'; spindle: number }                      // 継ぐ(needsTie を消す)
  | { type: 'lever'; spindle: number }                    // 握り:止まっていれば下ろす(巻く)、巻いていれば上げる(止める)
  | { type: 'stopAll' }
  | { type: 'start' }                                     // かけた口の握りを全部下ろす。meterM を 0 に、batches + 1
  | { type: 'setSlow'; slow: boolean }
  | { type: 'doff'; spindle: number }                     // 巻いたコーンを外す(made に足す)。止まっている口だけ
  | { type: 'finish' }                                    // 終える(done)
  | { type: 'tick'; dtMs: number };
```

- **巻く**:`tick` で、巻いている口はすべて同じ速さで進む(`SPEED_M_PER_S`(レベルごと。高速)、低速はその 1/5。`dtMs` は 100 を上限に丸める)。`woundM` と `meterM` が増え、その口の元の糸の `remaining` が減る。
- **元の糸が空になる**:`remaining` が 0 になったら、その口は止まる(`running` false)。refill で元の糸が空になるのは失敗(`emptied` + 1。クリールに返す糸が無くなる)。
- **継ぐ**:巻いた途中の口(`woundM > 0`)に別の元の糸をかけると `needsTie`。`tie` するまで握りを下ろせない(下ろそうとしたら何もしない。画面が理由を出す)。
- **外す(doff)**:止まっている口の、巻いたコーンを `made` に移し、その口の `woundM` を 0 に。split では、かけていたチーズの残りも、1本として仕上がる(仕上がったものとして数える)。
- **終える**:`finish` で done。
- **採点**(`resultOf(state, puzzle)`):
  - **足りない本数**:split は、作ったコーンとチーズの残りのうち `needM` に届かないものの数。refill は、作ったコーン(`made`)と元のコーン(`remaining`)のうち `needM` に届かないものの数。加えて、そろった本数が `needCount` に足りなければ、その差も足りない本数に数える。
  - **止めた誤差**:split はチーズの半分との差(各口の最大、%)。refill は、作ったコーンの長さが `needM` を超えたぶん(最大、%)。
  - **かけた回数**:`batches`(最少は split で ⌈チーズの数 ÷ 12⌉、refill で 1)。
  - 星3:足りない 0、誤差 `STOP_TOL`(2%)以内、かけた回数が最少。星2:足りない 0。星1:それ以外。
  - 成績の行:「足りない本数 0本」「止めた誤差 1.2%」「かけた回数 2回(最少 2回)」「糸を継いだ回数 1回」。
- 途中保存できる形(`isValidResume`)。乱数は使わない。時刻は `tick` の `dtMs` だけ。
