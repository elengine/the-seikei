## 長さの計算(`logic.ts` に関数で置く)

```ts
/** 番手から 1g あたりの長さ(m/g)。'2/48' → 24、'1/48' → 48、'2/60' → 30 */
export function metersPerGram(count: string): number;
/** 正味の長さ(m)=(重さ − 紙の芯の重さ)× m/g。小数は切り捨て */
export function lengthOf(grossG: number, coreG: number, count: string): number;
```

- 番手は糸のデータ(`yarns.json` の `spec`、例「ウール 2/48」)から読む。

## お題(`puzzles.ts`)

- クリール立てのお題 15 題から作る(柄と糸を同じにする。ほかのゲームと同じ考え)。糸は、その柄の**最初の糸**。
- レベル1〜2 は `split`、レベル3〜5 は `refill`。数は乱数を使わず、お題ごとに決まった値にする(同じお題は毎回同じ)。

```ts
export interface ItowariPuzzle {
  id: string; stage: 1 | 2 | 3 | 4 | 5; patternId: string; name: string;
  yarnId: string; count: string;          // 番手(例 '2/48')
  kind: 'split' | 'refill';
  coreG: number;                          // 紙の芯の重さ(レベル1〜4 は 0 として扱い、はかりは正味を出す。レベル5 は 20)
  sources: { id: string; grossG: number }[]; // 元のチーズ・コーン(はかりに載せた重さ)
  needCount: number;                      // クリールに要る本数(split:チーズの数 × 2。refill:元の本数 + 作る本数)
  needM: number;                          // 1本あたり要る長さ(m)
}
```

- 数の目安(`params.ts` の表。下は例。遊んで調整する):
  - レベル1(split):チーズ 6 個、どれも同じ重さ(正味 500g・2/48 → 12,000m)。クリールに要る本数 12(作るのは 6)。1本あたり要る長さ 5,500m。
  - レベル2(split):チーズ 15 個・要る本数 30(口は 12 なので 2 回に分けてかける)、重さが 3 通り(450・500・550g)。1本あたり要る長さは、いちばん軽いチーズの半分より少し短い値。
  - レベル3(refill):残りのコーン 6 本、クリールに 8 本要る、あと 1,200m。余りが 1,200m 以上のコーンが 2 本以上ある(1本から1本作れる)。
  - レベル4(refill):残り 6 本、要る 9 本、あと 1,500m。1本の余りでは足りず、**継いで**作る必要がある組み合わせを含む。
  - レベル5(refill):レベル4 と同じ形で、紙の芯 20g を引いて計算する。
  - どのお題も**解ける**こと(テストで確かめる:余りの合計 ≥ 作る本数 × 要る長さ)。

## ルール(`logic.ts`)

> 管理者の決定(2026-10-04、会話):「事前に長さを設定して開始したら自動で止まる。巻いている間は操作がないので短時間で良い。巻き終わったら判定して、許容範囲なら星判定、範囲外なら失敗で、長さの設定からやり直す」。

```ts
export interface Segment { sourceId: string; lengthM: number }  // この元の糸から何 m 巻くか(設定した長さ)
export interface Spindle {            // 口(最大 SPINDLES = 12)
  segments: Segment[];                // 0〜2 個。2個目は「継ぐ糸」(1個目を巻き終えたら自動で継いで続ける)
}
export type Failure =
  | { kind: 'sourceEmpty'; spindle: number; sourceId: string }   // 設定した長さが、元の糸の残りより長い
  | { kind: 'sourceShort'; sourceId: string; leftM: number }     // 元に残る長さが needM に届かない
  | { kind: 'madeShort'; spindle: number; woundM: number };      // 作ったコーンが needM に届かない
export interface ItowariState {
  puzzleId: string;
  phase: 'setup' | 'winding' | 'failed' | 'done';
  spindles: Spindle[];                // 長さ SPINDLES
  remaining: Record<string, number>;  // 元の糸ごとの残りの長さ(m)。まだ使っていない糸も含む
  used: string[];                     // 前の回までに使い終えた元の糸(箱に戻らない)
  weighed: string[];                  // はかりに載せた元の糸の id
  made: number[];                     // 仕上がったコーンの長さ(m)。split ではチーズの残りも1本として入る
  progress: number;                   // 巻いている回の進み 0〜1(アニメーション用)
  runs: number;                       // 巻いた回数(成功した回)
  failures: number;                   // 失敗した回数
  lastFailures: Failure[];            // 直前の失敗の中身(画面で示す)
}
export type ItowariAction =
  | { type: 'weigh'; sourceId: string }
  | { type: 'mount'; spindle: number; sourceId: string; slot: 0 | 1 }  // 上の段にかける(slot 1 は継ぐ糸。slot 0 が無いとかけられない)
  | { type: 'unmount'; spindle: number; slot: 0 | 1 }
  | { type: 'setLength'; spindle: number; slot: 0 | 1; lengthM: number } // 10m 単位。0〜METER_MAX_M(10,000)
  | { type: 'start' }                                                    // かけた口がすべて長さを持っているときだけ
  | { type: 'tick'; dtMs: number }
  | { type: 'retry' };                                                   // 失敗のあと、setup に戻る
```

- **巻く(winding)**:`start` で winding。`tick` で `progress` が `WIND_ANIM_MS`(4,000ms。レベルで変えない)かけて 0 → 1。巻いているあいだ、ほかの操作は受け付けない。`progress` が 1 になったら判定する。
- **判定**(`judgeRun`。純粋な関数):口ごとに、segments の長さの合計 = 作ったコーンの長さ。元の糸ごとに、引いた長さの合計を残りから引く。
  - 元の糸の残りより長く引いた → `sourceEmpty`(元の糸が途中で空になる)。
  - split:チーズの残り < `needM` → `sourceShort`。作ったコーン < `needM` → `madeShort`。
  - refill:元のコーンの残り < `needM` → `sourceShort`(クリールに戻すコーンが足りない)。作ったコーン < `needM` → `madeShort`。
  - 失敗が1つでもあれば **failed**:`failures` + 1、`lastFailures` に中身を入れ、**残りの長さは巻く前に戻す**(やり直し)。`retry` で setup に戻る(かけた糸と設定した長さはそのまま残し、直せるようにする)。
  - 失敗が無ければ成功:作ったコーンを `made` に入れる(split ではチーズの残りも入れる。refill の元のコーンは残りを減らしたまま箱に戻る)。使った糸のうち split のチーズは `used` へ。口は空にする。`runs` + 1。そろった本数が `needCount` 以上なら **done**、まだなら setup(次の回。split レベル2 の2回目など)。
- **採点**(`resultOf(state, puzzle)`):
  - **失敗した回数**:`failures`。
  - **余分**:split はチーズの半分との差(各口の最大、%)。refill は作ったコーンが `needM` を超えたぶん(最大、%)。
  - **巻いた回数**:`runs`(最少は split で ⌈チーズの数 ÷ 12⌉、refill で 1)。
  - 星3:失敗 0、余分 `EXTRA_TOL`(5%)以内、巻いた回数が最少。星2:失敗 1 回以下。星1:それ以外(仕上げれば必ず星1)。
  - 成績の行:「失敗した回数 0回」「余分 1.2%」「巻いた回数 2回(最少 2回)」「糸を継いだ口 1」。
- 途中保存できる形(`isValidResume`)。乱数は使わない。時刻は `tick` の `dtMs` だけ。
