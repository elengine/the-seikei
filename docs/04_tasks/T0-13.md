## 仕様:gameFrame.ts

```ts
export interface GameFrame {
  root: HTMLElement;
  stage: HTMLCanvasElement;     // 盤面
  panel: HTMLElement;           // 操作と情報の欄
  message: HTMLElement;         // panel 内のメッセージ欄
  resize(): void;               // 画面サイズに合わせて配置と Canvas を調整
  destroy(): void;              // 監視の解除と DOM の削除
}
export function createGameFrame(parent: HTMLElement, opts: {
  title: string;                         // 呼び出し側で terms.t() 済みの文字列
  onBack: () => void;                    // 「もどる」(確認は呼び出し側で行う)
  onHelp: () => void;                    // 「あそびかた」
  logicalW: number; logicalH: number;
  onStageResize?: (fit: StageFit) => void;
}): GameFrame;
```

- 上部の帯は高さ 72px。左に「もどる」、中央に題名、右に「あそびかた」(いずれも64px 以上)。
- 残りの領域を、landscape なら左:盤面(残り幅の 65%)・右:panel、portrait なら上:盤面(残り高さの 60%)・下:panel に分ける。
- 盤面の Canvas は `setupCanvas` で領域いっぱいに作り、`fitStage` の結果を onStageResize に渡す。
- `onViewportChange` で自動的に resize する。destroy で監視を解除する。

## 仕様:tutorialOverlay.ts

```ts
export function showTutorial(parent: HTMLElement, spec: TutorialSpec, opts: {
  nextLabel?: string; startLabel?: string;   // 既定「つぎへ」「はじめる」
  onPage?: () => void;                        // ページ送りのたび(効果音用)
}): Promise<void>;                            // 最後のページで「はじめる」を押すと解決
```

- 1ページに絵(Canvas。各ページの draw で描く)と text。text は3行以内を想定し、`--fs-body` で表示する。
- 左下にページ数(例「1 / 3」)。前のページへ戻るボタンも置く(最初のページでは非表示)。

## 仕様:resultView.ts

```ts
export function showResult(parent: HTMLElement, opts: {
  praise: string;                 // ほめる一言
  stars: 1 | 2 | 3;
  lines: string[];                // 成績(例「継いだ本数 12本」)
  newPatternNames: string[];      // 新しく集めた柄(空なら欄を出さない)
  againLabel: string; homeLabel: string;
}): Promise<'again' | 'home'>;
```

- 星は ★ と ☆ の文字で表し、色だけに頼らない。
- 表示後 1.5 秒の演出中もボタンは押せる。

## テスト(jsdom)

1. gameFrame:「もどる」「あそびかた」で各コールバックが呼ばれる。destroy で DOM から消える。
2. tutorialOverlay:3ページの spec で「つぎへ」を2回、「はじめる」を1回押すと解決する。onPage が2回呼ばれる。最初のページでは戻るボタンがない。
3. resultView:星3なら ★★★、星1なら ★☆☆ の表示。「もう一度」で 'again'、「ホームへ」で 'home'。newPatternNames が空なら柄の欄がない。

jsdom には Canvas がないため、テストでは `HTMLCanvasElement.prototype.getContext` を空の偽物に差し替えてよい。
