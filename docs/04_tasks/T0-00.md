# T0-00 リポジトリの作成

- 目的:GitHub にリポジトリを作り、設計書とアイコンを置いて、GitHub Pages を使える状態にする。
- 関連要件:C-02
- 前提:なし。このタスクだけは、まだリポジトリがない状態で行う。

## 事前に確認すること(満たしていなければ作業せず報告する)

1. `git --version` が動く。
2. `gh auth status` で GitHub にログイン済みである。
3. 管理者が指定した場所に `seikei-game-docs.zip` がある。

## 手順

1. `gh repo create the-seikei --public --description "整経を題材にした iPad・スマホ向けゲーム"` でリポジトリを作る。
   - GitHub の無料プランで Pages を使うため、公開(public)にする。
   - 同じ名前のリポジトリがすでにある場合は、何もせず報告する。
2. 作業用のフォルダに clone する(場所は管理者の指定に従う。指定がなければ `~/projects/the-seikei`)。
3. zip を展開し、中の `docs/` と `public/` をリポジトリの直下にそのまま置く。ほかのファイルは作らない。
4. リポジトリ直下に `PROGRESS.json` を作る:

```json
{
  "project": "整経ゲーム",
  "updated_at": "(作業した日時 JST)",
  "phase": "P0",
  "current_task": "T0-00",
  "done": ["T0-00"],
  "checks": {},
  "notes": [],
  "open_bugs": []
}
```

5. main ブランチに commit(メッセージ `T0-00: 設計書とアイコンを追加`)して push する。
6. GitHub Pages を「GitHub Actions でデプロイする」設定で有効にする:
   `gh api -X POST repos/{owner}/the-seikei/pages -f build_type=workflow`
   (すでに有効な場合のエラーは無視してよい。失敗した場合はエラー内容を報告する)

## 完了条件

- GitHub 上にリポジトリがあり、`docs/`、`public/icons/`(4ファイル)、`PROGRESS.json` が main にある。
- `gh api repos/{owner}/the-seikei/pages` の結果で `build_type` が `workflow` になっている。
- 報告に、リポジトリの URL と clone した場所を書く。
