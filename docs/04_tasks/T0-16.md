## 仕様:log.ts

```ts
export interface LogEntry { at: string; level: 'info' | 'warn' | 'error'; message: string; }
export interface Logger {
  log(level: LogEntry['level'], message: string): void;   // 同期。保存は後で行う
  entries(): LogEntry[];                                   // 新しい順
  flush(): Promise<void>;                                  // meta 'logs' に保存
}
export async function createLogger(store: RawStore, clock: Clock, max?: number): Promise<Logger>;  // max 既定 100
```

- 起動時に meta 'logs' を読み込む。件数が max を超えたら古いものから捨てる。
- log() の後、1秒以内に自動で flush する(連続した log は1回にまとめる)。flush の失敗は無視する。

## 仕様:termsScreen.ts(`#/settings/terms`)

- `ctx.terms.entries()` を1行ずつ表示:「現在の呼び名」(大きく)、説明(補足の色)、「かえる」ボタン、上書き中なら「元にもどす」ボタン。
- 「かえる」で textInputDialog(最大10文字)。決定したら `terms.set`。
- 上部に「もどる」(設定へ)。

## 仕様:adminScreen.ts(`#/admin`)

| 機能 | 仕様 |
|---|---|
| バックアップを書き出す | `repo.exportAll()` を JSON にし、ファイル名 `seikei-backup-YYYYMMDD-HHmm.json` で保存させる。`navigator.canShare({ files })` が true なら `navigator.share` を使い、そうでなければ a 要素の download で保存する |
| バックアップを読み込む | 隠した `<input type="file" accept="application/json">` で選ばせ、JSON として読み込めなければ「ファイルを読み込めませんでした」。読めたら `repo.importAll` を呼び、結果の件数(追加・更新・変化なし・読み込めず)を表示する |
| データの状態 | スキーマの版(meta 'schemaVersion')、永続化の状態(`navigator.storage.persisted()`。使えなければ「不明」)、使用量の見積もり(`navigator.storage.estimate()`)、端末ID |
| ログ | Logger の entries を新しい順に表示 |
| もどる | 設定へ |

- AppContext に logger を足す必要がある場合は、`src/app/context.ts` への追加を報告してから行ってよい(変更は logger の追加のみ)。
