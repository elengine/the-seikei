# T0-09 画面サイズと Canvas

- 目的:横長・縦長のレイアウト判定、画面サイズ変化の通知、盤面の拡大縮小の計算、Canvas の解像度調整を共通化する。
- 関連要件:NFR-U-07、02_architecture 7章・9章
- 前提:T0-01

## 作成するファイル

`src/core/viewport/viewport.ts`、`src/core/viewport/viewport.test.ts`

## 仕様

```ts
export type Layout = 'landscape' | 'portrait';
export interface ViewportSize { width: number; height: number; }  // CSS px

export function layoutOf(size: ViewportSize): Layout;  // 幅 >= 高さ なら landscape

// 論理座標の盤面(logicalW×logicalH)を、利用できる領域に縦横比を保って収める。純粋関数。
export interface StageFit { scale: number; offsetX: number; offsetY: number; }
export function fitStage(logicalW: number, logicalH: number, availW: number, availH: number): StageFit;
// scale は収まる最大の倍率。余白は左右または上下に均等に配る。

export function currentSize(): ViewportSize;  // visualViewport があればその幅高さ、なければ window.innerWidth/Height

// サイズ・向きの変化を通知する。visualViewport の resize、window の resize と orientationchange を監視し、
// 同じフレーム内の複数の変化は requestAnimationFrame で1回にまとめる。戻り値で監視を解除する。
export function onViewportChange(cb: (size: ViewportSize, layout: Layout) => void): () => void;

// Canvas を CSS サイズ cssW×cssH で表示し、内部解像度を devicePixelRatio 倍にする。
// 戻り値の ctx は、CSS px の座標で描けるよう setTransform 済み。
export function setupCanvas(canvas: HTMLCanvasElement, cssW: number, cssH: number): CanvasRenderingContext2D;
```

- devicePixelRatio は 1〜3 の範囲に丸める(大きすぎる内部解像度を避ける)。

## テスト

1. `layoutOf`:1180×820 は landscape、393×873 は portrait、800×800 は landscape。
2. `fitStage(1000, 750, 2000, 750)`:scale 1、offsetX 500、offsetY 0。
3. `fitStage(1000, 750, 500, 1000)`:scale 0.5、offsetX 0、offsetY 312.5。
4. `onViewportChange`:window の resize を2回続けて発火させても、次のフレームで cb が1回だけ呼ばれる(requestAnimationFrame を vi.fn で差し替えてよい)。解除後は呼ばれない。
