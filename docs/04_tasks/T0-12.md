# T0-12 効果音

- 目的:音源ファイルを使わず、Web Audio で効果音を合成して鳴らす。
- 関連要件:FR-C-05、FR-C-08、02_architecture 8.4
- 前提:T0-01

## 作成するファイル

`src/core/audio/sounds.ts`、`src/core/audio/audio.ts`、`src/core/audio/audio.test.ts`

## 仕様:sounds.ts(音の設計図。純粋なデータ)

```ts
export type SoundName = 'tap' | 'ok' | 'gentleNo' | 'knot' | 'page' | 'fanfare';
export interface Note { freq: number; startMs: number; durMs: number; wave: 'sine' | 'triangle'; gain: number; }
export const SOUNDS: Record<SoundName, Note[]>;
```

| 名前 | 用途 | 目安 |
|---|---|---|
| tap | ボタン | 高めの短い音 1つ(約60ms) |
| ok | 正解・成功 | 上がる2音 |
| gentleNo | 違う操作 | 低めでやわらかい短い音 1つ。責める感じにしない |
| knot | 糸を結んだ | 小さな3連音 |
| page | チュートリアルのページ送り | 短い1音 |
| fanfare | クリア | ド・ミ・ソ・ド の上昇 |

- 高齢者にも聞き取りやすいよう、周波数は 250〜2000Hz の範囲にする。
- 各 Note の gain は 0.5 以下。1つの音の全体の長さは 2000ms 以下。

## 仕様:audio.ts

```ts
export interface AudioPlayer {
  unlock(): void;                 // 最初の操作のときに呼ぶ。AudioContext を作り resume する
  play(name: SoundName): void;    // unlock 前、または無効時は何もしない
  setEnabled(on: boolean): void;
  setVolume(v: number): void;     // 0〜1 に丸める
}
export function createAudioPlayer(makeContext?: () => AudioContext): AudioPlayer;
```

- 各 Note は OscillatorNode と GainNode で鳴らし、音の頭と終わりに短い(10ms 程度)フェードを入れて「プツッ」という音を防ぐ。
- 全体の音量は、共通の GainNode に volume を掛けて調整する。
- 例外が起きても投げずに無視する(音が鳴らなくても遊びは止めない)。

## テスト

1. SOUNDS のすべての名前に1つ以上の Note があり、周波数・gain・長さが上の範囲内。
2. `makeContext` に偽の AudioContext(createOscillator などを vi.fn で記録するもの)を渡し、unlock 前の play では発振器が作られない。
3. unlock 後の play('ok') で、Note の数だけ発振器が作られる。
4. setEnabled(false) の後は作られない。
5. setVolume(1.5) は 1 に丸められる。
