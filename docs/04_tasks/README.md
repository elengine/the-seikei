# タスク仕様書の一覧(P0 共通基盤)

## Discord での渡し方

1タスクにつき、次の定型文を Hermes Agent に送る。仕様書の本文はリポジトリ内にあるので、メッセージに貼る必要はない。

```
docs/04_tasks/00_rules.md と docs/04_tasks/T0-05.md を読んで、タスクを実行してください。
```

完了報告を受けたら、管理者が内容を確認してから次のタスクを送る。

最初の T0-00 だけは、まだリポジトリがないため、zip の場所を添えて次のように送る。

```
~/seikei-game-docs.zip を一時フォルダに展開し、その中の docs/04_tasks/00_rules.md と docs/04_tasks/T0-00.md を読んで、タスクを実行してください。
```
