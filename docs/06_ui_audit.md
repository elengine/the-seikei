# 画面の点検(見た目の統一の準備)

- 日付:2026-09-30(確認役)。出どころ:管理者の依頼「アプリ全体のレイアウトや UI を統一してほしい。画面ごとにマージンやアラインが違い、見た目がチープ。日本中の整経業者さんに遊んでもらえる仕上がりに」(会話)。
- 見た画面:ホーム、設定、呼び名の変更、クリール立ての一覧・盤面、ドラム巻きの一覧・盤面、続きからの確認。大きさは 1180×820 と 412×915(本番と同じビルド `f48e83e` 時点)。

## 見つかった違いと安っぽさ

### 画面の枠(見出しの行)

| 画面 | 「戻る」 | 題名 | 右側 |
|---|---|---|---|
| ホーム | なし | 中央・小さい(屋号) | なし |
| 設定・呼び名の変更 | 左、左右の余白あり | **中央** | なし |
| クリール立ての一覧 | 左、**余白なしで端に接する** | **「戻る」のすぐ右**に左寄せ | なし |
| ドラム巻きの一覧 | 左 | 「戻る」のすぐ右 | なし |
| ゲームの盤面 | 左 | 中央 | 「遊び方」 |

- 見出しの行の形が画面ごとに3通りある。題名の大きさ・太さ・高さもそろっていない。

### 中身の幅と余白

- ドラム巻きの一覧は、中身を**中央に細く**(最大幅つき)置く。クリール立ての一覧は**画面の幅いっぱい**。同じ種類の画面なのに形が違う。
- 設定は画面の幅いっぱいで、項目名が左端、ボタンが右端に離れすぎる(1180 幅で 900px 以上離れる)。
- 左右の余白が、画面によって 0・12px・16px・24px と違う。上の余白(見出しの行の上)も違う。
- `base.css` は 1008 行。余白の値は `--gap`(12px)の倍数と、`8px`・`10px`・`12px`・`24px`・`2px` などの直書きが混ざる。角の丸みも `4px`・`8px`・`12px` が混在。

### 一覧の行

- クリール立ては「未解放」を2行目に出す。ドラム巻きは右端に出す。行の高さも違う。
- 未解放の行は、文字を薄くするだけ。鍵などの記号が無く、解放済みとの差が弱い。
- 星(成績)の出し方が、一覧の画面ごとに違う(クリール立ては題名の右、ドラム巻きは未表示のことがある)。

### ホーム

- 1180×820 で、屋号(小さい)とゲームのボタン2つが上に固まり、画面の8割が空白。「設定」だけが一番下。
- ゲームのボタンが小さな四角で、ゲームの絵や説明が無い。何のアプリか、はじめての人に伝わらない。
- アプリの題名(「整経ゲーム」など)が画面のどこにも無い。

### 部品

- ボタンは「塗り(緑)」「枠(藍)」「塗り(藍)」「薄い緑」と4種類あり、どれが主な操作かの決まりが見えない(例:設定の「✓大」は藍の塗り、ホームは緑の塗り、クリール立ての「確認する」は緑の塗り、「ヒント」は薄い緑)。
- 確認の画面(続きから)は、文が小さく(20px)、ボタンとの間が詰まっている。題名が無い。
- 設定の「管理者」だけ、ほかと違う小さな四角。
- 呼び名の変更は、用語(大)と説明(小)の2段が詰まっていて、行の区切りが無い。15行以上が続くので読みにくい。

### 盤面(Canvas)と操作欄

- 盤面の地の色と、操作欄の地の色が同じ生成りで、区切りが無い。盤面の外枠も無い。
- 操作欄の部品の大きさと間隔が、ゲームごとに違う(クリール立ては詰まり、ドラム巻きは広い)。

## 見た目の方向を決めるときの論点(管理者に見本を見せて決める)

1. 色と質感:生成りの地・藍・木を基本に、縞(ストライプ)の柄を飾りに使うか。
2. 書体:今は端末の標準のゴシック体。読みやすさを重視した書体(例:BIZ UD ゴシック。無料で使える)をアプリに入れるか。入れると容量が数 MB 増え、最初の読み込みが少し遅くなる。
3. ホームの形:ゲームを「カード」(絵・名前・一言の説明・星の数)で並べるか。
4. 広く遊んでもらうための準備:アプリ名とアイコン、はじめて開いた人への案内、呼び名の初期値。
