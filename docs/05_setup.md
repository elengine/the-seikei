# お父さんの端末の準備手順

管理者が、お父さんの端末で整経ゲームを使える状態にするための手順。

## 共通の注意

- インストールは、Chrome のメニューの「ホーム画面に追加」ではなく、**管理者メニューの「アプリとしてインストール」ボタン**から行う(P0 の実機確認で、Chrome のメニュー側の判定が古い記録を見て「インストール済み」と誤表示し、インストールできない現象があったため)。
- インストール中は VPN を切っておく。
- マニフェストの id(`the-seikei`)は変えない。

## Android(Chrome)

1. Chrome で `https://elengine.github.io/the-seikei/` を開く。
2. 「せってい」→ 一番下の「管理者」→ `1967` で管理者メニューを開く。
3. 診断欄の「インストールの判定」が「はい」であることを確かめる。
4. 「アプリとしてインストール」を押し、Chrome の画面で「インストール」を選ぶ。十数秒でアプリ一覧に「整経」が出る。
5. 「整経」から起動し、管理者メニューの診断欄で表示モードが全画面(standalone)、永続化が「されている」ことを確かめる。

## iPad(Safari)

1. Safari で `https://elengine.github.io/the-seikei/` を開く。
2. 共有ボタン →「ホーム画面に追加」。
3. ホーム画面のアイコンから起動し、全画面で開くこと、管理者メニューで永続化の状態を確かめる。
4. 以後は必ずホーム画面のアイコンから起動する(Safari から開くと、保存データが別扱いになる)。

## 新しい版を届けたとき

- 通常は、次にアプリを起動したときに自動で切り替わる。
- すぐに切り替えたいときは、管理者メニューの「今すぐ新しい版に切り替える」を押す(T1-01 以降)。
