### PU-08c:文字の大きさの5段階

- `FontScale` は 1〜5 の数。`FONT` は仕様の表のとおり(段階1 = 今の「大」、段階3 = 「特大」、本文は最小 20px)。`applyFontScale` は `data-font` に数の文字を入れる。`base.css` は `:root[data-font='2']`〜`'5'` で `--fs-*` を切り替える(`xlarge` の規則は無くした)。仕様に表の無い値は、段階1 と 3 を通る直線で広げた:題名 `--fs-title` 32/35/38/41/44、星(一覧)24/26/28/30/32、星(結果)56/60/64/68/72、結果の見出し 36/39/42/45/48、ホームのアプリ名 44/47/50/53/56、カードの名前 30/32/34/36/38。
- `settings.ts`:保存してある値を読み込むときに置き換える(`'large'` → 1、`'xlarge'` → 3、1〜5 の整数はそのまま、それ以外・範囲の外・小数・文字は 1)。既定は 1。
- 設定の「文字の大きさ」は `<input type="range" min="1" max="5" step="1">` のスライダー(`aria-label="文字の大きさ"`、`aria-valuetext` は「段階N」)。両端に「小」「大」、5 つの目盛り、下に見本の文「この大きさで表示します」。動かしているあいだ(`input`)は見本の文の大きさだけがすぐ変わり、保存(画面全体の切り替え)は指を離したとき(`change`)。行の高さ 64px、溝 8px(選んだ側が `ai`、残りが `line`)、つまみ 44px(白地・藍の枠)。`-webkit-appearance: none` にして `::-webkit-slider-*` と `::-moz-range-*` で自前で描き、`touch-action: none`。600px 未満は、スライダーを項目名の下の段の全幅にする。
